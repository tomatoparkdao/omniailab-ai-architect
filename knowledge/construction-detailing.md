# 构造与施工深化

构造与施工深化回答的是"设计意图如何被造出来"。它把平面、界面、材料统一到可施工的节点上，处理基层、收口、防水、变形、检修等一系列工程问题。构造是设计的最后一公里，也是返工最集中的环节。

本领域给出的是**常见做法与构造层次**，不构成结构、防火、防水的最终结论。所有涉及结构安全与消防构造的判定，须由持证专业人员在项目所在地复核签署。

## 适用范围与边界

- 适用：墙面、地面、天花的构造层次，收口节点、防水构造、检修构造、变形缝。
- 适用：S6 构造方案、S7 施工图深化。
- 不适用：结构构件的设计。
- 不适用：防火构造的合规结论。
- 边界：构造层次须与材料规格、设备定位一致。
- 边界：现场施工工艺差异须通过容差与做法说明覆盖。

## 核心判据

1. 每个收口部位都有对应节点大样。
2. 节点大样标注了完整的构造层次与厚度。
3. 基层做法明确（找平、找坡、防水、隔声）。
4. 材料交接处有明确的收口方式与顺序。
5. 潮湿区域的防水构造连续、上翻高度明确。
6. 变形缝、伸缩缝的处理与该部位变形量匹配。
7. 大面材料的排版起铺点在节点中可追溯。
8. 吊顶做法考虑了检修、承载与自重。
9. 墙面的基层平整度要求已说明。
10. 地面构造层次考虑了标高与完成面厚度。
11. 节点考虑了不同材料的线膨胀差异。
12. 石材、瓷砖的挂贴方式与安全锚固已明确。
13. 木饰面的基层防潮与通风已考虑。
14. 收口条、踢脚的构造与作用已说明。
15. 灯具、风口、喷淋与天花的节点协调。
16. 设备检修口的构造便于反复开启。
17. 门窗洞口构造考虑了防水、保温、收口。
18. 节点对施工误差留有余量。
19. 构造做法与材料表、图纸一致。
20. 特殊造型（弧形、异形）的基层做法已说明。
21. 节点标注了材料编号与规格。
22. 构造层次满足隔声、保温、防火需求（待复核）。
23. 节点经济性合理，不因过度构造浪费。
24. 施工顺序在复杂节点中已说明。
25. 关键节点有现场交底的版本。
26. 节点图的标准图与被引用图号对应。
27. 节点的可维护性（拆装、更换）已考虑。
28. 构造做法不受限于单一供应商的专有系统（除非注明）。
29. 涉及安全的构造（锚固、承载）注明待专业复核。
30. 图纸图册中节点索引完整无缺。

## 数值与区间

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 地面找平层厚度 | 20–50 mm | 视标高 |
| 地面完成面总厚 | 30–80 mm | 含粘贴/找平 |
| 墙砖粘贴层厚度 | 6–15 mm | 视系统 |
| 石材干挂空腔 | 50–150 mm | 视龙骨 |
| 墙面找平层厚度 | 10–30 mm | 视基层 |
| 吊顶吊杆长度 | 300–1500 mm | 视净高 |
| 吊顶龙骨间距 | 300–600 mm | 视板材 |
| 石膏板接缝处理 | 留缝 + 嵌缝带 | 防裂 |
| 防水层上翻高度 | 淋浴区 ≥1800 mm | 以规范为准 |
| 防水层上翻（其他） | ≥300 mm | 以规范为准 |
| 地面防水层数 | 1–2 道 | 视部位 |
| 变形缝宽度 | 20–50 mm | 视部位 |
| 踢脚高度 | 60–120 mm | 视做法 |
| 收口凹缝深度 | 3–10 mm | 视材料 |
| 检修口常用尺寸 | 300×300 / 600×600 mm | 视设备 |
| 木饰面基层含水率 | ≤12% | 防变形 |
| 门洞收口余量 | 5–15 mm | 现场调整 |
| 隔声墙空气层 | 50–100 mm | 视隔声 |

## 常见错误

- 只画平面与界面，无节点大样。
- 节点只给外形不给层次与厚度。
- 基层做法缺位，现场随意施工。
- 材料交接靠打胶，后期开裂脱落。
- 湿区防水不连续或上翻不足。
- 变形缝做法与变形量不匹配。
- 大板排版无起铺点，现场开切混乱。
- 吊顶未考虑检修与承载，变形下沉。
- 石材湿贴于高墙面，存在安全隐患。
- 木饰面基层无防潮，后期膨胀变形。
- 设备检修口开启不便或藏在造型后。
- 门窗收口未考虑防水与保温。
- 节点未留施工误差余量，现场被迫削改。
- 异形造型无基层做法说明。
- 图纸节点索引不全，施工方找不到对应大样。
- 节点与材料表不一致，选错收口。

## 分阶段应用

- S6：确定关键节点的构造方案。
- S7：出完整节点大样与标准图。
- 施工前对复杂节点进行交底。
- 变更须同步更新节点索引与材料表。
- 安全相关节点须经专业复核后出图。

## 典型权衡与取舍

- 构造厚度 vs 净尺寸：构造越厚，可用净空间越小。
- 施工便利 vs 收口精细：可施工性与精致度常矛盾。
- 造价 vs 耐久：更耐久的构造通常成本更高。
- 标准化 vs 定制：标准化易施工，定制更贴合设计。
- 隐蔽 vs 检修：越隐蔽越难检修。
- 防水冗余 vs 厚度：防水越足越厚。

## 输出物与数据格式

- 节点大样图（编号 + 层次 + 标注）。
- 标准构造图集引用。
- 材料交接收口索引。
- 检修口与设备安装节点。
- 施工交底文件（复杂节点）。

## 风险与不确定性

- 现场施工误差影响收口效果。
- 材料实际尺寸与图纸不符。
- 基层条件（平整度、含水率）差异大。
- 构造做法在不同施工队之间执行不一致。
- 安全相关构造的复核结果可能反改做法。
- 以上风险须在节点说明与容差设定中覆盖。

## 术语与口径

- **节点大样**：放大表达构造做法的详图。
- **基层**：面层之下的结构或找平层。
- **收口**：材料交接处的处理方式。
- **上翻**：防水层沿墙面上返的高度。
- **容差**：允许的施工尺寸偏差。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地现行规范"。
- 防水、防火、结构锚固等要求应转成"待本地复核项"。
- 构造与规范冲突时以合规优先。
- 涉及结构安全与消防构造的最终判定交由持证专业人员签署。

## 常见问答式判断

- 问：这里怎么收口？答：先定材料交接方式与顺序。
- 问：防水要不要上翻？答：按部位与规范要求设定高度。
- 问：这个造型怎么落地？答：先定基层与骨架做法。
- 问：检修口会不会太显眼？答：在可检修与美观间取平衡。
- 问：节点要不要复核？答：涉及承载与安全的必须复核。
- 以上问答用于暴露缺失信息，不替代专业判定。

## 典型节点类型清单

- 墙地交接：踢脚、地面与墙面收口。
- 墙顶交接：天花与墙面收口、跌级处理。
- 地漏与防水：湿区地面找坡与防水上翻。
- 石材干挂：龙骨、挂件与安全锚固。
- 木饰面基层：防潮、基层与饰面板安装。
- 吊顶检修口：开启方式与承载。
- 门窗收口：与墙体、防水、保温交接。
- 灯具与风口：天花开孔与安装。
- 变形缝：盖板与变形量匹配。
- 特殊造型：弧形、异形基层做法。
