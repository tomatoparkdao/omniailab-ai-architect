# 人体工学与尺度

人体工学与尺度是空间规划的"量纲底座"。它提供的是可被直接引用的尺寸判据，把"够不够、顺不顺、累不累"从主观感受变成可校核的数值。本领域服务于平面布置、家具选型、构造收口与施工深化。

本领域给出的是**常见工程惯例区间**，不是法定强制值，也不构成无障碍合规结论。涉及无障碍的最终判定须由持证专业人员在项目所在地复核签署。

## 适用范围与边界

- 适用：通道宽度、家具间距、操作台高度、洁具布置、扶手与栏杆高度、储物尺度。
- 适用：S3 平面布置、S4 尺度深化、S7 施工图中的细部尺寸。
- 不适用：结构安全、消防疏散的最终判定。
- 不适用：无障碍合规结论（本领域仅提供参考尺度）。
- 边界：不同人群（儿童、老人、残障）尺度差异大，须按目标人群选取。
- 边界：数值为惯例区间，实际以产品样本与项目所在地规范为准。

## 核心判据

1. 主要通道净宽不小于双人并行所需宽度。
2. 单人通行空间不小于人体可舒适通过的净宽。
3. 家具之间预留了起坐、开合、弯腰等动作所需空间。
4. 操作台高度与使用姿势匹配（站姿、坐姿各有常用值）。
5. 储物高处与低处的常用区间合理，重物不置于过高处。
6. 洁具中心距与前方活动空间满足使用与清洁需求。
7. 梯段踏步高度与宽度组合符合人体舒适步幅。
8. 扶手、栏杆高度在常见区间，且连续无中断。
9. 门把手、开关、插座的离地高度符合常用习惯。
10. 主要视线高度与窗台、隔断、陈设遮挡关系合理。
11. 桌椅高度差使肘部自然下垂时前臂接近水平。
12. 厨房操作三角（洗涤—备餐—烹饪）动线不交叉。
13. 衣柜净深可容纳衣架与衣物。
14. 鞋柜、玄关凳等换鞋动作有足够空间。
15. 卫生间内转身、开门、使用洁具三者不冲突。
16. 儿童空间的安全尺度（防夹、防碰）已考虑。
17. 老人空间的助力设施（扶手、座椅）位置合理。
18. 坐轮椅使用者的通行与转圜参考尺度已纳入（最终合规待复核）。
19. 主要功能房间的家具布置满足多人在场时的通行。
20. 人体尺度校核结果已回写至平面尺寸标注。
21. 视线高度与屏幕、展示面、镜面位置协调。
22. 楼梯平台宽度不小于梯段宽度。
23. 阳台、露台栏杆的高度与间距符合安全惯例。
24. 不同功能区采用了与其行为相匹配的椅子与桌面尺度。
25. 站立操作与坐着操作的工作台分别校核。
26. 尺度取值说明了目标人群（成人平均值或特殊人群）。
27. 关键尺寸在图纸上有明确标注，而非依赖经验。
28. 尺寸冲突时以使用频率高者优先。
29. 尺度校核覆盖了主要的固定家具与设备。
30. 所有涉及安全的尺度均标注待专业复核。

## 数值与区间

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 单人通行净宽 | 600–750 mm | 最低舒适宽度 |
| 双人并行净宽 | 1200–1500 mm | 主通道 |
| 主要走廊净宽 | 1200–1800 mm | 公共建筑取高值 |
| 餐桌到餐椅就座 | 750–900 mm | 便于起坐 |
| 沙发前沿到茶几 | 300–450 mm | 取物与通行 |
| 电视到沙发距离 | 屏幕对角线 2–3 倍 | 视尺寸 |
| 厨房操作台高度 | 站姿 800–900 mm | 视身高 |
| 厨房吊柜底到台面 | 500–600 mm | 防碰头 |
| 厨房操作三角单边 | 1200–2700 mm | 减少折返 |
| 书桌高度 | 720–760 mm | 配 420–480 mm 椅高 |
| 座椅座面高 | 400–460 mm | 视用途 |
| 衣柜净深 | 550–600 mm | 容纳衣架 |
| 玄关换鞋凳高 | 400–450 mm | 便于起坐 |
| 洁具中心距 | 750–900 mm | 常用布置 |
| 洗手盆前方净空 | 600–750 mm | 使用与清洁 |
| 坐便前方净空 | 600 mm 起 | 以规范为准 |
| 踏步高度 | 150–175 mm | 舒适区间 |
| 踏步宽度 | 260–300 mm | 舒适区间 |
| 扶手高度 | 850–1000 mm | 常见区间 |
| 栏杆垂直杆间距 | ≤110 mm | 防儿童穿越 |
| 开关高度 | 1200–1400 mm | 常用习惯 |
| 插座高度 | 300 / 1200 mm | 视用途 |
| 窗台高度 | 900–1000 mm | 常规 |

## 常见错误

- 通道宽度只按图纸经验，不按人体尺度校核。
- 家具布置后无法开门或无法打开抽屉。
- 厨房操作台高度一刀切，未区分站姿坐姿。
- 衣柜净深不足，衣架无法正常悬挂。
- 卫生间洁具间距过近，使用尴尬且难清洁。
- 踏步高度不一致，行走易绊倒。
- 开关插座高度未随家具高度调整。
- 视线高度与镜面、屏幕位置冲突。
- 儿童空间未做防夹防碰处理。
- 老人空间扶手中断，无法连续扶持。
- 无障碍仅按最小宽度画，实际转圜不足。
- 尺度取值未说明目标人群。
- 楼梯平台宽度小于梯段宽度。
- 阳台栏杆间距过大，存在安全隐患。
- 尺度校核漏掉固定设备（如钢琴、冰箱）。
- 关键尺寸靠"看起来差不多"，未标注。

## 分阶段应用

- S3：用最小尺度校核平面可行性。
- S4：细化家具与固定设备的尺度。
- S7：在施工图中标注关键尺寸并核对节点余量。
- 尺度表随项目维护，作为统一引用源。
- 目标人群改变时须重校全部关键尺寸。

## 典型权衡与取舍

- 舒适尺度 vs 面积效率：尺寸充裕体验好，但容纳人数少。
- 统一尺度 vs 个性化：统一利于施工，个性利于特定人群。
- 通用设计 vs 特殊定制：通用面广，定制贴合。
- 家具尺寸 vs 通道宽度：家具越大通道越窄。
- 储物深度 vs 空间占用：越深储物越多，占净空越大。

## 输出物与数据格式

- 人体尺度校核表（部位 + 取值 + 依据 + 目标人群）。
- 关键尺寸标注图（单位 mm）。
- 家具尺寸清单（名称 + 长宽高）。
- 通行宽度校核图。
- 洁具布置尺寸图。

## 风险与不确定性

- 目标人群差异大，均值可能不适用。
- 产品实际尺寸与样本有偏差。
- 规范更新可能改变某些最低值。
- 施工完成面厚度影响净尺寸。
- 以上风险须在尺度表中标注假设与复核要求。

## 术语与口径

- **净宽**：扣除所有凸出物后的可通行宽度。
- **中心距**：两个洁具或设备中心线之间的距离。
- **净高**：完成面到上方障碍物的垂直距离。
- **操作三角**：厨房洗涤、备餐、烹饪三点构成的工作动线。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地现行规范"。
- 无障碍、楼梯、栏杆等安全相关尺度应转成"待本地复核项"。
- 规范与产品样本冲突时，取更安全者并标注。
- 涉及安全的最终判定交由持证专业人员签署。

## 常见问答式判断

- 问：这条通道够宽吗？答：按通行人数与行为类型取对应净宽。
- 问：柜子能不能做到顶？答：看举高取物是否安全与是否需要梯子。
- 问：洁具能不能再近？答：按中心距与前方净空下限校核。
- 问：踏步能不能做陡？答：按踏步高度与宽度组合的舒适区间判断。
- 问：这个高度合适吗？答：按目标人群的身高分布取值。
- 以上问答用于暴露缺失信息，不替代专业判定。
