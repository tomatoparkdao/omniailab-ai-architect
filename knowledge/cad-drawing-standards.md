# CAD 制图标准

CAD 制图标准是设计成果能否被准确施工、被他人读懂、被反复修改的基础。统一的制图规则能显著降低沟通成本与错误率。本领域定义图层、线型、标注、文字、比例、图框与图纸组织的统一约定。

本领域给出的是**常见制图惯例**，不引用具体标准编号。如项目所在地或委托方另有制图标准要求，以更严格者为准。

## 适用范围与边界

- 适用：图层组织、线型线宽、尺寸标注、文字样式、图框与标题栏、图纸编号、打印设置。
- 适用：S7 施工图阶段的全部 CAD 成果。
- 不适用：三维模型与 BIM 参数化（见 `bim-modeling-principles`）。
- 不适用：效果图表现。
- 边界：制图标准服务于施工与沟通，不追求形式本身。
- 边界：命名与图层体系一旦确定，项目内不得随意更改。

## 核心判据

1. 所有图层有统一命名规则，含义可自解释。
2. 每种线型只表达一种含义。
3. 线宽分级体现图面层次（主体粗、次要细）。
4. 尺寸标注采用统一样式与精度。
5. 文字样式、字高、字体统一。
6. 图框与标题栏格式全项目一致。
7. 图纸编号规则统一且不重复。
8. 比例选择使图纸内容清晰可读。
9. 打印样式（CTB/STB）统一，线宽可预测。
10. 标注尺寸与几何实际尺寸一致，无"手改"数值。
11. 图面不出现重叠、遮挡、未修剪的多余线。
12. 每个图元在正确图层上，不靠颜色硬改。
13. 引用外部文件（Xref/图块）路径规范可移植。
14. 图块库统一，同一构件不重复定义。
15. 图纸修订有记录（版本、日期、内容）。
16. 平面、天花、地面、立面图号与索引对应。
17. 索引符号与详图编号一致。
18. 文字说明无错别字与格式混乱。
19. 坐标与单位（mm）在项目内统一。
20. 图纸冻结与图层可见性设置不误导他人。
21. 打印前进行打印预览与线条检查。
22. 大样图放大比例与标注一致。
23. 图纸目录与实际图纸数量一致。
24. 每个专业图纸有统一的图签信息。
25. 电子文件命名规则统一（专业-图号-版本）。
26. 修改他人图纸时保留可追溯性。
27. 图面留白与图框边界保持整洁。
28. 使用注释性对象（如适用）确保多比例一致。
29. 出图前进行内部校审记录。
30. 交付格式（DWG/PDF）与用途匹配。

## 数值与区间

以下均为**常见制图惯例区间**，非强制标准，须以项目所在地或委托方制图标准为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 绘图单位 | mm | 建筑制图常用 |
| 常规平面比例 | 1:50 / 1:100 | 视范围 |
| 大样比例 | 1:5 / 1:10 / 1:20 | 视细节 |
| 总图比例 | 1:200 / 1:500 | 视范围 |
| 打印线宽（粗） | 0.5–0.7 mm | 主体结构 |
| 打印线宽（中） | 0.25–0.35 mm | 次级构件 |
| 打印线宽（细） | 0.09–0.13 mm | 填充与标注 |
| 尺寸标注字高 | 2.5–3.0 mm（打印） | 视比例 |
| 说明文字字高 | 3.0–3.5 mm（打印） | 视比例 |
| 图框尺寸（A1） | 841×594 mm | 标准图幅 |
| 图框尺寸（A3） | 420×297 mm | 常用 |
| 尺寸精度 | 整数 mm | 建筑常规 |
| 图层数量（建议） | 按专业与构件分类 | 不宜过少过多 |
| 标高精度 | 0.001 m | 常用 |
| 轴线编号间距 | 视开间 | 连续不跳号 |

## 常见错误

- 图层命名混乱，他人无法识别。
- 一种线型承载多种含义。
- 线宽不分级，图面一片均匀，无层次。
- 标注样式不统一，字高大小不一。
- 图框与标题栏格式不一致。
- 图纸编号重复或跳号。
- 比例选择不当，内容过密或过疏。
- 打印线宽不可预测，实物与屏幕差别大。
- 尺寸数值与几何不符（手动改数字）。
- 图面残留大量未修剪线条。
- 图元不在正确图层，靠颜色区分。
- Xref 路径为绝对路径，换机后丢失。
- 同一构件有多个图块定义。
- 无修订记录，版本混乱。
- 索引与详图编号不匹配。
- 打印前未检查，输出缺线或重叠。

## 分阶段应用

- S7 前：确定图层、线型、标注、图框标准。
- S7 中：按标准出图，定期校审。
- S7 后：整理图纸目录、修订记录与交付格式。
- 标准一经确定，全项目统一执行，不得个人化。
- 交付前做完整打印检查。

## 典型权衡与取舍

- 图层细分 vs 管理成本：越细越清晰，也越难管理。
- 信息量 vs 图面整洁：信息多易乱，整洁易漏。
- 标准化 vs 适应性：标准统一，特殊项目需微调。
- 自动标注 vs 手动控制：自动高效，手动可控。
- 单文件 vs 拆分：单文件便于协同，拆分便于管理。

## 输出物与数据格式

- 制图标准说明（图中图例页）。
- 图层与线型对照表。
- 标题栏与图框模板。
- 图纸目录（图号 + 图名 + 版本）。
- 修订记录表。
- 打印样式文件说明。

## 风险与不确定性

- 不同软件版本兼容性差异。
- 外部参照丢失导致图面缺失。
- 字体缺失导致文字乱码。
- 多人协同导致图层污染。
- 交付格式与接收方软件不兼容。
- 以上风险须在交付前通过标准化检查规避。

## 术语与口径

- **图层**：图元的组织分类容器。
- **线宽**：打印后的线条粗细。
- **外部参照（Xref）**：被引用的外部图纸文件。
- **图纸目录**：全部图纸的编号与名称清单。
- **修订记录**：版本变更的历史说明。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地或委托方制图标准"。
- 若委托方有制图手册，以其为准并做适配说明。
- 制图标准与建模标准冲突时，以出图可读性优先。
- 涉及交付合规的要求交由项目负责人确认。
- 图纸中涉及结构、消防、无障碍、机电负荷的标注内容，其结论须由持证专业人员在项目所在地复核签署，制图标准本身不作安全判定。

## 常见问答式判断

- 问：这个图层怎么命名？答：按"专业-构件-用途"规则命名。
- 问：线宽要不要分级？答：需要，以体现图面层次。
- 问：比例怎么选？答：以内容清晰可读为准。
- 问：尺寸能不能手改？答：禁止，必须与几何一致。
- 问：交付什么格式？答：按用途交付 DWG 与 PDF。
- 以上问答用于保证制图一致性。

## 图层命名规则建议

- 建议采用"专业-构件-用途"三段式命名，如"建筑-墙体-轮廓"。
- 分隔符全项目统一（短横线或下划线），不得混用。
- 图层名避免中文与特殊字符混排导致兼容问题（以团队习惯为准）。
- 常用图层应纳入模板文件，禁止临时新建散乱图层。
- 图层颜色用于区分，但不得以颜色替代图层分类。
- 打印线宽由图层或打印样式控制，二者择一并统一。
- 废弃图层应清理，避免图纸臃肿。
- 图层模板一经发布，项目中只增不改名。
