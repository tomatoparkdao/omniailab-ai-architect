# 室内设计方法论

室内设计方法论是"总设计师"在建筑壳体确定后，对内部功能、界面、氛围与使用体验负责的工作框架。它把建筑给定的空间条件翻译为可施工、可运营、可持续的室内方案，并约束后续的材料、照明、机电与构造领域。

本领域输出的是**室内设计逻辑与判断框架**，不是风格词库。任何风格描述都必须能落到功能、尺度、材料、照明四个可验证维度上。

## 适用范围与边界

- 适用：室内功能重组、隔墙与界面划分、天花与地面策略、色彩与材质基调、软装与家具策略。
- 适用：S1 室内任务解读、S2 室内概念、S3 室内平面、S4 界面深化、S6 定稿协调。
- 不适用：结构改动的安全性判定、消防分区最终结论、机电负荷与风量计算。
- 不适用：室外总图与建筑外形（见 `architectural-design-principles`）。
- 边界：风格由业主与设计团队共同决定，本领域只负责风格与功能、造价、可维护性的自洽。
- 边界：所有材质与规格的具体选型在 `material-and-finish-selection` 中细化。

## 核心判据

1. 室内平面中的每一道新隔墙都能说明其功能目的，而非仅为造型。
2. 每个空间的动线入口与出口清晰，使用者不需要回头找路。
3. 界面（顶、地、墙）的完成面在相交处有明确收口逻辑。
4. 天花高度变化处的收口方式与其造型意图一致。
5. 室内净高在扣除机电与造型后仍满足功能与心理舒适底线。
6. 主要视觉焦点与主要功能点不冲突（避免"好看但不好用"）。
7. 材质分区与功能分区对齐，通道地面与停留区地面有区分。
8. 色彩基调与空间功能匹配（如医疗、教育、办公对色彩的心理需求不同）。
9. 家具布置满足人体活动尺度与通行宽度（详见 `human-ergonomics`）。
10. 软装与硬装不在同一界面争夺视觉主导权。
11. 灯光预设位置在概念阶段就与天花造型协调（详见 `lighting-design`）。
12. 可达性：所有可开启柜门、设备检修口在布置后仍能打开。
13. 维护逻辑成立：高频区域采用耐污耐磨材质，隐蔽处不设奢材。
14. 室内高差处理有明确做法（台阶、缓坡、地毯过渡）。
15. 声学敏感空间（会议、影音、休息）有界面吸声策略。
16. 各功能区的照度、色温、氛围灯设计有分工（详见 `lighting-design`）。
17. 室内与建筑界面（窗、幕墙、柱、梁）的关系被主动设计，而非被动包裹。
18. 造价分级：门厅等重点区高完成度，辅助区低完成度，界面不打架。
19. 方案中不出现无法落地的"效果图专属"造型。
20. 平面、天花、地花、立面四张图在同一版本上协调一致。
21. 每个主要房间有一句可判定的设计目标（不是形容词）。
22. 材质样板的编号与图纸标注一一对应。
23. 方案考虑了使用中的可变性（可移动家具、可更换软装）。
24. 应急与检修需求（消防栓、配电箱、检修口）不被永久构件遮挡。
25. 与结构柱、剪力墙的关系通过包、露、借三种策略明确表态。
26. 室内平面预留了设备与管井检修的可达路径。
27. 界面造型与结构梁位、柱位的关系已被主动协调。
28. 主要房间的照度与色彩在同一设计意图下统一。
29. 方案中对"可变区域"与"固定区域"有明确区分。
30. 交付图册中每个空间均可被现场工人独立理解并施工。

## 数值与区间

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 室内净高（办公开放区） | 2.6–3.0 m | 吊顶后净高 |
| 室内净高（住宅起居） | 2.6–2.9 m | 视层高与机电 |
| 室内净高（酒店客房） | 2.5–2.7 m | 含走廊吊顶 |
| 室内净高（商业首层） | 3.3–4.2 m | 可局部通高 |
| 隔墙厚度（轻钢龙骨） | 75–150 mm | 含饰面 |
| 隔墙厚度（砌块） | 100–200 mm | 视隔声要求 |
| 地面完成面厚度 | 30–80 mm | 石材/瓷砖含找平 |
| 架空地板高度 | 100–300 mm | 办公常用 |
| 踢脚高度 | 60–120 mm | 与材质收口相关 |
| 天花跌级高度差 | 100–300 mm | 藏灯槽与风管 |
| 门洞净宽（住宅内） | 800–900 mm | 以规范与功能为准 |
| 通道净宽（室内） | 900–1200 mm | 主要动线取高值 |
| 家具间距（沙发到茶几） | 300–450 mm | 活动尺度 |
| 家具间距（餐椅后通道） | 750–900 mm | 便于起坐 |
| 墙面瓷砖常用规格 | 300×600 / 600×600 mm | 视缝与排版 |
| 地面石材常用规格 | 600×600 / 800×800 mm | 视板块与排版 |
| 木饰面厚度 | 3–18 mm（贴面/板） | 视基层与造型 |
| 吸声材料 NRC | 0.4–0.9 | 视空间声学需求 |

## 常见错误

- 概念阶段只谈"感觉"，不落功能与尺度。
- 天花造型与灯具、风口、喷淋、烟感打架，后期开洞补救。
- 界面收口靠"打胶解决"，缺乏构造逻辑。
- 材质样板与图纸编号不一致，施工阶段选错材料。
- 门厅堆砌高完成度、走廊草率处理，视觉跳变。
- 只做平面对称，忽略实际使用人数与家具尺度。
- 消防设施被造型遮挡，验收阶段被迫拆除。
- 灯光位置在造型确定后才考虑，被迫牺牲照明质量。
- 软装与硬装风格割裂，最终靠摆件"救场"。
- 忽略声学，导致开放办公与会议互相干扰。
- 无障碍只在图纸注释，未落到净宽与门槛处理。
- 高差处理无做法，施工随意加台阶。
- 可开启柜门与设备检修口被布置的家具堵死。
- 变更多次后，平、天、地、立四图版本失控。
- 用"高级灰""性冷淡"等词替代色彩体系说明。
- 忽略后期运维与清洁，选不耐污材质。

## 与其它领域的接口

- 与 `architectural-design-principles`：接收建筑壳体与柱网；回传室内界面与功能调整需求。
- 与 `spatial-planning`：接收房间划分；回传室内动线与家具布置约束。
- 与 `human-ergonomics`：输出界面与家具意向；接收净尺寸与活动尺度校核。
- 与 `material-and-finish-selection`：输出材质基调；接收具体材料、规格与工艺。
- 与 `lighting-design`：输出天花与界面条件；接收照度、色温与灯具布置。
- 与 `building-systems-coordination`：输出吊顶最低标高要求；接收风管、水管、桥架占位。
- 与 `construction-detailing`：输出收口意向；接收节点大样与基层做法。
- 与 `cad-drawing-standards`：输出平天立地四图；接收图层、标注与图框规范。
- 与 `design-review-checklists`：室内方案在提交前逐条对照评审。

## 分阶段应用

- S1：解读室内任务书，区分"必需功能"与"期望氛围"。
- S2：提出 2–3 个室内概念方向，比较功能匹配度与造价。
- S3：落实室内平面，验证动线、功能与尺度。
- S4：深化界面、天花、色彩、材质，形成可施工方案。
- S6：与机电、照明、软装协调，锁定版本。
- 各阶段均需维护"平天立地"四图同步，避免版本漂移。

## 典型权衡与取舍

- 净高 vs 造型：跌级天花造型漂亮，但压缩净高。
- 材质档次 vs 造价：高完成度区域越集中，整体成本越可控。
- 风格纯度 vs 功能：为风格牺牲储物或通行，长期体验差。
- 开放式布局 vs 声学私密：越开放越需声学补偿。
- 可变性 vs 确定性：越可变更，初期投入越高。
- 维护成本 vs 初装成本：耐污耐损材质初期贵、长期省。

## 输出物与数据格式

- 室内平面布置图（家具 + 尺寸，单位 mm）。
- 天花布置图（标高、造型、灯位、风口）。
- 地面铺装图（材质分区 + 排版起点）。
- 主要立面展开图（界面 + 材质编号）。
- 材质样板表（编号 + 名称 + 规格 + 部位）。
- 色彩体系说明（主色/辅色/点缀色 + 应用部位）。

## 风险与不确定性

- 业主审美偏好主观且易变，需以功能为锚定。
- 建筑壳体若滞后，室内方案可能被迫返工。
- 机电点位若未协同，天花与灯具布置会失效。
- 材料供货与价格波动影响选型落地。
- 施工工艺水平影响收口质量，需在节点中预留容差。
- 以上风险应显式记录在方案说明中。

## 术语与口径

- **界面**：顶、地、墙三类完成面的统称。
- **收口**：两种材料或两个界面相交处的处理方式。
- **跌级**：天花标高的变化层次。
- **四图**：平面、天花、地面、立面的合称。
- **完成度分级**：按重要性与成本对区域分级。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地现行规范"这一约束来源。
- 防火分区、疏散、无障碍、室内环境污染控制等要求应转成"待本地复核项"。
- 规范对材料燃烧性能、环保等级有要求时，选型须以合规为前提。
- 涉及安全与合规的最终判定，一律交由持证专业人员签署。

## 常见问答式判断

- 问：这个造型能落地吗？答：先确认基层、收口与机电预留是否可行。
- 问：净高够不够？答：按最不利点算造型+机电后再答。
- 问：能不能不做吊顶？答：看机电暴露是否可接受与检修是否方便。
- 问：色彩能不能再大胆？答：看功能属性与使用时长对心理的影响。
- 问：软装能不能后期补？答：硬装阶段须先预留点位与尺度。
- 以上问答用于快速暴露缺失信息，而非替代专业判断。

## 设计意图的表达规范

- 每个空间用一句可判定的目标描述，而非形容词。
- 平、天、地、立四图须能相互印证同一意图。
- 材质、色彩、照明三者在同一叙事下统一。
- 造型变化须能说明其功能或结构原因。
- 重要界面给出放大或展开图。
- 变更须同步更新全部相关图纸与说明。

## 检查清单

- [ ] 室内平面每道隔墙都有功能目的。
- [ ] 动线入口出口清晰，无回头路。
- [ ] 界面相交处均有收口做法。
- [ ] 天花变化处收口与造型意图一致。
- [ ] 净高扣除机电与造型后满足底线。
- [ ] 视觉焦点与功能点不冲突。
- [ ] 通道与停留区地面有区分。
- [ ] 色彩基调与功能匹配且有体系说明。
- [ ] 家具布置满足活动尺度与通行宽度。
- [ ] 软装与硬装无视觉争夺。
- [ ] 灯位在概念阶段已与天花协调。
- [ ] 所有柜门与检修口布置后可开启。
- [ ] 高频区采用耐污耐磨材质。
- [ ] 室内高差均有明确做法。
- [ ] 声学敏感空间有吸声策略。
- [ ] 消防设施未被造型永久遮挡。
- [ ] 平天立地四图同版本一致。
- [ ] 材质样板编号与图纸对应。
- [ ] 方案保留必要的可变性。
- [ ] 主要房间设计目标均以可判定语句表达。
- [ ] 室内高差与门槛处理已落到专项做法。
- [ ] 设备检修路径未被永久构件封堵。
- [ ] 软装点位在硬装阶段已预留。
