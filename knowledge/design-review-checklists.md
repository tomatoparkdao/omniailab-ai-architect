# 设计评审清单

设计评审清单是质量控制的操作系统。它把分散在各领域的判据收拢为"按阶段、按对象、可勾选"的检查项，用于在提交前发现问题、在评审中统一口径、在交付前锁定成果。本领域不产生新设计，只负责判定既有设计是否达标。

本领域给出的是**通用评审要点与判定口径**，不替代合规审查。涉及结构、消防、无障碍、机电负荷的结论，须由持证专业人员在项目所在地复核签署。

## 适用范围与边界

- 适用：各阶段设计自检、内部评审、向业主提交前检查、交付前验收。
- 适用：S1 任务书评审、S4 方案深化评审、S6 定稿评审、S8 交付评审。
- 不适用：替代法定审查与专业签署。
- 不适用：产生设计方案。
- 边界：评审结论分"通过、有条件通过、退回"，须写明理由与责任方。
- 边界：评审项应可判定，避免"感觉不对"这类无效结论。

## 核心判据

1. 每项评审意见都能指向具体图纸、构件或数值。
2. 评审结论分档明确（通过/有条件通过/退回）。
3. 退回项必须给出可执行的修改方向。
4. 评审覆盖功能、规范、造价、可实施性四个维度。
5. 评审记录包含版本号与时间，可追溯。
6. 未决项在评审中显式列出并指定决策人。
7. 评审不放过"图上有、说明无"的不一致。
8. 评审不放过"说明有、图上无"的不一致。
9. 安全相关项一律标注待专业复核，不由设计单方判定。
10. 评审对跨专业接口重点检查。
11. 评审检查各专业图纸版本一致性。
12. 评审检查材料表、图纸、样板三方一致。
13. 评审检查净高在最不利点是否成立。
14. 评审检查疏散与无障碍路径在图上连续。
15. 评审检查造价指标与方案完成度匹配。
16. 评审检查机房、管井等负空间是否落位。
17. 评审检查末端点位是否统一排布。
18. 评审检查构造节点是否齐全。
19. 评审检查制图标准执行情况。
20. 评审检查模型与图纸是否同源。
21. 评审后形成整改清单并跟踪闭环。
22. 评审发现的问题按严重度分级。
23. 评审对重复出现的问题上升为流程改进项。
24. 评审结论须经相关专业会签。
25. 评审不因进度压力跳过安全项。
26. 评审记录归档，供后续阶段引用。
27. 每次评审聚焦"本轮变更"与"上轮遗留"。
28. 评审对"看起来没问题"的地方抽样复核。
29. 评审的通过不等于合规，须以专业复核为准。
30. 所有安全与合规结论均标注待持证专业人员复核签署。

## 数值与区间

以下均为**常见评审判据区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 项目 | 常用判据 | 说明 |
|---|---|---|
| 净高（办公） | ≥2.6 m | 吊顶后，视规范 |
| 净高（走廊） | ≥2.3 m | 视管线 |
| 走廊净宽 | ≥1.5 m | 按人流与规范 |
| 房间面积偏差 | 与任务书 ≤5% 可解释 | 视项目 |
| 疏散距离 | 连续无回头路 | 最终以规范为准 |
| 无障碍净宽 | 连续一致 | 最终以规范为准 |
| 管井尺寸 | 满足立管+检修 | 视立管数 |
| 机房检修通道 | ≥700 mm | 视设备 |
| 材料三方一致 | 表/图/样板一致 | 无例外 |
| 图纸版本一致 | 全专业同版本 | 无例外 |
| 碰撞记录 | 已执行且有报告 | 无例外 |
| 未决项数量 | 提交前应清零或明确 | 视阶段 |
| 退回项闭环率 | 100% | 无例外 |
| 重难点专项 | 独立评审 | 视项目 |

## 常见错误

- 评审意见笼统，无法执行。
- 只审平面，不审天花、地面、立面。
- 忽略跨专业接口。
- 材料表、图纸、样板不一致未被发现。
- 净高只查典型处，不查最不利点。
- 疏散与无障碍只做图面标注，不查连续性。
- 造价与完成度不匹配未提出。
- 机房与管井未落位却通过评审。
- 末端点位杂乱未被指出。
- 构造节点缺失仍判定"基本可行"。
- 制图标准未执行却无人过问。
- 模型与图纸不同源未被发现。
- 退回项无责任人、无期限。
- 因进度压力跳过安全项。
- 评审记录缺失，无法追溯。
- 重复问题不上升为流程改进。

## 分阶段应用

- S1：评审任务书完整性与矛盾点。
- S4：评审方案深化与跨专业协调。
- S6：评审定稿一致性，重点查接口。
- S8：评审交付物完整性与一致性。
- 每次评审形成整改清单并跟踪闭环。

## 评审对象分组

- 空间组：功能、面积、流线、尺度。
- 界面组：天花、地面、墙面、收口。
- 材料组：选型、规格、样板、清单。
- 光环境组：照度、色温、控制。
- 机电组：净高、管井、末端、检修。
- 制图组：图层、标注、图框、版本。
- 模型组：精度、属性、碰撞、同源。
- 交付组：目录、格式、说明、维护。

## 典型权衡与取舍

- 评审严格 vs 进度：严格发现更多问题，进度压力大。
- 覆盖全面 vs 聚焦重点：全面易疲劳，聚焦易漏。
- 一次到位 vs 迭代：一次到位成本高，迭代易反复。
- 量化 vs 定性：量化可判定，定性易争议。
- 内部评审 vs 外部审查：内部快，外部权威。

## 输出物与数据格式

- 评审记录表（项目 + 阶段 + 版本 + 日期）。
- 问题清单（编号 + 描述 + 严重度 + 责任方 + 期限）。
- 结论页（通过/有条件通过/退回）。
- 整改闭环跟踪表。
- 流程改进项清单。

## 风险与不确定性

- 评审遗漏导致后期返工。
- 评审标准不统一导致结论争议。
- 跨专业信息不同步导致误判。
- 进度压力导致评审流于形式。
- 安全项被设计单方判定产生风险。
- 以上风险须通过分级评审与复核机制控制。

## 术语与口径

- **通过**：满足本阶段要求，可进入下一阶段。
- **有条件通过**：存在非阻断项，限期整改。
- **退回**：存在阻断项，须重新提交。
- **闭环**：问题整改并验证完毕。
- **未决项**：需外部决策的事项。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地现行规范"。
- 合规类结论一律转成"待专业复核项"。
- 评审发现与规范冲突时以合规优先。
- 涉及安全与合规的最终判定交由持证专业人员签署。

## 评审会议组织建议

- 评审前分发材料并标注重点，避免现场首次阅读。
- 明确评审范围与本轮重点，控制议程时长。
- 每个专业代表须能回答本专业问题。
- 现场记录问题编号，会后统一成整改清单。
- 争议项当场标注，不在会上陷入细节争论。
- 结论由主审汇总，相关专业会签。
- 会后限期反馈闭环，下一轮先查遗留项。
- 重复出现的问题上升为流程与培训改进项。

## 检查清单

- [ ] 任务书需求逐条可映射。
- [ ] 功能分区与平面一致。
- [ ] 公共与后勤流线无强制交叉。
- [ ] 每层最不利点净高成立。
- [ ] 房间面积与指标一致并有偏差说明。
- [ ] 家具与设备布置满足活动尺度。
- [ ] 疏散路径连续可读并标注待复核。
- [ ] 无障碍路径连续并标注待复核。
- [ ] 机房、管井、负空间已落位。
- [ ] 末端点位统一排布。
- [ ] 材料表、图纸、样板三方一致。
- [ ] 规格与排版起点明确。
- [ ] 收口节点齐全。
- [ ] 防水与湿区构造明确。
- [ ] 照度、色温、显色满足功能。
- [ ] 灯具点位与天花协调。
- [ ] 管线综合与天花图一致。
- [ ] 制图图层、标注、图框统一。
- [ ] 图纸版本全专业一致。
- [ ] 模型与图纸同源。
- [ ] 碰撞检查有记录。
- [ ] 未决项已列清单并指定决策人。
- [ ] 退回项已闭环。
- [ ] 所有安全与合规结论均标注须由持证专业人员复核签署。
