# AI 概念表现方法论

## 适用范围与边界

本领域解决一个具体问题：**平面方案确认之后、正式深化之前，怎么用 AI 生成一批能拿给业主看的概念效果图，并且不让这批图干扰后续的专业判断。**

三件事在本领域内：

1. 机位怎么定——从已确认的平面里取出哪些房间、站在哪里、看什么；
2. 提示词怎么写——把统一空间模型里的信息（面积、开间进深、材料、光线、视高）翻译成画面语言；
3. 迭代怎么管——改哪张、留哪张、什么时候整批重出。

三件事不在本领域内：

- **不做尺寸判断**。图像不承担任何比例与尺寸责任，任何"从效果图反推尺寸"的做法一律禁止；
- **不替代正式表现**。正式的、多视角一致的空间表现属于阶段 S5，由同一份锁定模型生成；本领域产出的是概念阶段的沟通材料；
- **不做材料样板认定**。图上看到的纹理、色号、拼缝都不是样板，不能据此下单。

一条根本区分：**概念效果图是"用来对齐感受"的，正式表现图是"用来确认结果"的。** 混用这两种用途，是概念阶段最常见的事故来源。

## 核心判据

1. 平面未通过门禁确认，不得出概念效果图——把未被批准的空间画漂亮，等于用图像替业主做决定。
2. 每一张图的机位必须能指向统一空间模型里的一个具体空间或整体轮廓，不出现"凭空多出来的房间"。
3. 同一批图必须来自同一次模型修订；修订号一变，整批作废重出，不允许新旧混用。
4. 参考图固定为同一份已确认平面，逐张换参考图会让画面之间失去共同依据。
5. 机位数量以"能讲清一个空间决策"为准，宁少勿滥；常规住宅第一批以整户型一张、主要空间各一张为宜。
6. 视高取人眼高度区间，不取上帝视角（整户型轴测除外）——视高错了，空间尺度感就假。
7. 镜头上限按画幅控制：常规视野用于读空间关系，超广角只在确实需要时使用，且不得用于表现细节。
8. 光线必须交代方向与色温，且同一批图共用一套光照假设，避免一张暖黄一张冷白。
9. 提示词里出现的材料名称必须与材料方案一致；图上出现了方案里没有的材料，这张图作废。
10. 迭代只改单张。用新的一批整体覆盖，会让同一批图的观感分裂。
11. 每张图都要能回答"依据是哪一次修订、哪一套平面、哪一条提示词"，提示词指纹必须随图留存。
12. 图上不得出现文字、水印、标识、人物——这些元素会掩盖空间问题，且无法在工程上核对。
13. 表现图的产出状态必须如实标注：已生成、待生成、失败，三态不得混淆；失败不能重试成"看起来成功"。
14. 任何一张概念效果图都不得成为后续专业判断的输入：几何、尺寸、材料用量、造价，全部以模型与清单为准。
15. 业主对图不满时，先判断是**感受问题**（换机位、换光线）、**表面问题**（换材质表达）还是**空间问题**（平面本身不成立）。第三类必须回到平面阶段，不能靠加一张图解决。

## 数值与区间

以下为**工程惯例区间**，用于给出一致的手感；不构成任何地区的法定或强制要求。具体项目应结合当地实践与持证专业人员意见调整。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 人眼视高（住宅） | 1400–1600 mm | 坐姿空间可略低，通高空间可略高 |
| 人眼视高（公共空间） | 1550–1700 mm | 高于住宅，强调开阔感 |
| 整户型轴测视点高度 | 0.6–0.9 倍最大平面尺寸 | 抬高俯视，去屋顶读关系 |
| 常规空间镜头 | 24–35 mm（等效） | 读空间关系与比例 |
| 细节镜头 | 50–85 mm（等效） | 读材质与收口，压缩感强 |
| 严格规避 | < 16 mm（等效） | 透视畸变明显，空间关系失真 |
| 画幅 | 16:10 或 3:2 | 横向构图利于表达水平主导线 |
| 光线色温（日间） | 5000–5600 K | 冷暖对比明显，材质本色可辨 |
| 光线色温（夜间） | 2700–3300 K | 需明确交代"发光的面" |
| 房间数量与机位比 | 3–5 个主要空间 → 4–6 张 | 不含整户型图 |
| 单批修订跨度 | 仅一次修订 | 跨修订混用即视为作废 |
| 迭代轮次 | 每机位 ≤ 3 轮 | 超出通常说明机位或平面本身有问题 |

## 常见错误

1. **先出图后补平面**：图很漂亮，但平面里没有这个空间。正确顺序是平面确认 → 出图。
2. **不指定视高与镜头**：模型自由发挥，同一批图尺度感互相矛盾。
3. **光线逐张变化**：没有统一光照假设，业主会以为设计在变。
4. **把效果图当作材料确认依据**：图上"看起来像"的材质与真实样板差别往往很大。
5. **用新一批图覆盖旧一批**：前几轮已经确认过的空间观感被抹掉，讨论失去基准。
6. **整体重出以解决单点不满**：成本高、观感分裂，且往往掩盖了真正的问题在平面。
7. **在图上生成文字与标注**：文字越像真的越危险——它不会被工程核对，却会被当成信息。
8. **失败当作成功**：提交失败后不记录原因、直接给一张降级图冒充成果。
9. **把概念效果图带入施工图讨论**：图纸与模型一旦以图为依据，尺寸链条就断了。
10. **过度依赖单张"神图"**：一张图的偶然性很高；能站住的是一批一致的图。

## 与其它领域的接口

| 交接对象 | 方向 | 交接内容 |
|---|---|---|
| `spatial-planning` | 输入 | 已确认方案的房间清单、面积、开间进深、动线关系 |
| `human-ergonomics` | 输入 | 视高、通行净宽、家具尺度（用于机位与画面合理性） |
| `material-and-finish-selection` | 双向 | 材料名称与色值进入提示词；图上的材质表现反过来提示选材方向 |
| `lighting-design` | 输入 | 光线方向、色温、发光面位置；图面光影须与照明方案一致 |
| `interior-design-methodology` | 输入 | 界面做法与主导线形态，决定构图与镜头取舍 |
| `design-review-checklists` | 输出 | 机位清单、状态清单、待整改项 |
| `design-presentation-methodology` | 输出 | 逐机位一页的汇报结构：图、模型、提示词摘要、状态 |
| `concept-design` | 双向 | 概念关键词进入提示词；图的反向反馈可用于校正概念方向 |
| `bim-modeling-principles` | 边界 | 明确图像不参与模型与构件信息 |

## 检查清单

- [ ] 平面方案门禁已确认，且确认人已记录
- [ ] 本批图统一标注模型修订号，且仅对应一次修订
- [ ] 参考图为同一份已确认平面，逐张一致
- [ ] 整户型机位已包含，且抬高俯视、去屋顶
- [ ] 每个机位都指向模型中真实存在的空间
- [ ] 视高在 1400–1600 mm（住宅）区间内，已逐位记录
- [ ] 镜头在 24–35 mm（常规）区间内，无低于 16 mm 的机位
- [ ] 光线方向与色温已统一，且与照明方案一致
- [ ] 提示词中的材料名称与材料方案逐项对应
- [ ] 负向提示词已包含：变形几何、错误透视、多余门窗、文字水印、人物
- [ ] 每张图的提示词指纹已留存
- [ ] 产出状态逐条标注（已生成 / 待生成 / 失败），无占位图
- [ ] 图上无文字、无标识、无人物
- [ ] 迭代轮次与改动点已记录，未使用整批覆盖
- [ ] 汇报文件已包含"非尺寸依据"声明页
- [ ] 已向业主说明：本批图为感受对齐材料，不是施工或采购依据
