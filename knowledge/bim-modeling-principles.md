# BIM 建模原理

BIM 建模原理定义"用三维数字模型承载设计信息"的规则。它强调模型不是效果图的附属品，而是信息的载体：几何、属性、关系三者统一。本领域约束建模精度、命名、参数、协同与交付，为施工图、工程量与运维提供一致的数据源。

本领域给出的是**常见建模惯例与精度分级**，不涉及结构计算与机电负荷。建模标准如委托方另有要求，以更严格者为准。

## 适用范围与边界

- 适用：模型精度分级、构件命名与参数、坐标与单位、协同方式、碰撞检查、模型交付。
- 适用：S5 三维模型建立、S7 施工图与模型出图。
- 不适用：结构分析与配筋模型。
- 不适用：机电系统计算。
- 边界：模型必须与图纸、材料表保持一致，不得各说各话。
- 边界：建模深度按用途分级，不盲目追求高精度。

## 核心判据

1. 模型单位与坐标系统全项目统一。
2. 模型原点唯一且有明确设定。
3. 构件按统一的命名与分类规则建立。
4. 模型精度分级与项目阶段匹配。
5. 每个构件带有可查询的属性（类型、材料、编号）。
6. 模型与图纸版本同源，无双重维护。
7. 楼层标高与轴网在模型中准确建立。
8. 构件之间不出现无意义的几何穿插。
9. 模型可用于生成平面、剖面与明细表。
10. 空间（房间）在模型中已划分并命名。
11. 门窗等构件参数化，可统计数量与规格。
12. 模型中的材料信息与材料表一致。
13. 机电与建筑模型在同一坐标系下协同。
14. 碰撞检查已执行并留有记录。
15. 模型的详细程度与使用目的匹配，无冗余。
16. 模型文件命名与版本规则统一。
17. 模型可被第三方软件正常打开与量取。
18. 模型中的错误与待定项有标注。
19. 模型更新后相关图纸与明细自动同步。
20. 模型的几何精度满足出图与量算要求。
21. 协同过程中不同专业模型的合模流程明确。
22. 模型的构件来源（专业、作者）可追溯。
23. 不滥用高面数几何导致文件沉重。
24. 模型交付前完成几何与信息检查。
25. 模型中的注释与说明规范统一。
26. 模型的视图与图册设置统一。
27. 模型的变更记录可追溯。
28. 模型用于工程量统计时，口径与算量规则一致。
29. 涉及安全的构件信息标注待专业复核。
30. 模型交付格式与用途匹配。

## 数值与区间

以下均为**常见建模惯例与精度分级**，非强制标准，须以项目所在地或委托方建模标准为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 模型单位 | mm | 与制图一致 |
| 坐标精度 | 0.1 mm | 几何建模 |
| 精度等级 LOD100 | 体量概念 | 面积体块 |
| 精度等级 LOD200 | 方案级 | 主要构件 |
| 精度等级 LOD300 | 施工图级 | 精确尺寸 |
| 精度等级 LOD350 | 深化级 | 含接口 |
| 精度等级 LOD400 | 加工级 | 含制造信息 |
| 文件大小（单层参考） | 数十至数百 MB | 视复杂度 |
| 合模频率 | 每日或每周 | 视协同强度 |
| 碰撞容差 | 按净空要求 | 视系统 |
| 模型命名分隔符 | 统一符号 | 如短横线 |
| 视图命名 | 按图种 | 平/剖/详 |
| 明细表字段 | 编号/名称/规格/数量 | 统一 |
| 模型轴网间距 | 与建筑一致 | 单位 mm |
| 修订标记 | 版本号+日期 | 可追溯 |

## 常见错误

- 单位或坐标不统一，合模错位。
- 构件命名随意，无法统计与筛选。
- 精度超标或不足，与用途不匹配。
- 模型与图纸各改各的，版本不一致。
- 轴网与标高建立错误，出图整体偏移。
- 构件几何穿插未清理，量算失真。
- 房间未划分，面积统计无法进行。
- 门窗未参数化，数量统计靠人工。
- 材料信息与材料表脱节。
- 机电未协同，碰撞无记录。
- 模型文件命名混乱，版本失控。
- 高面数构件拖慢协同效率。
- 模型无法被其他软件打开。
- 待定项未标注，下游误用。
- 变更后未更新，模型变成"历史文件"。
- 交付模型缺信息，无法用于运维。

## 分阶段应用

- S5：建立方案级模型，验证体量与空间。
- S7：深化到施工图级，出图并统计工程量。
- 各专业按合模流程定期协同。
- 模型变更须重新校核碰撞与净高。
- 交付前完成模型检查与信息补全。

## 典型权衡与取舍

- 建模深度 vs 效率：越深越准，也越慢。
- 信息丰富 vs 维护成本：信息多，维护负担大。
- 单一模型 vs 多模型：单一便于一致，多模型便于分工。
- 精确几何 vs 文件性能：越精确越重。
- 自动化出图 vs 人工校核：自动高效，仍需人工复核。

## 输出物与数据格式

- 建筑/结构/机电模型文件。
- 模型精度说明与用途。
- 构件命名与属性字典。
- 碰撞检查报告。
- 明细表（门窗、房间、材料）。
- 模型交付清单与格式说明。

## 风险与不确定性

- 各专业建模标准不统一。
- 软件版本与格式兼容问题。
- 模型过大影响协同效率。
- 信息缺失导致运维阶段无法使用。
- 变更未同步引发图纸与模型矛盾。
- 以上风险须在建模标准与协同计划中覆盖。

## 术语与口径

- **BIM**：建筑信息模型（Building Information Modeling）。
- **LOD**：模型详细程度分级。
- **合模**：多专业模型整合到一个坐标系。
- **碰撞**：不同专业构件空间冲突。
- **族/构件类型**：可复用的参数化对象。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地或委托方建模标准"。
- 若委托方有 BIM 执行计划，以其为准。
- 建模标准与制图标准冲突时，以保证图纸可读性优先。
- 涉及交付合规的要求交由项目负责人确认。

## 常见问答式判断

- 问：模型要多精细？答：按用途选 LOD 等级。
- 问：能不能不建模？答：看是否需要统计与协同。
- 问：模型和图纸谁为准？答：须同源，不一致即为缺陷。
- 问：碰撞要不要查？答：需要，且须留记录。
- 问：交付什么格式？答：按接收方要求，兼顾原生与开放格式。
- 以上问答用于保证模型一致性。

## 建模流程

1. 建立统一轴网、标高与坐标原点。
2. 确定精度等级与用途，编写建模约定。
3. 按"先结构、后建筑、再机电"顺序建模。
4. 划分房间与空间，赋予名称与用途。
5. 赋予构件属性（材料、编号、类别）。
6. 定期合模并执行碰撞检查。
7. 从模型派生平面、剖面与明细表。
8. 变更后同步更新并重新校核。
9. 交付前进行几何与信息双重检查。
10. 形成模型交付说明与使用指引。
