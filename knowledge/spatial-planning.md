# 空间规划

空间规划把建筑的功能意向落成具体的房间、面积与动线。它是方案阶段密度最高的判断领域，直接决定使用的便利性、运营效率与后续所有专业的工作量。空间规划的输出是平面，但它的本质是"把人、物、时间三者在二维平面上排好队"。

本领域输出的是**平面逻辑与校核框架**，不是最终施工图。凡涉及疏散、无障碍、结构可行性的最终结论，须由持证专业人员在项目所在地复核签署。

## 适用范围与边界

- 适用：功能气泡图、房间面积分配、主流线与辅助流线、开间进深控制、家具与设备占位。
- 适用：S3 平面方案、S4 方案深化、S5 三维表现前的平面锁定。
- 不适用：结构跨度与配筋、防火分区的最终划分、机电末端定位。
- 不适用：立面与造型（见 `architectural-design-principles`）。
- 边界：面积指标由任务书与当地规范共同约束，本领域只负责"指标与平面一致"。
- 边界：涉及人流的绝对容量计算须由专业工程师复核。

## 核心判据

1. 每个房间有明确的功能命名，无"多功能房"这类无约束空间。
2. 每个房间的面积与任务书指标偏差在可解释范围内。
3. 主入口到主要功能点的路径最短且不需穿越服务区。
4. 后勤、货运、垃圾流线与客流无强制交叉。
5. 每个房间至少一面临外墙或采光井（有采光需求者）。
6. 房间进深与面宽比例合理，不出现狭长无用空间。
7. 门的位置不阻碍家具布置与主要动线。
8. 窗与家具布置不冲突（床头、办公桌、操作台）。
9. 强弱电、给排水点位与房间功能匹配。
10. 竖向交通（楼梯、电梯）与人口密度匹配。
11. 卫生间数量与使用人数匹配（详见 `human-ergonomics`）。
12. 储藏空间按功能类型分类设置，非集中堆放。
13. 设备机房面积与设备清单匹配，且位置便于检修。
14. 管井位置上下贯通，避免标准层错位。
15. 结构柱不落在主要功能布置区或主通道居中位置。
16. 每个房间的疏散路径连续、可读（最终合规待专业复核）。
17. 无障碍路径在平面连续且宽度一致（待专业复核）。
18. 平面预留了扩租、改造或功能置换的接口。
19. 交通面积与使用面积之比在同类项目合理区间。
20. 平面的模数化程度支持后续施工与家具采购。
21. 公共区与私密区的过渡有缓冲，不是硬性切换。
22. 每个功能区的家具清单可列出，非"布置留白"。
23. 平面在同样面积下提供至少两个方案比较。
24. 主要功能房间的采光、通风、噪声三项均被评估。
25. 人流高峰（如出入口、电梯厅）的瞬时拥堵已被考虑。
26. 平面与天花、地面铺装的开分关系在方案阶段已可追溯。
27. 平面中没有"死角空间"（进不去、用不上、放不了家具）。
28. 各功能区之间噪声敏感度分级明确（静—半静—闹）。
29. 平面标注了全部门窗洞口与开启方向。
30. 平面达到了"可被施工方标注尺寸并施工"的完成度。

## 数值与区间

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 住宅起居室面积 | 18–30 m² | 视户型与人数 |
| 住宅主卧面积 | 12–18 m² | 含家具布置余量 |
| 住宅次卧面积 | 8–12 m² | 单人次卧下限 |
| 住宅厨房面积 | 6–10 m² | 视操作布局 |
| 住宅卫生间面积 | 4–8 m² | 视洁具数量 |
| 办公工位面积 | 6–10 m²/人 | 含通道与家具 |
| 办公会议室面积 | 按 1.5–2.5 m²/人 | 视桌型 |
| 商业店铺进深 | 8–20 m | 视业态 |
| 餐厅客位面积 | 1.2–2.0 m²/座 | 视档次 |
| 教室面积 | 1.2–1.5 m²/生 | 视学段 |
| 客房净面积 | 18–32 m² | 视星级 |
| 交通面积占比（办公） | 20%–30% | 与核心筒相关 |
| 走廊净宽 | 1.5–2.4 m | 按人流 |
| 单人通行净宽 | 600–750 mm | 尺度过窄不适 |
| 双人并行净宽 | 1200–1500 mm | 主通道 |
| 门洞净宽（房间） | 800–1000 mm | 视功能 |
| 卫生间洁具间距 | 中心距 750–900 mm | 视类型 |
| 储物间进深 | 600 mm 起 | 与柜体模数 |
| 停车位尺寸 | 2.4×5.3 m 起 | 以规范为准 |
| 电梯厅进深 | 1.8–2.4 m | 视梯型 |

## 常见错误

- 只做概念气泡图，不落具体家具与尺寸。
- 房间面积与任务书对不上，却无解释。
- 流线在图上"看起来不交叉"，实际使用时段冲突。
- 门开在角落，家具布置被迫将就。
- 窗户位置与功能布置冲突（床头对窗、镜对窗等）。
- 卫生间数量不足，高峰排队。
- 储藏按总面积摊派，未按功能分类。
- 机房位置无检修通道，设备进不去。
- 管井上下不对位，标准层被迫局部降板。
- 柱网与房间划分对不上，出现半柱半墙。
- 交通面积过大，看似气派实为浪费。
- 平面模数混乱，施工与家具采购成本上升。
- 静闹区混杂，会议室紧邻开放办公。
- 平面留白多，家具清单无法生成。
- 只出一个方案，未做对比论证。
- 无障碍图纸上标注合规，实际宽度不连续。

## 与其它领域的接口

- 与 `architectural-design-principles`：接收分区与体量；回传房间划分与流线细化结果。
- 与 `human-ergonomics`：输出房间尺寸；接收人体活动尺度与洁具间距校核。
- 与 `interior-design-methodology`：接收室内界面需求；回传平面动线约束。
- 与 `lighting-design`：输出功能分区；接收各区分区照明预设。
- 与 `building-systems-coordination`：输出机房与管井位置；接收管井尺寸与检修要求。
- 与 `construction-detailing`：接收构造做法对平面净尺寸的反馈。
- 与 `bim-modeling-principles`：输出房间边界数据；接收模型空间划分校验。
- 与 `cad-drawing-standards`：输出平面 CAD 图层与标注要求。
- 与 `design-review-checklists`：平面提交前逐条对照评审。
- 与 `design-presentation-methodology`：以"分区—流线—指标"表达平面结论。

## 分阶段应用

- S3：从气泡图进入平面，验证功能与流线，做至少两方案对比。
- S4：结合结构、机电、界面锁定房间净尺寸。
- S5：平面数据作为三维建模的基准，禁止在模型里改平面逻辑。
- 每次平面调整后须重新校核面积指标与流线。
- 平面锁定后才允许进入立面与表现深化。

## 典型权衡与取舍

- 房间数量 vs 单间面积：细分越多，单间越局促。
- 交通面积 vs 使用面积：走廊越宽越舒适，得房率越低。
- 集中机房 vs 分散机房：集中检修方便，但管道长、占净高。
- 模数统一 vs 个性化布局：统一利于施工，个性利于体验。
- 采光面分配 vs 功能优先级：采光最佳面应给使用时长最长的房间。
- 可变性 vs 当期效率：预留改造弹性会牺牲当期使用密度。

## 输出物与数据格式

- 功能气泡图（功能块 + 关系连线 + 权重）。
- 平面布置图（墙体 + 门窗 + 家具 + 尺寸，单位 mm）。
- 面积指标表（房间名 + 面积 + 与任务书偏差）。
- 流线分析图（四类流线分色）。
- 家具清单（房间 + 家具名 + 规格 + 数量）。
- 方案对比表（两方案的优劣与代价）。

## 风险与不确定性

- 任务书面积指标可能存在内部矛盾，须先澄清。
- 结构条件未知时，柱网假设可能被推翻。
- 机电占位未知时，净尺寸可能缩水。
- 业主使用习惯差异导致流线评价主观。
- 功能置换（如办公改公寓）会重塑全部平面逻辑。
- 以上风险应显式列出并标注假设。

## 术语与口径

- **气泡图**：用图形表达功能关系与权重的前平面工具。
- **动线**：使用者移动路径。
- **面积指标**：任务书或规范要求的面积分配。
- **得房率**：使用面积与建筑面积之比。
- **模数**：平面尺寸统一采用的基准单位。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地现行规范"。
- 疏散距离、无障碍净宽、防火分区等约束应转成"待本地复核项"。
- 规范冲突时以更严格者为准，并标注冲突点。
- 涉及安全的最终判定交由持证专业人员签署。

## 常见问答式判断

- 问：这个房间够大吗？答：按家具清单与活动尺度摆放后再答。
- 问：走廊能不能窄一点？答：看人流峰值与无障碍要求。
- 问：能不能多隔一间？答：看采光、通风与疏散是否仍成立。
- 问：机房能不能挪到角落？答：看检修通道与管井对位。
- 问：能不能开放式？答：看声学敏感度与运营模式。
- 以上问答用于暴露缺失信息，不替代专业计算。
