# 照明设计

照明设计既是技术，也是氛围工具。它决定空间能否被正确看见，也决定空间的情绪。本领域把自然光与人工光统一到同一套策略中，输出照度、色温、显色、灯具布置与控制方式的可执行判据。

本领域给出的是**常见照度与参数区间**，不是法定强制值。应急照明、疏散照明、消防应急电源等合规要求，须以项目所在地现行规范与持证专业人员复核为准。

## 适用范围与边界

- 适用：照度标准、色温、显色指数、灯具选型与布置、自然光利用、照明控制与场景。
- 适用：S4 照明策略、S5 表现阶段的光效设定、S6 定稿与灯具点位协调。
- 不适用：电气负荷计算与配电（见 `building-systems-coordination`）。
- 不适用：应急照明的合规结论。
- 边界：灯具品牌与型号由采购决定，本领域给性能参数要求。
- 边界：自然光策略与建筑朝向强相关，须与建筑专业协同。

## 核心判据

1. 每个功能空间有明确的照度目标值。
2. 照度均匀度满足空间使用需求，避免明暗过度跳跃。
3. 色温与空间功能及使用时段匹配。
4. 显色指数满足对色彩辨识的要求（如化妆、试衣、餐饮）。
5. 眩光被控制，主要视线方向无裸露高亮光源。
6. 灯具布置与天花造型、风口、喷淋、烟感协调。
7. 自然光与人工光的过渡方式已定义（感应、恒照度、时序）。
8. 主要工作面照度而非仅地面照度被校核。
9. 立面与重点陈设有专门的洗墙或重点照明。
10. 通道与台阶有引导照明，避免暗区。
11. 控制方式按区域、按场景划分，不"一开全开"。
12. 灯具维护更换的可达性已考虑。
13. 灯具的防护等级与使用环境匹配（潮湿、室外）。
14. 光源的色容差被控制，同空间色温一致。
15. 屏显区域避免灯具在屏幕形成反射眩光。
16. 卧室、酒店等空间的照明支持睡前低照度模式。
17. 办公区域照度满足长时间阅读与屏幕使用。
18. 重点照明的照度比（重点区:环境区）合理。
19. 照明的能耗策略与节能目标一致。
20. 自然采光不足的空间有补光方案。
21. 灯具的嵌入深度与吊顶厚度匹配。
22. 灯带、洗墙等线性照明的连续性无断裂。
23. 照明场景数量与运营需求匹配。
24. 灯具清单可列出（型号参数、功率、光通量）。
25. 效果图光效与施工图灯具点位一致。
26. 照明与材料的反射率、纹理配合，不"洗掉"材质质感。
27. 关键区域的照明有备用或分区冗余。
28. 照度的计算依据与假设已说明。
29. 室外与景观照明的光污染已考虑。
30. 所有应急与安全照明结论均标注待专业复核。

## 数值与区间

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 办公一般照明照度 | 300–500 lx | 视精细度 |
| 办公精细作业 | 500–750 lx | 局部补充 |
| 会议室照度 | 300–500 lx | 可调光 |
| 教室照度 | 300–500 lx | 黑板另设 |
| 住宅起居照度 | 100–300 lx | 氛围为主 |
| 住宅阅读照明 | 300–500 lx | 局部 |
| 厨房操作台照度 | 300–500 lx | 台面 |
| 卫生间照度 | 150–300 lx | 镜前另设 |
| 商业陈列照度 | 500–1000 lx | 重点照明 |
| 酒店客房照度 | 100–300 lx | 分场景 |
| 走廊照度 | 100–200 lx | 引导为主 |
| 车库照度 | 50–100 lx | 以规范为准 |
| 色温（办公） | 4000–5000 K | 中性偏冷 |
| 色温（住宅） | 2700–3500 K | 暖光 |
| 色温（商业） | 3000–4000 K | 视业态 |
| 显色指数 Ra | ≥80 一般，≥90 精细 | 视用途 |
| 重点与环境照度比 | 3:1 – 5:1 | 层次感 |
| 眩光控制 UGR | ≤19 办公 | 越低越舒适 |
| 灯具功率密度 | 按节能要求 | 以规范为准 |
| 线性灯带间距 | 视光通量 | 保证连续 |

## 常见错误

- 只有平均照度，无均匀度与工作面照度。
- 色温混用，同一空间冷暖不均。
- 显色指数不足，餐饮、试衣颜色失真。
- 眩光明显，灯具裸露出光面朝视线。
- 灯位与风口、喷淋打架，后期移位。
- 自然光与人工光无过渡，白天过亮夜间过暗。
- 只做地面照度，忽略桌面与墙面。
- 通道与台阶无引导照明，存在安全隐患。
- 控制简单，"一开全开"，无法分场景。
- 灯具嵌入深度大于吊顶厚度，装不进去。
- 灯带断裂，连续性差。
- 效果图光效与施工图点位不符。
- 洗墙灯把材质质感"洗平"。
- 忽略维护可达性，坏灯无法更换。
- 室外照明造成光污染。
- 应急照明靠猜设定，未复核。

## 与其它领域的接口

- 与 `architectural-design-principles`：接收朝向与采光面；回传自然光与人工光比例策略。
- 与 `interior-design-methodology`：接收天花与界面；回传照度、色温与灯具布置。
- 与 `material-and-finish-selection`：接收材料反射率；回传照明对材质表现的影响。
- 与 `building-systems-coordination`：接收电气容量与回路；回传照明负荷需求。
- 与 `construction-detailing`：输出灯具安装节点要求。
- 与 `bim-modeling-principles`：输出灯具族信息与点位。
- 与 `cad-drawing-standards`：输出灯具点位与回路标注规范。
- 与 `design-review-checklists`：照明方案纳入评审。
- 与 `design-presentation-methodology`：以"光效场景对比"表达照明结论。

## 分阶段应用

- S4：制定照明策略与照度目标。
- S5：在效果图中设定光效与色温，验证氛围。
- S6：协调灯具点位与控制方式，锁定回路。
- 照明变更须同步更新点位图与灯具清单。
- 应急照明须独立复核，不纳入常规流程。

## 典型权衡与取舍

- 照度充足 vs 能耗：越亮越费电。
- 氛围感 vs 功能性：氛围灯不足以支撑作业照度。
- 重点照明 vs 均匀照明：重点出层次，均匀保舒适。
- 灯具数量 vs 天花整洁：灯越多天花越碎。
- 色温统一 vs 场景变化：统一简单，变化灵活。
- 自然采光 vs 热负荷与眩光：进光多可能过热过亮。

## 输出物与数据格式

- 照度标准表（空间 + 照度 + 色温 + 显色）。
- 灯具点位图（符号 + 编号 + 回路）。
- 灯具清单（编号 + 参数 + 功率 + 光通量）。
- 照明控制表（回路 + 场景 + 控制方式）。
- 效果图光效设定说明。
- 应急照明需求清单（待复核）。

## 风险与不确定性

- 灯具参数与实物有偏差。
- 显色与色温在现场受材料反射影响。
- 自然光随季节与天气波动。
- 控制方案与运营模式不匹配。
- 能耗要求可能收紧。
- 以上风险须在照明说明中标注。

## 术语与口径

- **照度（lx）**：单位面积接受的光通量。
- **色温（K）**：光的冷暖程度。
- **显色指数（Ra）**：还原物体真实颜色的能力。
- **眩光（UGR）**：造成视觉不适的强光干扰。
- **均匀度**：最小照度与平均照度之比。
- 上述口径跨文档统一使用。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地现行规范"。
- 应急照明、疏散照明、节能功率密度等应转成"待本地复核项"。
- 规范与设计冲突时以合规优先。
- 涉及电气与安全的最终判定交由持证专业人员签署。

## 常见问答式判断

- 问：这里够亮吗？答：按工作面照度与均匀度校核。
- 问：能不能只做氛围灯？答：看是否有作业或精细识别需求。
- 问：色温要不要统一？答：同一空间内应统一，避免视觉杂乱。
- 问：灯能不能少一点？答：看均匀度与眩光是否仍可接受。
- 问：能不能不用应急灯？答：应急要求属强制范畴，须复核。
- 以上问答用于暴露缺失信息，不替代专业判定。

## 照明场景控制建议

- 按空间划分回路，避免全区分组开关。
- 常见场景可分为：日常、会客、清洁、夜间。
- 可调光灯具宜集中控制，减少面板数量。
- 感应与定时控制适用于走廊与卫生间。
- 自然采光充足区域宜设恒照度控制。
- 场景设定须与运营方确认使用习惯。
- 控制面板位置在平面图上明确标注。
