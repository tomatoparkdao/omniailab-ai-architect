# 建筑设计原理

建筑设计原理是"总设计师"在方案阶段对全局负责的判断依据。它回答的不是"好不好看"，而是"这个方案在功能、场地、法规、造价、可实施性四个维度上是否自洽"。本领域为空间规划、结构、机电、构造提供上游约束，是所有下游领域的约束来源。

本领域的输出是**设计意图与判断框架**，不是法定条文。凡涉及安全、消防、无障碍、机电负荷的最终结论，须由持证专业人员在项目所在地复核签署。

## 适用范围与边界

- 适用：方案阶段的总体构思、功能分区、流线组织、形体逻辑、场地回应、朝向与日照策略、体量关系判断。
- 适用：S1 任务书解读、S2 概念生成、S3 平面方案、S4 初步设计与方案深化中的建筑层面决策。
- 不适用：结构构件截面与配筋、消防疏散最终判定、无障碍合规最终结论、机电负荷计算。
- 不适用：施工图阶段的节点大样与材料下料（分别见 `construction-detailing` 与 `material-and-finish-selection`）。
- 边界：本领域只给出方向与校核框架，所有数值为工程惯例区间，需用项目所在地现行规范校核。
- 边界：当业主需求本身互相矛盾时，本领域负责暴露矛盾并给出取舍建议，而非替业主拍板。
- 边界：审美取向由业主与设计团队共同决定，本领域只对"形式—功能—造价"的自洽性负责。

## 核心判据

1. 每一块功能面积都能对应到任务书中的明确需求条目，无"为了填满平面"的冗余空间。
2. 主要使用空间朝向符合当地日照与主导风向惯例（北半球通常南向优先，具体以项目所在地气候区为准）。
3. 主入口可在不使用导航标识的情况下由外部道路自然识别。
4. 公共流线与服务流线（后勤、货运、垃圾）在平面图上无强制交叉；若交叉，须说明错峰或物理分隔措施。
5. 任一房间的疏散路径在图上连续、可读、无回头路；最终疏散距离以项目所在地现行规范为准。
6. 核心筒/竖向交通位于使用效率加权中心，而非几何中心。
7. 体型系数（外表面积/体积）与当地气候需求匹配：寒冷区宜紧凑，炎热区注重遮阳与通风。
8. 结构柱网与功能开间在方案阶段已初步对位，避免柱子落在主通道或核心使用区。
9. 每个楼层净高在扣减结构、机电、吊顶后仍满足功能最低值。
10. 建筑与场地的关系（退线、消防车道、景观界面）在总图上可被独立验证。
11. 方案存在至少一个主导性空间记忆点，而非均质铺开。
12. 造价方向上无"高完成度与低完成度"在同一视觉界面内直接冲突。
13. 无障碍通行路径在总图与首层平面上连续（最终合规由持证专业人员复核）。
14. 设备机房、管井、垃圾房等"负空间"已落位，未到最后才塞入。
15. 地下与地上功能对位，避免上下错位导致结构转换。
16. 标准层与首层、屋顶层策略明确区分，而非简单复制。
17. 外立面开口率与内部功能匹配（机房少开窗、展示面多开窗）。
18. 建筑与市政接口（水、电、燃气、排水标高）在方案阶段已被识别为约束。
19. 存在明确的"暂停点"：成本、规范或业主决策未定时，方案保留可切换余地。
20. 方案说明中不出现无法被图纸或数据支撑的形容词。
21. 被动式策略（遮阳、通风、蓄热）优先于主动式设备补救。
22. 首层与地面关系明确：是否架空、是否商业、是否有过街，需被显式声明。
23. 垂直分区（裙房/塔楼/地下室）的功能与交通衔接清晰。
24. 屋面策略（绿化、设备、光伏、排水坡度）已初步考虑。
25. 对周边既有建筑的遮挡、间距、视线干扰已被识别。
26. 防火分区与功能分区的边界在方案图上已可辨识（结论待专业复核）。
27. 人防、地下车库、设备用房的"不可见面积"占比已被估算。
28. 方案各层级（城市—场地—单体—房间）之间逻辑可自洽向下贯通。

## 数值与区间

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 项目 | 常用取值 | 说明 |
|---|---|---|
| 住宅标准层层高 | 2.9–3.1 m | 净高需再扣结构+机电+吊顶 |
| 办公标准层层高 | 3.9–4.2 m | 便于架空地板与吊顶并存 |
| 商业标准层层高 | 4.5–5.5 m | 首层常取高值 |
| 酒店客层层高 | 3.3–3.6 m | 考虑管廊与隔声 |
| 公共走廊净宽 | 1.5–2.4 m | 按人流与规范校核 |
| 门厅进深 | 相邻最宽通行面的 1.5 倍以上 | 避免"过道式门厅" |
| 房间进深/面宽比 | 1:1 – 2:1 | 过深影响采光通风 |
| 体型系数（参考） | 严寒区宜低，夏热冬暖区可放宽 | 仅作体量比较用 |
| 柱网模数（住宅） | 6.0 / 7.2 / 8.4 m | 与车位、开间联动 |
| 柱网模数（办公） | 8.1 / 8.4 / 9.0 m | 与停车效率联动 |
| 地下车位单车位面积 | 30–40 m²/辆（含通道） | 与柱网强相关 |
| 日照间距系数（参考） | 1.0–1.67 视纬度与规范 | 以当地日照分析为准 |
| 消防车道净宽 | 4.0 m 起 | 以现行规范为准 |
| 消防车转弯半径 | 12 m 起 | 以现行规范为准 |
| 建筑退线 | 按当地规划条件 | 不可自行假设 |
| 标准层得房率（住宅） | 75%–85% | 与核心筒效率相关 |
| 标准层得房率（办公） | 65%–78% | 与进深和核心筒相关 |
| 结构楼板厚度（参考） | 100–160 mm（常规跨度） | 以结构专业复核为准 |
| 层间梁下净高占用 | 400–900 mm（含风管） | 与机电系统相关 |
| 幕墙分格模数 | 1.2–1.8 m | 与板材规格联动 |
| 地下车库层高（净） | 2.2–2.4 m | 以规范与车型为准 |

## 常见错误

- 用"效果图好不好看"替代平面逻辑判断，概念与平面脱节。
- 核心筒居中于几何中心，导致使用效率低下、得房率差。
- 主通道被结构柱或梁下净高突变打断，通行体验割裂。
- 日照、通风只在文本里描述，从未做过体块级的朝向验证。
- 服务流线与客流交叉却无错峰或分隔说明，交付后运营冲突。
- 为追求立面效果设置大面积无使用功能的通高空间，牺牲可租售面积。
- 忽略当地气候区差异，把寒地做法直接套用到湿热地区。
- 结构、机电在方案阶段完全缺席，深化阶段被迫大改平面。
- 用单一"通用层"复制所有楼层，未区分首层、标准层、设备层、屋顶层。
- 造价控制缺位，方案完成度与成本目标无对应关系。
- 无障碍只在入口画个坡道，室内高差与门宽未系统检查。
- 设备机房面积不足，后期被迫占用车位或公共空间。
- 竖向管井分散设置，导致标准层使用率下降。
- 总图与单体方案由不同人完成，接口冲突。
- 把"概念"当成免于功能校核的理由。
- 未识别市政接入点标高，地下室排水方案后期失效。
- 盲目追求"低体型系数"而牺牲采光与通风，得不偿失。
- 方案说明堆砌形容词，缺少可验证判据。

## 与其它领域的接口

- 与 `spatial-planning`：输出功能分区与体量逻辑；接收房间划分与流线细化结果。
- 与 `human-ergonomics`：输出房间进深、层高意向；接收净尺寸与活动尺度校核。
- 与 `material-and-finish-selection`：输出立面与体量意图；接收材料可实现性与规格约束。
- 与 `lighting-design`：输出朝向与采光面；接收自然光与人工光比例策略。
- 与 `building-systems-coordination`：输出竖向交通与管井位置；接收管井尺寸与净高占用。
- 与 `construction-detailing`：输出几何与构造意向；接收节点可实施性反馈。
- 与 `bim-modeling-principles`：输出体量与楼层信息；接收模型阶段与精度约定。
- 与 `design-review-checklists`：方案结论在提交前应逐条对照评审清单。
- 与 `design-presentation-methodology`：以"分区—流线—形体"三段式表达结论。

## 分阶段应用

- S1：核对任务书的可行性与矛盾点，输出约束清单与待澄清问题。
- S2：生成 2–3 个体量方向，比较场地回应、成本、可建性。
- S3：将选定方向落到平面，验证功能分区与流线。
- S4：协调结构、机电、立面，形成可深化方案。
- 各阶段均应保留"未决项"台账，避免下游返工。
- 阶段推进的判据是"上一阶段的主要矛盾已被解耦"，而非时间到点。

## 典型权衡与取舍

- 得房率 vs 公共空间品质：核心筒越紧凑得房率高，但门厅与电梯厅体验下降。
- 体型系数 vs 采光通风：紧凑体量节能，但可能牺牲主要房间朝向。
- 层高 vs 造价：增加层高改善体验，但结构与机电成本上升。
- 立面完成度 vs 成本：幕墙面积与造价正相关，需分级处理。
- 车位数量 vs 地下室面积：车位密度受柱网约束，柱网又受开间约束。
- 以上每对矛盾都应在方案说明中显式列出取舍理由与代价。

## 输出物与数据格式

- 功能分区图（区划色块 + 面积标注，单位 m²）。
- 流线分析图（五类流线分色，交叉点加注）。
- 体量关系图（体块 + 朝向 + 主导风向箭头）。
- 楼层策略表（首层/标准层/设备层/屋顶层各一行）。
- 净高估算表（结构/机电/吊顶/净高分列，单位 mm）。
- 未决项清单（每项含影响范围与建议决策人）。

## 风险与不确定性

- 规范版本差异：不同地区对疏散、日照、退线的要求差异大，必须本地校核。
- 业主需求漂移：方案阶段需求变更率高，应保留模块化余地。
- 地勘缺失：地下方案在无地勘时具有高不确定性，须标注假设。
- 造价波动：材料与人工价格波动会影响完成度分级，须设弹性区间。
- 审批不确定性：规划、消防、人防审批结果可能反改方案，须设预案。
- 以上风险均应在方案说明中显式列出，而非隐去。

## 术语与口径

- **得房率**：可租售或可使用面积与建筑面积之比，口径须注明是否含公摊。
- **体型系数**：建筑外表面积与体积之比，用于体量层面的能耗比较。
- **核心筒**：集中竖向交通与管井的服务核，位置决定使用效率。
- **净高**：完成面到吊顶底面的垂直距离，区别于结构层高。
- **流线**：人、货、垃圾、疏散等移动路径的统称，须分类讨论。
- **负空间**：机房、管井、垃圾房等无直接使用价值但必需的房间。
- **暂停点**：方案中因信息缺失而临时保留的可切换设计决策。
- **完成度分级**：同一项目内不同区域按视觉与成本重要性分级处理。
- 以上口径在本知识库内统一使用，跨文档引用时不得改变含义。

## 与相关规范的衔接方式

- 本领域不引用具体条文号，只描述"项目所在地现行规范"这一约束来源。
- 凡是规范约束（疏散、日照、消防、无障碍、节能），均应转成"待本地复核项"。
- 规范冲突时，以更严格者为准，并在方案说明中标注冲突点。
- 规范更新可能导致方案返工，故方案应保留参数化余地。
- 涉及安全与合规的最终判定，一律交由持证专业人员签署。

## 常见问答式判断

- 问：这个进深够吗？答：先查功能活动尺度，再看采光与通风是否可达。
- 问：层高能不能再降？答：测算机电最小占用与净高底线后再答。
- 问：能不能加一层？答：看结构、消防、日照与规划限高的联动约束。
- 问：这个流线交叉能接受吗？答：看交叉频次、时段与安全等级。
- 问：立面能全部用玻璃吗？答：看朝向、能耗、眩光与成本。
- 问：能不能不做地下室？答：看车位配比与市政接口要求。
- 以上问答用于快速暴露缺失信息，而非替代专业计算。

## 检查清单

- [ ] 任务书每条需求都能映射到具体空间。
- [ ] 功能分区图与平面图一致，无"图上有、平面无"的分区。
- [ ] 公共流线与后勤流线已分别绘制并检查交叉。
- [ ] 每个楼层的净高估算（结构+机电+吊顶）已完成。
- [ ] 结构柱网与主要开间、车位排布已初步对位。
- [ ] 场地退线、消防车道、出入口已按规划条件标注。
- [ ] 主要空间朝向已结合当地气候与日照核对。
- [ ] 核心筒位置基于使用效率加权，而非几何中心。
- [ ] 首层、标准层、设备层、屋顶层分别有独立策略。
- [ ] 方案完成度与造价目标有对应说明。
- [ ] 已识别方案的主导记忆点。
- [ ] 设备机房、管井、垃圾房等负空间已落位。
- [ ] 地下与地上功能对位，无结构转换隐患。
- [ ] 无障碍通行路径在总图与首层连续，并注明待复核。
- [ ] 市政接口标高与容量已识别为约束。
- [ ] 未决项已列清单并标注决策人。
- [ ] 被动式策略已被优先考虑。
- [ ] 裙房/塔楼/地下室的垂直分区衔接清晰。
- [ ] 屋面策略已初步计划。
- [ ] 对周边既有建筑的影响已识别。
- [ ] 未对结构、消防、无障碍、机电负荷下最终结论。
- [ ] 所有安全类结论均标注"须由持证专业人员复核签署"。
