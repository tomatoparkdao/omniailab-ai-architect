# 示例库（Examples）

**这一层是"可整段照抄"的成品。** 规范在 `skills/` 与 `knowledge/`，判据在 `docs/DESIGN_CRITERIA.md`，
而"这句话到底该怎么说""交付到底该长什么样"——看这里。

| 文件 | 什么时候用 | 拿到什么 |
|---|---|---|
| [demo-brief.md](demo-brief.md) | 想看看"一条需求长什么样" | 一份可照抄的 120㎡ 住宅设计请求（中英对照） |
| [cold-start-prompts.md](cold-start-prompts.md) | 第一次用、不知道怎么开口 | 4 种起手话术 + 31 项能力的一句话点名表 |
| [deliverable-checklist.md](deliverable-checklist.md) | 收尾前自查"该拿的东西拿齐了吗" | 逐阶段产物清单 + 验收口径 |

## 怎么用

1. **不知道说什么** → 打开 `cold-start-prompts.md`，照抄一句发给 Skill。
2. **不知道该要什么** → 打开 `deliverable-checklist.md`，看完整交付包含哪些文件，再回去点名。
3. **想看一条真实需求的写法** → 打开 `demo-brief.md`，替换成你自己的项目参数。

> **示例里没有真实客户资料。** 全部为通用项目类型的自撰样例，可直接分发。
