# 起手话术（照抄即可）

你不需要懂设计术语，也不需要背流程。下面这些话直接复制发给 Skill。

## 一、四种起手式（冷启动）

| 你的情况 | 复制这句话 |
|---|---|
| 手上什么都没有，只想先看看它能干什么 | `跑示例项目` |
| 有一句话想法 | `120㎡ 三居，想要现代意式极简，预算 30 万` |
| 有原始户型图 | `这是原始户型图，先按 S1 帮我解析条件和问题` |
| 已经想清楚要什么 | `先给我两套可比较的平面方案，我要看采光和动线差异` |

**直接说"开始"也可以**，它会先问你四件事：项目类型 / 功能需求 / 预算口径与交付深度 / 手上有哪些资料。

## 二、推进中的两种回答

| 你想干什么 | 复制这句话 |
|---|---|
| 放行到下一阶段 | `确认` ／ `通过` ／ `定稿` ／ `继续`（必须是这四个词之一） |
| 要改某一处 | `第 3 套平面的客厅采光面被独占了，重排一下` |
| 改一个尺寸 | `把主卧衣柜从 600 深改成 550 深` |
| 问为什么这么定 | `为什么把玄关柜放在这里？给我理由和备选` |

## 三、只做一项能力（不走全流程）

| 想要什么 | 复制这句话 |
|---|---|
| 设计任务书 | `只做任务书，把需求整理成可验收的任务书` |
| 场地与条件分析 | `只做场地分析，这套房子的朝向采光有什么问题` |
| 原始图纸解析 | `只做图纸解析，把这张户型图的墙和门窗识别出来` |
| 概念方案 | `只做概念，给我三个设计方向` |
| 意向板迭代 | `只做意向板，我想要温暖克制的质感` |
| 概念图解 | `只做图解，用一张图说明我的动线问题` |
| 空间规划 | `只做平面，帮我排一版功能分区` |
| 布局优化 | `只做布局优化，现在厨房和餐厅太挤` |
| 人体工学 | `只做尺度，核一下通道和家具间距够不够` |
| 概念效果图 | `只做概念效果图，平面我确认了` |
| 室内设计 | `只做室内，把界面和氛围方案给我` |
| 建筑设计 | `只做建筑，看看体量和开窗怎么调` |
| 材料与色彩 | `只做材料，给我一套可采购可施工的材料体系` |
| 灯光 | `只做灯光，给我照度、色温与灯位方案` |
| 机电协同 | `只做机电，核一下净高和管线冲突` |
| CAD 制图 | `只做图纸，出方案深度的 DXF` |
| 3D 建模 | `只做模型，出一份 OBJ 网格` |
| 场景渲染 | `只做渲染任务包，我要拿去出图` |
| AI 视觉表现 | `只做表现，给我逐机位的提示词` |
| 漫游 | `只做漫游，给我多视角机位表` |
| BIM 建模 | `只做 BIM，出 IFC 投影数据` |
| 设计审核 | `只做审核，按清单挑这套方案的问题` |
| 专业协调校核 | `只做校核，看看各专业有没有打架` |
| 施工深化 | `只做节点，把收口和防水做法写清楚` |
| 造价适配 | `只做造价，这套方案跟预算差多少` |
| 工程量 | `只做工程量，算一下量和估算` |
| 材料物料表 | `只做物料表，按空间列清单` |
| 交付文档 | `只做交付文档，把索引和边界说明整理出来` |
| 版本与交付 | `只做交付，检查修订号和未闭环项` |
| 设计汇报 | `只做汇报，把这个阶段的成果做成提案` |

> **说"只做 X"就不会跑全流程。** 它会只做这一项，说清依据与边界，并把结论交回给你。

## 四、卡住时会用到的三句

| 情况 | 复制这句话 |
|---|---|
| 看不懂某个说法 | `解释一下"统一空间模型"是什么意思` |
| 报错或没出图 | `这一步报错了，帮我看是怎么回事，该查手册哪一节` |
| 不知道该干什么 | `现在到哪一步了？下一步我需要做什么` |
