# Example design request
Create a modern warm-minimalist interior for a 120 m² apartment. Two bedrooms, one study, kitchen, living/dining, two bathrooms.

Initial intake: request accurate base plan with dimensions and building location; do not infer structural walls. Produce 2 concepts, then an annotated plan proposal for approval; only after approval generate canonical geometry, model, renderings and draft drawing set.
