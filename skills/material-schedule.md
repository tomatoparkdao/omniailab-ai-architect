# 材料与物料表

## 做什么
材料与物料表把 S4 定下的材质体系翻译成**可采购、可下单**的采购级表格：每种材料一行，写明部位、规格、用量、损耗与替代方案，并与工程量清单、图纸标注逐条对齐。它不改变材料方案本身，只负责把"材料方案—图纸—工程量"三者收敛成一张能直接交给采购和施工的清单。数量与单价分列，量价分离，不合并。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 业主/总包要求"给我一份能直接询价的物料表" | 判定材料燃烧性能、环保等级是否达标（须持证专业人员复核） |
| 施工图已审查通过、进入 S8 交付包编制 | 判断某材料在本地是否买得到、报价多少（由采购与业主决定） |
| 材料方案或工程量更新后需要回填用量与替代 | 代替结构承重材料的选型与配筋 |
| 需要按部位/按档次汇总用量与损耗 | 把估算总额当成结算依据（估算 ≠ 结算） |
| 品牌断供、需要给出同等性能的替代方案 | 替业主选定具体品牌或供应商 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 材料方案（材质体系、编号、部位、档次） | `material-schedule-r<revision>.md` — 主材表（编号+名称+规格+部位+档次） |
| 工程量清单 `quantities.json`（净量） | `material-schedule-r<revision>.csv` — 用量与损耗分列明细 |
| 图纸标注与排版图（起铺点、分缝） | `material-schedule-r<revision>.json` — 结构化物料表（含替代方案） |
| 样板确认记录与维护要求 | `material-substitution-r<revision>.md` — 断供替代对照表 |
| 校核结果中的待复核项 | `material-schedule-uncertain.json` — `uncertain=true` 条目清单 |

## 操作步骤
1. 取 S8 当前修订的工程量清单与图纸标注，按"部位 × 材料编号"建立唯一配对表。
2. 逐条核对材料方案编号：主材表编号必须与图纸标注一一对应，对不上即列为不一致项。
3. 计算用量：净量 × 损耗系数；损耗按材料与排版取值（见判断清单），排版起点未定时不得开始算量。
4. **量价分离**：数量列与单价列分开记录，缺单价时留空并标 `awaiting_quote`，禁止用估算单价凑出一个"总价"。
5. 为每种主材填同等性能替代方案，应对断供与涨价；替代不得降低耐磨、防水、环保等级。
6. 回写与工程量、材料方案的差异到校核结果；差异全部闭环后方可进入交付包。
7. 自检：编号一致、损耗标注、替代齐备、待复核项已列明。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 主材表编号与图纸标注一致率 | 100%，不允许多义或悬空编号 |
| 用量口径 | 净量 × 损耗；数量与单价分列，不得合并为单一"总价" |
| 瓷砖类损耗率 | 5%–10%（常见工程惯例区间，视排版） |
| 石材类损耗率 | 8%–15%（常见工程惯例区间，视拼花） |
| 大板材料搬运可行性 | 已核对电梯/楼梯尺寸，不可行则改小板或标注分缝 |
| 潮湿区材料 | 采用防水/耐水材料并写明基层防水做法 |
| 未封样材料 | 不得进入采购流程，物料表中该行标 `awaiting_sample` |
| 防火/环保/放射性结论 | 一律标注"待持证专业人员复核签署"，不由本能力判定 |

## 硬性规则
1. **量价分离**：数量与单价必须分列；不得把两者相乘后合并成一个"总价"列掩盖单价异常与损耗叠加。
2. **三方一致**：物料表、材料方案、图纸标注必须一致，任一方改动须同步；不一致项不得交付。
3. **不代决策、不定合规**：材料燃烧性能、环保等级、结构承载等结论不在本能力范围，须转"待本地复核项"交持证专业人员。
4. **不虚构单价与品牌**：正文不出现外部品牌名；品牌档位只写"高/中/基本"档，具体品牌由采购与业主确定。
5. **深度如实**：物料表用量为方案阶段估算，不构成结算依据；未封样材料不得进入采购。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 把数量×单价合成"总价" | 单价异常与损耗叠加被掩盖，询价失真 | 数量、单价强制分列，总价只在终端汇总 |
| 排版起点未定就切料 | 现场随意开切、缝不齐、损耗失控 | 排版图先定起铺点与分缝，再算损耗 |
| 只算净量不给损耗 | 现场少量补货、批次色差、工期拖延 | 按材料类别加损耗，落在用量列 |
| 未备替代方案 | 材料断供导致停工或被迫降规格 | 每种主材填同等性能替代，断供即启用 |
| 物料表与工程量各算一套 | 采购量与施工量对不上，结算争议 | 单一数据源，物料表从工程量派生 |

## 与阶段 / 其他能力的关系
- 参与阶段：`[S8]`（物料清单与交付）
- 上游能力：`quantity-takeoff`（提供净量工程量）、`material-design`（提供材质体系与编号）、`cad-drafting`（提供图纸标注与排版）
- 下游能力：`documentation`（物料表并入交付文本）、`delivery`（物料表进入交付包并冻结版本）
- 本能力的产物进入：S8 交付包；材料变更时随 `delivery` 的失效重算链重出。
