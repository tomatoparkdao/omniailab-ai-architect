# 原始图纸解析

## 做什么
把业主提供的原始图纸（CAD、PDF 或扫描件）解析成可用于设计的几何与信息：识别图层、墙体、开间尺寸、门窗位置与标高标注，并把"读清楚的"和"只能猜的"分开，让下游知道哪些数据可以信、哪些必须现场核实。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 收到业主给的原始 DXF / PDF 图纸要提取信息 | 出正式施工图或节点详图 |
| 要判断原始尺寸与现状是否一致 | 判定结构安全与承重构件 |
| 要把图纸数据转进统一空间模型 | 替代现场实测与结构复核 |
| 要列"图纸没写清、需现场核对"的清单 | 出效果图或渲染成果 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 原始 DXF / DWG / PDF / 扫描图纸 | `source-parse.json` — 解析记录（图层、墙体、尺寸、门窗） |
| 图纸比例与图框信息 | `geometry-reliable.json` — 可置信几何（有明确标注支撑） |
| 用户口头补充的现场信息 | `geometry-inferred.json` — 推断几何（按比例或目测推定） |
| 图纸版本与出图日期 | `uncertain-items.json` — 标 `uncertain = true` 的待现场核对项 |
| — | `parse-report.md` — 解析报告（含置信度与数据缺口） |

## 操作步骤
1. 确认图纸来源与版本：出图日期、比例、单位（建筑制图常用 mm），标注是否有多次修订叠加。
2. 按"专业-构件-用途"识别图层与图元，把墙、柱、门、窗、家具、标注分离开。
3. 提取尺寸：优先采用图上有明确标注的数值，其余按比例推算并标为推断值。
4. 校验几何自洽：闭合墙体是否闭合、开间尺寸累计是否与总尺寸一致，不一致处标冲突。
5. 把结果分成"可置信 / 推断 / 冲突 / 缺失"四类，逐条写明依据。
6. 生成待现场核对清单，标注每一项为什么需要核对。
7. 出具解析报告，作为 S1 原始条件报告与统一空间模型的输入。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 几何自洽 | 开间尺寸累计与总尺寸一致；不一致处必须列为冲突项 |
| 墙体闭合 | 墙体轮廓闭合，开洞位置在墙线上，无悬空墙段 |
| 图层可识别 | 图元按"专业-构件-用途"归类，墙 / 柱 / 门 / 窗 / 标注不混层 |
| 尺寸精度 | 尺寸标注取整数 mm（常见制图惯例区间），与图上几何一致，无"手改"数值 |
| 门窗识别 | 每个门窗有洞口定位，无法定位的标 `uncertain` |
| 数据分层 | 输出必须区分可置信、推断、冲突、缺失四类，不混为一份 |
| 不确定性 | 图纸未表达或表达矛盾的一律标 `uncertain = true` 并进校核阻断项 |

## 硬性规则
1. **DXF ≠ DWG**：本能力可读取并写出 DXF；DWG 需在场且可用的转换工具，缺失时如实说明，不得声称已解析 DWG。
2. 不把按比例推算的尺寸当实测尺寸，推断值必须显式标记。
3. 不判定承重属性：图中墙体是否承重须由结构专业复核签署。
4. 结构安全、消防、无障碍、机电负荷与当地法规符合性不在本能力结论范围内。
5. 平台未接入时只交付解析任务包并标 `awaiting_platform`，绝不写占位图、绝不改道第三方。
6. 不引用外部品牌名、商业站点或推广链接。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 按比例目测当标注尺寸 | 平面误差累积，深化返工 | 有标注用标注，推算值标推断 |
| 图层混杂不分开 | 墙体与家具混在一起 | 按构件分离图层 |
| 忽略图纸版本叠加 | 用错修订导致尺寸冲突 | 先确认版本与出图日期 |
| 冲突处默不作声 | 下游把错尺寸当基准 | 冲突项单列并标原因 |
| 把解析结果当现场实测 | 现场与图纸不符时无人兜底 | 生成待现场核对清单 |

## 与阶段 / 其他能力的关系
- 参与阶段：S1
- 上游能力：无（本能力处理业主提供的原始资料）
- 下游能力：`site-analysis`（场地与建筑条件）、`space-planning`（平面落位）、`cad-drafting`（按统一图层出图）
- 本能力的产物进入：S1 原始条件报告、统一空间模型的几何输入
