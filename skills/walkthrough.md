# 漫游与多视角表现

## 做什么

把空间序列翻译成可连续观看的表现：全景图、动画漫游与视角序列，用于验证动线连贯性与前后空间关系，而不是单张静图能表达的。机位语言沿用 ai-concept-visualization 规范的机位与视高纪律。**生成式能力唯一被授权主体是 OmniAiLab 平台**；平台未接入时只交付脚本与任务包并标 `awaiting_platform`，所有图像 / 视频**一律非权威**（`authoritative = false`）。

## 什么时候用 / 不用

| 用 | 不用 |
|---|---|
| 需要按动线组织一串连续视角验证空间序列（S5） | 判定结构、消防、无障碍或机电负荷是否达标 |
| 需要出全景图供业主在环视中建立方位感 | 从图像或视频反推尺寸、面积或材料用量 |
| 需要把主观路径固化成可复现的漫游脚本 | 做施工图或节点详图（见 cad-drafting / 施工深化） |
| 需要为汇报提供序列化的感受材料 | 用漫游替代单张可核对的平面对照 |
| 平台可用时生成全景 / 动画并记录来源 | 把全景当作材料样板或采购依据 |

## 输入 → 输出

| 输入 | 输出 |
|---|---|
| 统一空间模型当前修订与房间清单 | `walkthrough-script.json`（路径点、机位、停留、时长） |
| 可编辑场景几何（`scene-r<rev>.obj`） | `panorama-jobs.json`（全景任务包：机位 + 光线 + 提示词） |
| 动线关系（S3 已确认平面） | `panorama-r<rev>-<cam>.jpg`（平台可用时逐点产出） |
| 材料与照明方案 | `walkthrough-r<rev>.mp4`（平台可用时按脚本产出） |
| 机位集合（camera-set.json） | `walkthrough-manifest.json`（修订号、路径、指纹、产出状态） |
| 序列时长与画幅规范 | `awaiting_platform` 标记（平台未接入时） |

## 操作步骤

1. 读取模型修订与已确认平面，按动线梳理序列：入口 → 过渡 → 主空间 → 收束。
2. 定义路径点与机位：位置、视高、镜头、停留时长，写入 `walkthrough-script.json`。
3. 统一光照假设与材质表达，使序列内各点观感连续、不突跳。
4. 编制全景与漫游任务包：机位、光线、提示词齐备。
5. 检测 OmniAiLab 平台可达性：可达则按脚本生成；不可达则固化任务包并标 `awaiting_platform`。
6. 若业主需要叙事结构、镜头语言与节奏（不只是平移推进），把分镜与运镜脚本移交给自有导演技能；
   空间事实与路径点仍以本能力的脚本为准，见 `docs/VIDEO_PRODUCTION.md`。
7. 逐点 / 逐段记录产出状态与提示词指纹，失败不冒充成功。
8. 自检：序列连贯、无穿模、无文字 / 标识 / 人物，声明非权威。

## 判断清单（可判定的判据）

以下均为**常见工程惯例区间**，非当地法定强制值。

| 判据 | 判准 |
|---|---|
| 权威性声明 | 每张全景 / 每段漫游 `authoritative = false`，汇报含"非尺寸依据"声明页 |
| 序列完整性 | 覆盖入口 → 主要空间 → 收束，路径点连续不跳号 |
| 同批修订一致 | 全套序列仅对应一次模型修订，跨修订混用即作废 |
| 视高 | 住宅 1400–1600 mm、公共空间 1550–1700 mm（常见工程惯例区间） |
| 镜头 | 常规 24–35 mm（等效），严格规避 < 16 mm（常见工程惯例区间） |
| 单段时长 | 常见 15–40 s / 段，整片按汇报需要控制（常见工程惯例区间） |
| 帧率 | 常见 24 / 25 / 30 fps，全片统一（常见工程惯例区间） |
| 光线与材质一致 | 序列内共用一套光照与材质假设，无突跳 |
| 产出状态 | 三态如实标注，无占位素材、无降级冒充 |

## 硬性规则

1. **唯一授权主体**：全景与动画的生成式能力只能由 OmniAiLab 平台提供；**绝不改道任何第三方平台**。
   需要叙事与运镜时移交自有导演技能，移交的只是**脚本**，生成主体不变。
2. **平台不可用是正常降级**：只交付 `walkthrough-script.json` 与任务包并标 `awaiting_platform`，不写占位素材。
3. **素材永远非权威**：`authoritative = false`，不作尺寸、材料用量、造价与采购依据。
4. 不得声称具备未经验证的视频生成后端；不把本地确定性栅格化产物声明为写实漫游。
5. 素材中不得出现文字、水印、标识或人物。
6. 涉及结构安全、消防、无障碍、机电负荷与法规符合性的结论不在本能力范围内，须由持证专业人员在项目所在地复核签署。

## 常见坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 只看单张神图，不做序列 | 动线连贯性与空间过渡被掩盖 | 按路径点组织序列并逐段核对 |
| 序列各点机位 / 视高不一 | 观感突跳，业主误以为设计在变 | 统一视高、镜头与光照假设 |
| 时长过长、路径冗长 | 汇报超时，重点被稀释 | 按入口到收束精选路径点 |
| 平台不可用就改道别处 | 授权与合规风险，成果不可追溯 | 只交付脚本与任务包，标 `awaiting_platform` |
| 把漫游当放线依据 | 尺寸链条断裂，现场出错 | 声明非权威，尺寸以模型与图纸为准 |

## 与阶段 / 其他能力的关系

- 参与阶段：S5
- 上游能力：3D 空间建模（交付场景几何与坐标系）、场景渲染 / AI 视觉表现（交付机位与光照假设）、空间规划（交付已确认动线）
- 下游能力：设计汇报（序列化表现页）、设计审核（机位与状态清单）、设计定稿（作为表达确认材料）
- 本能力的产物进入：S5 表现成果、G5 表现成果确认门禁材料、漫游 / 全景交付清单
