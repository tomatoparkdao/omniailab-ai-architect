# 概念方案设计

## 做什么
把任务书里的需求与约束翻译成一个能用一句话说清的设计主张，并把它落成空间原型与风格语言：定位（面向谁、什么调性）、概念主张、空间原型、风格与案例参照。概念必须在平面上成立，而不是只在效果图上成立。

**概念方向 ≠ 设计风格**：同一套空间原型可以配不同风格，同一风格也能落成不同空间策略。所以本能力产出的是「2–3 套空间策略不同的方向 × 每套一套视觉语言」，换色不算换方案。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 业主要求"先给我两套概念方向比一比" | 做施工图深化与节点大样 |
| 任务书确认后要定设计方向与调性 | 替代平面方案的尺度校核 |
| 要给出可被记住的空间原型与记忆点 | 判定结构可行性与消防合规 |
| 需要一句话主张与图文证据支撑 | 出可直接施工的正式图纸 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| `design-brief` 确认版任务书（G1 基准） | `concept-options.json` — 2–3 套方向（原型 / 策略 / 材料 / 代价 / 证据） |
| `user-needs.json`、`design-opportunities.md` | `concept-options.md` — 人读版：每套回应哪条机会 |
| `site-conditions` 场地与建筑条件 | `concept-diagrams/*.svg` — 功能关系 / 分区 / 动线 / 采光 / 序列 |
| 业主风格倾向与参考偏好 | `moodboards/mb-*.svg` — 真实色板与材料板（色值取自风格库） |
| 造价档位与目标完成度 | `concept-comparison.md` — 八维比较 + 总设计师推荐（未评估项不折算） |
| 品牌与命名信息（如有） | `concept-presentation.pptx` — 可编辑提案；`g2-approval-summary.md` — G2 摘要 |

## 操作步骤
1. 先读 S1：G1 是否确认、基准是否仍有效、有哪些机会必须回应（`concept --action generate` 已内置）。
2. 复述任务书核心矛盾（谁用、何时用、要求什么、限制什么），确认方向不被误读。
3. 生成 2–3 个体量或空间原型方向，比较场地回应、成本与可建性（建筑项目按体量，室内项目按空间序列）。
4. 把每个方向写成"锚 → 象 → 法 → 形"四步：锚定问题、确立意象、给出方法、落成形式。
5. 把概念落到功能、尺度、材料、照明四个可验证维度，避免只有形容词。
5. 明确每个方向的主导记忆点（至少一个），避免均质铺开。
6. 用统一标准、统一格式做方向比选，标注各自代价与适用前提。
7. 出具 `concept-r{n}` 供 G2 确认，确认后方向与关键词不再变更。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 一句话主张 | 概念主张可用一句话说清，且不含不可验证的形容词 |
| 概念四步 | 锚 → 象 → 法 → 形 四步齐备，缺一步概念不成立 |
| 概念可验证 | 概念落到功能、尺度、材料、照明四个可验证维度 |
| 平面原型 | 空间原型在平面上成立（按真实尺寸），不只是效果图成立 |
| 主导记忆点 | 至少存在一个主导性空间记忆点，而非均质铺开 |
| 美学基线 | 冷调打底、暖色点睛，暖材占比 ≤40%（常见工程惯例区间） |
| 配色校验 | 60-30-10 配比 + 黑色 3–8% 作重音（常见工程惯例区间） |
| 方案可比 | 方向比选使用同一标准、同一格式，差异点可被快速识别 |

## 硬性规则
0. **不许凑数**：没有证据支持的方向不进入候选；空间家族相同的两套不算两个方向，宁可只出两套。资料不足时如实写「待核实」，不编面积、不编预算。
1. **不代业主决策**：给推荐 + 理由 + 备选，不写"几套都行"。
2. 概念不得作为免于功能校核的理由，平面四问不通过时方向不算成立。
3. 不得引用第三方事务所的自有作品作为默认案例；案例只来自原创知识库与用户授权内容。
   素材库（`docs/REFERENCE_SOURCES.md`）只用于调研趋势——结论可带走，原图不进交付物。
4. 图像（效果图、意向图）不作尺寸依据，概念图解须声明非权威成果。
5. 结构安全、消防、无障碍、机电负荷与当地法规符合性不在本能力结论范围内。
6. 平台未接入时只交付任务包并标 `awaiting_platform`，绝不写占位图、绝不改道第三方。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 概念只有形容词 | 无法验证也无法落地 | 落到功能 / 尺度 / 材料 / 照明四维度 |
| 概念与平面脱节 | 概念很美但平面做不出 | 原型按真实尺寸在平面上验证 |
| 用效果图代替概念 | 平面逻辑缺失，深化返工 | 先过平面四问再谈表现 |
| 方向比选标准不一 | 业主无法比较 | 同标准同格式呈现 |
| 概念阶段就锁死材料 | 后期无从调整 | 概念只定倾向，材料在 S4 深化 |

- 参与阶段：S2, S3
