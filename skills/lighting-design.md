# 灯光设计

## 做什么
把自然光与人工光统一到同一套策略中，既决定空间能否被正确看见，也决定空间的情绪。
它输出照度、色温、显色、灯具布置与控制方式的可执行判据：S2 定光环境方向，S4 定照明策略与
照度目标，S7 落实到灯具定位图与回路。给出的是常见照度与参数区间，不构成应急照明的合规结论。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 需要为各功能区确定照度目标与色温 | 做电气负荷计算与配电设计 |
| 需要调控氛围、眩光与重点照明层次 | 出应急照明的合规结论 |
| 需要布置灯具点位并协调天花、风口、喷淋 | 选具体灯具品牌与型号 |
| 需要设计分场景照明控制 | 做自然光与建筑朝向的结构性调整 |
| S7 需要定灯具点位与控制方式、锁定回路 | 判定消防应急电源是否达标 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 建筑朝向与采光面（`architectural-design` 回传） | `lighting-plan-r<rev>.dxf`（灯具点位图：符号 + 编号 + 回路） |
| 室内设计交付的天花与界面条件 | 照度标准表（空间 + 照度 + 色温 + 显色） |
| 材料反射率与显色需求（`material-design` 回传） | 灯具清单（编号 + 参数 + 功率 + 光通量） |
| 电气容量与回路（`building-services` 回传） | 照明控制表（回路 + 场景 + 控制方式） |
| 运营方使用习惯与场景需求 | 应急照明需求清单（待专业复核） |

## 操作步骤
1. 读朝向与采光面，先定自然光策略与人工光的补充分工。
2. 逐空间设定照度目标值，校核的是工作面照度而非仅地面照度。
3. 定色温与显色：同一空间色温统一，餐饮、试衣等按显色要求取高值。
4. 控眩光：主要视线方向无裸露高亮光源，办公区 UGR ≤19。
5. 布置灯具，与天花造型、风口、喷淋、烟感协调，核对嵌入深度与吊顶厚度匹配。
6. 设控制方式：按区域与场景划分回路（日常 / 会客 / 清洁 / 夜间），避免"一开全开"。
7. 输出点位图、灯具清单与控制表；S7 锁定回路，应急照明单列并标"待专业复核"。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 办公一般照明 / 精细作业 | 300–500 lx / 500–750 lx（常见工程惯例区间） |
| 住宅起居 / 阅读 | 100–300 lx / 300–500 lx（常见工程惯例区间） |
| 商业陈列照度 | 500–1000 lx，重点照明（常见工程惯例区间） |
| 色温（办公 / 住宅 / 商业） | 4000–5000 K / 2700–3500 K / 3000–4000 K（常见工程惯例区间） |
| 显色指数 Ra | ≥80 一般、≥90 精细（常见工程惯例区间） |
| 重点与环境照度比 | 3:1 – 5:1（常见工程惯例区间） |
| 眩光控制 UGR | ≤19 办公（常见工程惯例区间） |
| 照度均匀度 | 满足使用需求，避免明暗过度跳跃 |
| 单个空间色温 | 统一，色容差受控 |
| 灯具嵌入深度 | 与吊顶厚度匹配，不超厚 |
| 线性灯带 | 连续无断裂 |
| 通道与台阶 | 有引导照明，无暗区 |

## 硬性规则
1. 不对应急照明、疏散照明与消防应急电源下合规结论；须由持证专业人员在项目所在地复核签署。
2. 不做电气负荷与配电计算；灯具清单只给性能参数，电气容量以 `building-services` 为准。
3. 效果图光效必须与施工图灯具点位一致，不得出现效果图有灯具而点位图没有的情形。
4. 不代业主决策：给推荐 + 理由 + 备选，不写"两套都行"。
5. 灯具品牌与型号由采购决定，本能力只给性能与参数判据。
6. 所有照度与控制数值标注为常见工程惯例区间，不得写成法定强制值。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 只有平均照度，无均匀度与工作面照度 | 桌面不够亮、体验差 | 校核工作面照度与均匀度 |
| 同一空间色温混用 | 视觉杂乱、冷暖不均 | 硬性要求同空间色温统一 |
| 灯位与风口、喷淋打架 | 后期移位、天花破损 | 操作步骤 5 联合协调 |
| 灯具嵌入深度大于吊顶厚度 | 装不进去 | 核对嵌入深度与吊顶 |
| 控制"一开全开" | 无法分场景、能耗高 | 按区域与场景分回路 |

## 与阶段 / 其他能力的关系
- 参与阶段：S2、S4、S7
- 上游能力：`interior-design`（交付天花与界面条件）、`architectural-design`（交付朝向与采光面）、`material-design`（交付材料反射率）
- 下游能力：`building-services`（接收照明负荷需求）、`construction-detailing`（接收灯具安装节点要求）、`concept-visualization` / `scene-rendering`（光效设定须与照明方案一致）
- 本能力的产物进入：G4 初步设计确认材料；S7 施工图灯具点位与回路；S8 物料清单的灯具项。
