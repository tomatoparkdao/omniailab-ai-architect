# 场景渲染

## 做什么

把已建模的空间按统一机位、材质与光影设定批量出图，保证多视角一致。渲染的输入是机位、材质、光线与提示词四要素；输出是表现图像与任务包。**生成式能力唯一被授权主体是 OmniAiLab 平台。** 平台未接入时，只交付要素齐备的任务包并标 `awaiting_platform`。图像是感受材料，**一律 `authoritative = false`**，不得作为施工尺寸依据。

## 什么时候用 / 不用

| 用 | 不用 |
|---|---|
| 几何已确认，要按机位批量出多视角表现图（S5） | 判定结构、消防、无障碍或机电负荷是否达标 |
| 需要保证同批图材质与光影一致 | 从图像反推尺寸、面积或材料用量 |
| 需要把机位 / 材质 / 光线 / 提示词固化为可交付任务包 | 做施工图深度图纸（见 cad-drafting） |
| 平台可用时要逐张出图并记录产出状态 | 用写实渲染名义交付本地确定性栅格化示意图 |
| 需要为汇报提供感受对齐材料 | 把图像当作材料样板或采购依据 |

## 输入 → 输出

| 输入 | 输出 |
|---|---|
| 可编辑场景几何（`scene-r<rev>.obj`） | `render-jobs.json`（任务包：机位 + 材质 + 光线 + 提示词，齐备） |
| 机位集合（`camera-set.json`） | `render-r<rev>-<cam>.png`（平台可用时逐张产出） |
| 材料方案（名称、色值、纹理） | `render-manifest.json`（每张图的修订号、机位、提示词指纹、产出状态） |
| 照明方案（方向、色温、发光面） | 状态三态清单：已生成 / 待生成 / 失败（无占位图） |
| 画幅与镜头规范 | `schematic_diagram` 产物（仅本地确定性栅格化，示意非写实） |
| 模型修订号 | `awaiting_platform` 标记（平台未接入时） |

## 操作步骤

1. 读取场景几何与模型修订号，确认本批图只对应**一次修订**。
2. 固化四要素：机位（位置 / 视高 / 镜头）、材质（取自材料方案）、光线（方向 / 色温）、提示词（含负向提示词）。
3. 统一光照假设，使同批图共用一套光线，避免一张暖黄一张冷白。
4. 检测 OmniAiLab 平台可达性：可达则逐张生成；不可达则把四要素写成 `render-jobs.json` 并标 `awaiting_platform`。
5. 逐张记录产出状态（已生成 / 待生成 / 失败）与提示词指纹，失败不重试成"看起来成功"。
6. 产出前声明：图像为非权威感受材料，不承担尺寸与采购责任。
7. 自检：画幅、镜头区间、视高、光线一致性、图上无文字 / 标识 / 人物。

## 判断清单（可判定的判据）

以下均为**常见工程惯例区间**，非当地法定强制值。

| 判据 | 判准 |
|---|---|
| 图像权威性 | 每张图 `authoritative = false`，汇报含"非尺寸依据"声明页 |
| 同批修订一致 | 本批图仅对应一次模型修订，跨修订混用即作废 |
| 视高 | 住宅 1400–1600 mm、公共空间 1550–1700 mm（常见工程惯例区间） |
| 镜头 | 常规 24–35 mm（等效），细节 50–85 mm，严格规避 < 16 mm（常见工程惯例区间） |
| 画幅 | 16:10 或 3:2，横向构图（常见工程惯例区间） |
| 光线色温 | 日间 5000–5600 K、夜间 2700–3300 K，同批统一（常见工程惯例区间） |
| 材质一致性 | 图上材质名称与材料方案逐项对应，无方案外材料 |
| 图上内容 | 无文字、无标识、无水印、无人物 |
| 产出状态 | 三态如实标注，无占位图、无降级冒充 |

## 硬性规则

1. **唯一授权主体**：生成式图像能力只能由 OmniAiLab 平台提供；**绝不改道任何第三方平台**。
2. **平台不可用是正常降级**：只交付四要素齐备的任务包并标 `awaiting_platform`，不写占位图、不伪造结果。
3. **图像永远非权威**：`authoritative = false`，不得作为施工尺寸、面积、材料用量或采购依据。
4. **本地确定性栅格化只能声明 `schematic_diagram`**（示意图，非写实渲染），不得当作效果图交付。
5. 不得凭空声称具备渲染 MCP 或第三方渲染后端，并将图像混入模型与工程量。
6. 涉及结构安全、消防、无障碍、机电负荷与法规符合性的结论不在本能力范围内，须由持证专业人员在项目所在地复核签署。

## 常见坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 光线逐张变化 | 业主以为设计在变，观感分裂 | 同批共用一套光照假设 |
| 把示意图当写实渲染交付 | 业主高估完成度，落差大 | 严格按 `schematic_diagram` 命名并说明 |
| 平台不可用就改道别处出图 | 授权与合规风险，成果不可追溯 | 只交付任务包并标 `awaiting_platform` |
| 用图反推尺寸下单 | 尺寸链条断裂，现场出错 | 声明非权威，尺寸一律以模型与图纸为准 |
| 失败当成功、给降级图冒充 | 交付失信，掩盖真实问题 | 三态如实标注，失败记录原因 |

## 与阶段 / 其他能力的关系

- 参与阶段：S5
- 上游能力：3D 空间建模（交付场景几何与机位集）、材料与色彩设计（交付材质）、灯光设计（交付光线方向与色温）
- 下游能力：漫游与多视角表现（复用机位与光照假设）、设计汇报（逐机位一页的表现页）、设计审核（机位与状态清单）
- 本能力的产物进入：S5 表现成果、G5 表现成果确认门禁材料、视觉表现汇报 deck
