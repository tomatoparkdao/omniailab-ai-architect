# CAD 制图

## 做什么

把统一空间模型（Canonical Spatial Model）翻译成符合统一制图标准的二维图纸：图层、线型、线宽、标注、图框与图号成套一致。同一能力服务两个绘制深度——S4 起即可绘制**方案深度**（schematic），S7 在锁定后深化为**施工图深度**（construction）。二者的区别在于深度，不在有无：图纸不是最后才画。

## 什么时候用 / 不用

| 用 | 不用 |
|---|---|
| 平面确认后要出平、天花、地面、立面的方案深度图纸（S4） | 判定结构安全、消防、无障碍是否达标（须持证专业人员） |
| 施工图阶段要出正式平立剖、节点索引与图号体系（S7） | 生成效果图或漫游（见 scene-rendering / ai-visualization / walkthrough） |
| 需要统一图层命名、线型线宽、标注样式与打印样式 | 建立参数化构件与信息模型（见 bim-modeling） |
| 需要图纸目录、修订记录与图签信息 | 判定机电负荷、管线容量等专业计算结论 |
| 需要把模型 / BIM 导出成可交付的二维图纸 | 把方案深度图纸当作"已审查"的施工图使用 |

## 输入 → 输出

| 输入 | 输出 |
|---|---|
| 统一空间模型当前修订 | `plan-r<rev>.dxf`、`ceiling-r<rev>.dxf`、`elevation-<no>-r<rev>.dxf` |
| 该阶段出图深度（schematic / construction） | `drawing-index.json`（图号 + 图名 + 版本） |
| 制图标准（图层 / 线型 / 标注 / 图框） | `layer-standard.json`（图层与线型对照表） |
| 材料填充图案与编号规则 | `title-block.dxf`（图框与标题栏模板） |
| 灯具点位、机电点位（S7） | `revision-log.json`（修订记录表） |
| 详图索引与图号规则 | `print-style` 说明（打印样式与线宽预测） |

## 操作步骤

1. 读取模型当前修订与阶段深度，明确本批图纸是 schematic 还是 construction，并记录。
2. 建立或沿用项目制图标准：图层命名（专业-构件-用途）、线型、线宽分级、标注样式、文字样式、单位（mm）。
3. 按图种分别绘制平面、天花、地面、立面；尺寸与几何一致，禁止手动改数值。
4. 标注尺寸、标高、材料填充、图号与索引符号，确保索引与详图编号一一对应。
5. 套用统一图框与标题栏，填写图签；生成图纸目录与修订记录。
6. 自检：图层、线型、线宽、比例、图号唯一性、打印样式、图面无重叠与多余线。
7. 交付 DXF 与打印就绪文件；如需 DWG，交由具备许可的后端另存并回报所用后端。

## 判断清单（可判定的判据）

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地或委托方制图标准为准。

| 判据 | 判准 |
|---|---|
| 出图深度与阶段匹配 | S4 为 schematic、S7 为 construction，不得混称或升格 |
| 绘图单位与坐标 | 统一 mm，模型原点唯一且全项目一致 |
| 线宽分级 | 粗 0.5–0.7 mm、中 0.25–0.35 mm、细 0.09–0.13 mm（打印，常见工程惯例区间） |
| 常规平面比例 | 1:50 / 1:100（常见工程惯例区间） |
| 大样比例 | 1:5 / 1:10 / 1:20（常见工程惯例区间） |
| 尺寸标注字高 | 2.5–3.0 mm（打印，常见工程惯例区间） |
| 图框尺寸 | A1 841×594 mm、A3 420×297 mm（常见工程惯例区间） |
| 尺寸一致性 | 标注值与几何实测值一致，无手改数字 |
| 图号唯一性 | 图纸目录图号不重复、不跳号、与实际图纸数量一致 |
| 图元归属 | 图元在正确图层，不以颜色替代图层分类 |

## 硬性规则

1. **DXF ≠ DWG**：本仓内置写出器只输出 DXF；DWG 必须由具备许可的后端（如 AutoCAD）另存，并回报所用后端，不得声称直接产出 DWG。
2. **深度如实命名**：不得把方案深度图纸（schematic）说成施工图（construction）或"已审查"；施工图深度须在 S7、设计锁定后绘制。
3. **门禁前置**：平面未确认（G3）前不得出正式图纸；设计锁定后不得局部手改，须走变更影响分析。
4. **免责边界**：图纸中涉及结构安全、消防、无障碍、机电负荷与法规符合性的标注结论不在本能力范围内，须由持证专业人员在项目所在地复核签署。
5. 尺寸必须与几何一致，禁止手动改数值；不确定信息标 `uncertain = true`，并作为阻断项上报。

## 常见坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 把 CAD 当"最后一步"，S4 之前不画图 | 方案缺可核对图纸，问题被拖到施工图阶段 | 牢记 R2：方案深度图纸自 S4 起即可绘制 |
| 把 .dxf 直接改名成 .dwg 交付 | 文件损坏或无法打开，被误当正式 DWG | 明确 DXF≠DWG，DWG 由许可后端另存 |
| 线宽不分级、比例乱选 | 图面一片均匀，内容过密或过疏 | 按线宽分级与比例区间配置打印样式 |
| 手动改标注数值 | 尺寸与几何不符，现场放错 | 用标注对象绑定几何，改几何不改数字 |
| 图号重复、索引对不上详图 | 施工找不到图，返工 | 出图前核对图纸目录与索引编号 |

## 与阶段 / 其他能力的关系

- 参与阶段：S4, S7
- 上游能力：空间规划（交付已确认平面）、室内设计（交付顶墙地做法）、BIM 建模（交付可导出的模型）
- 下游能力：工程量计算（按图算量）、设计审核与专业协调校核（图纸合规性）、施工深化（节点与索引）
- 本能力的产物进入：S7 施工图文件与审查记录、G7 施工图审查门禁材料、S8 交付包
