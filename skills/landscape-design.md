# 景观设计

## 做什么
在景观主导或含室外范围的项目里负责室外空间的组织：分区、游线、竖向、水景、植物与铺装，并给出维护策略。核心不是"把院子做好看"，而是回答**这块地服务哪些活动、人怎么走、水往哪里流、树长大以后会怎样**。

本能力不接管建筑本体，也不把住宅房间布局算法套到室外。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 独立庭院、私家花园、屋顶花园、庭院水景 | 纯室内委托（改走 `interior-design` / `space-planning`） |
| 建筑项目里需要处理室外与建筑的关系 | 判定挡土墙配筋与水泵选型 |
| 要判断水景、植物与维护是否匹配业主能力 | 大型市政绿地与生态修复专项 |
| 要出分区、游线与竖向方案 | 出苗木清单与施工图 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| `design-brief` 委托范围与业主诉求 | `landscape-zones.md` — 分区与占比（%） |
| 场地尺寸、朝向、周边视线 | `landscape-circulation.svg` — 游线（主路 / 支线 / 宽度 / 材料） |
| 现状标高、排水去向 | `landscape-levels.md` — 竖向与找坡、排水点 |
| 维护意愿与使用人（儿童 / 老人） | `landscape-water.md` — 水景类型、深度、循环与安全措施 |
| 当地气候与土壤条件 | `landscape-planting.md` — 植物层级、常绿落叶比、季相 |
| 造价与完成度 | `landscape-r{n}.pptx` — 方案汇报 |

## 操作步骤
1. 确认委托范围：只做景观，还是与建筑 / 室内联合；联合时先接过建筑让出的负空间。
2. 列活动清单：通行、停留、种植、水景、儿童、服务收纳，每项对应一块地。
3. 定竖向：现状标高、期望视线、排水方向；先定标高再定材料。
4. 排游线：主路宽 900–1200 mm，闭合或有明确终点；跨水、跨高差处定做法。
5. 定水景类型：按维护意愿与儿童安全在水面、浅渠、跌水、旱溪之间选。
6. 配植物：乔木 / 灌木 / 地被三层，定常绿落叶比与两个以上季相观赏点。
7. 定铺装：不超过三种材料，变化与功能或标高对齐。
8. 写维护表：每周 / 每季 / 每年各做什么，随方案一起交底。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 分区完整性 | 每块地能说出服务哪种活动，无"过渡性空地" |
| 游线闭合 | 主路闭合或终点有可看之物，无无意义断头路 |
| 竖向可读 | 图上有明确找坡方向与排水点，坡度 ≥0.5%，不朝建筑外墙 |
| 院宽与高度 | 院宽小于周边建筑高度时，需用种植或构筑物软化压迫感 |
| 水景匹配 | 维护意愿低时不选大面积静水；水景占 10%–25% 为宜 |
| 儿童安全 | 有水时同时给出水深、防滑与看护视线三项措施 |
| 植物层级 | 乔木 / 灌木 / 地被三层齐全；常绿落叶比与季相明确 |
| 树与建筑距离 | 大树离建筑基础 ≥3 m，按成年冠幅预留 |
| 铺装数量 | 不超过三种主材，交界处有收边 |
| 室内外连续 | 标高衔接、铺装延伸、视线贯通三项至少落实两项 |

## 硬性规则
1. 不判定挡土结构、水景结构与水泵选型；涉及结构安全的结论须由持证专业人员在项目所在地复核签署。
2. 不给具体植物品种承诺，只给层级、比例与季相；品种须按当地气候与土壤确定。
3. 不把住宅房间布局算法用于室外：分区按活动划分，不出现"主卧 / 次卧"式命名。
4. 水景必须同时给出维护成本与儿童安全措施，缺一项不得进入方案确认。
5. **不代业主决策**：水景与种植方案给推荐 + 理由 + 备选。
6. 平台未接入时只交付方案任务包并标 `awaiting_platform`，绝不改道第三方生成。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 只做平面图案不做竖向 | 排水失败、视线平淡 | 先定标高与排水，再定材料 |
| 水景按效果图画 | 渗漏、返碱、水质恶化 | 池体与防水构造先行 |
| 乔木离墙太近 | 五到十年后根系顶铺装、树冠挡光 | 按成年冠幅预留 ≥3 m |
| 院子铺满硬质 | 夏季反射强，排水全靠市政 | 留出种植与透水面积 |
| 汀步、水边无防滑 | 儿童与老人跌倒 | 防滑面 + 警示 + 看护视线 |
| 无维护方案 | 入住一年后荒废 | 维护表随方案交付 |
| 只按面积占比凑数 | 分区之间没有视线与路径关系 | 分区与游线一起定 |

## 与阶段 / 其他能力的关系
- 参与阶段：S1, S2, S3, S4
- 上游能力：`design-brief`（委托范围与诉求）、`site-analysis`（场地条件）
- 协同能力：`architectural-design`（建筑让出的负空间）、`interior-design`（窗台以外的视线衔接）
- 下游能力：`lighting-design`（景观照明）、`building-services`（水景循环与灌溉接驳）、`material-design`（室外材料耐候与防滑）
- 本能力的产物进入：G1 任务书确认材料、G2 概念确认材料、G3 平面确认材料
