# 室内设计

## 做什么
在建筑壳体与平面确定之后，对内部功能、界面（顶、地、墙）、天花造型、色彩与软硬装负责，
把平面发展成有明确收口逻辑、可施工可维护的做法方案。它约束后续的材料、照明、机电与构造。
给出的是室内设计逻辑与判断框架，不是风格词库——每个风格描述都必须落到功能、尺度、材料、
照明四个可验证维度上。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 需要深化天花造型、地面铺装与立面展开 | 判定结构改动的安全性 |
| 需要定界面收口逻辑与高差做法 | 做消防分区的最终结论 |
| 需要整合软装与硬装并排定视觉主导权 | 做机电负荷与风量计算 |
| 需要维护"平天立地"四图同版本一致 | 出室外总图与建筑外形 |
| S6 需要与机电、照明、软装协调并锁定版本 | 细化具体材料规格与工艺（属材料设计） |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 已确认平面（G3 通过）与家具清单 | `ceiling-plan-r<rev>.dxf`（天花布置图：标高、造型、灯位、风口） |
| 室内任务解读与概念方向 | `floor-plan-finish-r<rev>.dxf`（地面铺装图：材质分区 + 排版起点） |
| 人体工学尺度校核（净宽、通行） | 主要立面展开图（界面 + 材质编号） |
| 机电回传的吊顶最低标高与风口点位 | 平天立地四图（同版本一致） |
| 材料基调与照明条件 | 色彩体系说明（主色 / 辅色 / 点缀色 + 应用部位） |

## 操作步骤
1. 读取已确认平面与室内任务解读，区分"必需功能"与"期望氛围"。
2. 逐道新隔墙说明功能目的，剔除仅为造型的隔墙。
3. 定天花策略：明确跌级高度差（100–300 mm）、灯位、风口、喷淋协调关系。
4. 定地面与墙面的材质分区与收口逻辑，通道地面与停留区地面作区分。
5. 编排色彩体系与软硬装主导权，保证软装与硬装不在同一界面争夺视觉焦点。
6. 校核净高：扣除机电与造型后仍满足功能与心理舒适底线（办公开放区 2.6–3.0 m 等）。
7. 输出平天立地四图并核对同版本一致；S6 与机电、照明、软装协调后锁定版本。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 室内净高（办公开放区） | 2.6–3.0 m（常见工程惯例区间） |
| 室内净高（住宅起居） | 2.6–2.9 m（常见工程惯例区间） |
| 天花跌级高度差 | 100–300 mm，藏灯槽与风管（常见工程惯例区间） |
| 通道净宽（室内） | 900–1200 mm，主要动线取高值（常见工程惯例区间） |
| 地面完成面厚度 | 30–80 mm，含找平（常见工程惯例区间） |
| 踢脚高度 | 60–120 mm，与材质收口相关（常见工程惯例区间） |
| 每道新隔墙 | 能说明功能目的，非仅为造型 |
| 界面相交处 | 均有明确收口逻辑，不靠打胶解决 |
| 可开启柜门 / 检修口 | 布置家具后仍能打开 |
| 平天立地四图 | 同一版本，平、天、地、立相互印证 |
| 声学敏感空间 | 有吸声策略（NRC 0.4–0.9，常见工程惯例区间） |

## 硬性规则
1. 不对结构安全、消防分区、机电负荷下最终结论；须由持证专业人员在项目所在地复核签署。
2. 不出现无法落地的"效果图专属"造型；每处造型变化都要能说明其功能或结构原因。
3. 消防设施（消防栓、配电箱）不得被造型或永久构件遮挡。
4. 不代业主决策：给推荐 + 理由 + 备选，不写"两套都行"。
5. 用可判定语句写设计目标，不得用"高级灰""性冷淡"等形容词替代色彩体系说明。
6. 材质样板编号与图纸标注必须一一对应，四图与说明不得版本漂移。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 天花造型与灯具、风口、喷淋打架 | 后期开洞补救、净高损失 | 操作步骤 3 提前协调 |
| 界面收口靠打胶 | 后期开裂、无构造逻辑 | 逐一确定收口方式 |
| 材质样板与图纸编号不一致 | 施工选错材料 | 编号一一对应并锁版本 |
| 灯光位置在造型确定后才考虑 | 牺牲照明质量 | 概念阶段即让灯位与天花协调 |
| 忽略声学 | 开放办公与会议互相干扰 | 声学敏感空间设吸声策略 |

## 与阶段 / 其他能力的关系
- 参与阶段：S4、S6
- 上游能力：`space-planning`（交付房间划分）、`ergonomics`（交付净尺寸与活动尺度校核）、`concept-design`（交付室内概念方向）
- 下游能力：`material-design`（接收材质基调细化为规格与工艺）、`lighting-design`（接收天花与界面条件定照度与灯位）、`building-services`（接收吊顶最低标高要求）
- 本能力的产物进入：G4 初步设计确认材料（顶墙地做法定案）；S6 锁定版本与深化依据。
