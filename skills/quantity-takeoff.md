# 工程量计算

## 做什么
从统一空间模型逐阶段计算**工程量**：面积、延长米、体积、个数与套数，随设计深化滚动更新。
它只管"量"，不管"价"——量价分离，工程量与图纸同源同版本，图纸一改量就重算。
到 S8 施工图与做法定案后，才形成与图纸一致的正式工程量清单；此前各阶段的量都是过程版本，**不构成结算依据**。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 要按当前平面口径出一份工程量（S1 起，任何阶段） | 核定分项单价或做报价 |
| 平面或做法变更后要重算受影响部位的量（S3 起） | 出具可作为结算或招标依据的正式清单 |
| 要给造价适配提供量作为估算基础（S1–S6） | 替代持证造价专业人员签署工程量 |
| 施工图完成后要出与图纸一致的正式清单（S8） | 决定结算金额或处理索赔 |
| 要多轮量对比、看哪里增了哪里省了 | 承诺量在施工中不再变化 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 统一空间模型当前修订（房间边界、构件几何） | `quantities.json`（结构化工程量：构件 → 部位 → 单位 → 数量） |
| 材料与做法（层次、规格、排版、收口） | `bill-of-quantities.csv`（分项清单，供采购与成本使用） |
| 节点构造层次与厚度（施工深化与节点，S7） | `takeoff-baseline.json`（计量基线：口径 + 假设 + 单位 + 置信度） |
| 房间面积指标与损耗率设定 | `takeoff-report.md`（口径说明 + 不确定项 + 计量方法） |
| 上一轮工程量记录 | `takeoff-diff-r<revision>.md`（轮次差异：增项 / 减项 / 变更来源） |
| 施工图正式深度成果（S8） | `quantity-closure.json`（与图纸核对一致的正式清单版本） |

## 操作步骤
1. 确定计量口径：按净面积还是展开面积，是否含门洞、是否含损耗，逐条写明假设。
2. 从模型逐构件算量，按部位归类（地面、墙面、天花、门窗、固定家具、管线占位）。
3. 面积类按净面积记，异形与造型另计展开面积；延长米按中心线或净长并声明。
4. 计入损耗率：瓷砖、石材按排版难度取值，其余按常规；损耗与净量分列。
5. 与图纸核对：抽检若干部位，确保量能追溯到具体构件与尺寸，图纸间尺寸一致。
6. 变更发生后按影响面只重算受影响部位，并与上一轮做差异对比。
7. 到 S8 用施工图与做法定案数据重算，形成与图纸一致的正式清单并版本冻结。

## 判断清单（可判定的判据）
以下数值均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 判据 | 判准 |
|---|---|
| 量与图纸一致 | 抽检部位可追溯到构件与尺寸，图纸间尺寸一致 |
| 计量口径声明 | 每份量必须写明净面积/展开面积、含/不含门洞与损耗（无声明不得出数） |
| 单位与精度 | 面积 m²、长度 m、体积 m³、个数 个/樘/套；面积取整至 0.1 m² |
| 材料损耗率 | 瓷砖 5%–10%、石材 8%–15%（常见工程惯例区间） |
| 损耗与净量分列 | 净量与损耗分列，可分别核对 |
| 轮次差异 | 每轮出差异表，增/减项可指向变更来源 |
| 正式清单口径 | S8 清单须与施工图同版本，未定案做法不得进入正式清单 |
| 不确定信息 | 由图纸推断的尺寸/面积标 `uncertain = true`，在核对中作为阻断项 |

## 硬性规则
1. **R3 铁律**：工程量自 S1 起随阶段滚动更新，S8 才形成正式清单；不得等到 S8 才第一次计量。
2. **量价分离**：本能力只出工程量，不给单价、不给金额；金额由造价适配负责。
3. **过程版本不构成结算依据**：S1–S7 的量不得写成"结算量/清单量/招标量"。
4. 无口径不出数：不得用占位数据冒充工程量；平台未接入时标 `awaiting_platform`。
5. 不确定尺寸一律标 `uncertain = true` 并作为阻断项，不得把推断当实测计入正式清单。
6. 不越界到法定造价与结算：本能力不承担造价咨询的签署责任，不代业主决策。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 到最后才第一次算量 | 量与图不符，采购与造价失控 | 自 S1 起滚动计量 |
| 不声明计量口径 | 净面积/展开面积混用，量对不上 | 基线里逐条写明口径与假设 |
| 损耗与净量混在一起 | 无法核对 | 净量、损耗分列 |
| 异形造型只按投影面积计 | 严重少算 | 造型另计展开面积 |
| 图纸改了量没重算 | 量与图脱节 | 按影响面重算并出差异表 |
| 把过程量当结算量 | 越界承诺，责任外溢 | 明确标注非结算依据 |

## 与阶段 / 其他能力的关系
- 参与阶段：S1、S2、S3、S4、S5、S6、S7、S8
- 上游能力：空间规划（提供房间边界与面积）、材料与饰面选择（提供规格与损耗）、施工深化与节点（提供构造层次与厚度）
- 下游能力：造价适配（接收量作为估算基础）、材料与物料表（接收用量与损耗）、设计审核（接收量与图纸一致性结果）
- 本能力的产物进入：S1–S6 各阶段造价适配材料、G7 施工图审查记录、S8 交付包（正式工程量清单）
