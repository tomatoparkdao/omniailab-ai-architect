# 人体工学与尺度

## 做什么
空间规划的"量纲底座"：把通行宽度、家具间距、操作台高度、洁具布置、储物尺度这些
"够不够、顺不顺"的判断，变成可被直接引用的数值判据，并回写到平面尺寸标注。
它在 S3 用最小尺度校核平面可行性，在 S4 细化家具与固定设备的尺度。
给出的是常见工程惯例区间，不构成无障碍合规结论。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| "这条走廊够宽吗？""这个房间放得下吗？" | 判定结构安全与消防疏散是否达标 |
| 需要校核家具之间能否起坐、开合、弯腰 | 出无障碍合规结论（仅提供参考尺度） |
| 需要确定操作台、书桌、洁具的常用高度与间距 | 选具体产品品牌与型号 |
| 需要把关键尺寸标注到图上供施工引用 | 做机电负荷与风量计算 |
| 目标人群变化后需要重校关键尺寸 | 判定楼梯承载与栏杆结构安全 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 空间规划交付的房间划分与家具清单 | `ergonomics-check.json`（部位 + 取值 + 依据 + 目标人群） |
| 家具与固定设备意向（含尺寸、冰箱、钢琴等） | 人体尺度校核表（可用可判定语句逐条核对） |
| 界面与完成面厚度（`material-design` 回传） | 关键尺寸标注图（单位 mm） |
| 照明对视线高度的要求（`lighting-design` 回传） | 通行宽度校核图、洁具布置尺寸图 |
| 目标人群定义（成人均值或特殊人群） | 待专业复核项清单（涉及安全的尺度） |

## 操作步骤
1. 确认目标人群（成人均值、儿童、老人、轮椅使用者），取值口径先定死。
2. 从房间划分与家具清单列出所有需要校核的部位。
3. 对每个部位取惯例区间值，标注该值的依据与所属人群，写入尺度校核表。
4. 校核通行净宽：单人 600–750 mm、双人并行 1200–1500 mm，主通道取高值。
5. 校核家具操作空间与操作台高度（站姿 800–900 mm），确认开门、开抽屉、弯腰动作成立。
6. 校核储物与洁具布置（衣柜净深 550–600 mm、洁具中心距 750–900 mm）。
7. 把结论回写平面尺寸标注，冲突时以使用频率高者优先；安全类尺度标"待专业复核"。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 单人通行净宽 | 600–750 mm（常见工程惯例区间） |
| 双人并行 / 主通道净宽 | 1200–1500 mm（常见工程惯例区间） |
| 主要走廊净宽 | 1200–1800 mm，公共建筑取高值（常见工程惯例区间） |
| 厨房操作台高度 | 站姿 800–900 mm（常见工程惯例区间） |
| 厨房吊柜底到台面 | 500–600 mm，防碰头（常见工程惯例区间） |
| 书桌 / 座面高度 | 书桌 720–760 mm，座面 400–460 mm（常见工程惯例区间） |
| 衣柜净深 | 550–600 mm，可容纳衣架（常见工程惯例区间） |
| 洁具中心距 | 750–900 mm（常见工程惯例区间） |
| 踏步高宽 | 高 150–175 mm、宽 260–300 mm（常见工程惯例区间） |
| 扶手 / 栏杆 | 扶手高 850–1000 mm，栏杆垂直杆间距 ≤110 mm（常见工程惯例区间） |
| 开关 / 插座高度 | 开关 1200–1400 mm，插座 300 或 1200 mm（常见工程惯例区间） |

## 硬性规则
1. 不对无障碍、楼梯、栏杆等安全类尺度下最终结论；须由持证专业人员在项目所在地复核签署。
2. 每个取值必须说明依据与目标人群，不得只写"看起来差不多"。
3. 数值是常见工程惯例区间，不得写成法定强制值，也不得当作合规依据。
4. 产品实际尺寸与样本可能有偏差，最终以实物与项目所在地规范为准。
5. 尺度校核漏掉固定设备（冰箱、钢琴、检修口）即视为未完成。
6. 涉及安全的尺度一律标注"待专业复核"，不得隐含通过结论。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 通道宽度只按图纸经验不按人体尺度校核 | 使用者通行别扭 | 逐条对照惯例区间表 |
| 家具布置后无法开门或打开抽屉 | 空间名义可用实则废 | 操作步骤 5 校核动作空间 |
| 操作台高度一刀切 | 站姿坐姿都不舒服 | 区分站姿 800–900 mm 等口径 |
| 衣柜净深不足 | 衣架无法正常悬挂 | 按 550–600 mm 下限校核 |
| 未标目标人群 | 均值对特殊人群不适用 | 校核表强制写人群与依据 |

## 与阶段 / 其他能力的关系
- 参与阶段：S3、S4
- 上游能力：`space-planning`（交付房间划分）、`interior-design`（交付界面与家具意向）
- 下游能力：`layout-optimization`（用校核结果淘汰不成立方案）、`cad-drafting`（把关键尺寸转为标注要求）、`construction-detailing`（回传收口尺度与构造余量）
- 本能力的产物进入：G3 平面确认材料；S4 尺度深化与 S7 施工图细部尺寸的依据。
