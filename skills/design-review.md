# 设计审核

## 做什么
把设计成果按"按阶段、按对象、可勾选"的清单做规则初筛：几何是否自洽、配置是否齐全、图说是否一致、模型与图纸是否同源。
它给的是**内部评审判定**——通过、有条件通过、退回——并逐条落到具体图纸、构件或数值。
它不替代法定审查，也不产生新设计：结构安全、消防、无障碍、机电负荷与当地法规符合性一律不在本系统结论范围内。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 定稿前要给整套成果做一次统一口径的自检（S6） | 判定结构安全、消防或无障碍是否达标 |
| 施工图出图前要查图说一致性、节点齐全性与净高（S7） | 出具"已通过审查"或"符合规范"的结论 |
| 提交业主前要把问题按严重度分级、指定责任方 | 替代法定审查机构或持证专业人员的签署 |
| 每轮评审要先查上轮遗留项是否闭环 | 代替专业工程师评定机电负荷与容量 |
| 重复出现的问题要上升为流程改进项 | 出具文件的法律效力或验收结论 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 统一空间模型当前修订与版本号 | `review-record.json`（评审记录：项目+阶段+版本+日期） |
| 该阶段成果（平面、天花、地面、立面、材料表、图纸清单） | `issues-<stage>-r<revision>.json`（问题清单：编号+描述+严重度+责任方+期限） |
| 材料表、图纸、样板三方（核对一致性） | `review-<stage>-r<revision>.md`（结论页：通过/有条件通过/退回 + 理由） |
| 上游校核结果（协调、工程量、估算）与阻断项 | `review-closure-<stage>.md`（整改闭环跟踪表） |
| 上一轮评审记录与遗留项清单 | `review-boundary.md`（免责与待持证专业人员复核项清单） |

## 操作步骤
1. 锁定本轮评审对象的版本号与范围，先确认图纸、模型、材料表为同一版本。
2. 按对象分组逐项勾选：空间组、界面组、材料组、光环境组、机电组、制图组、模型组、交付组。
3. 对"图上有、说明无"和"说明有、图上无"的不一致逐条记录，不放过。
4. 对每层最不利点净高、材料三方一致、图纸版本一致三类硬项做强制核对。
5. 把每条意见指向具体图纸/构件/数值，按严重度分级，给出可执行的修改方向。
6. 汇总结论分档：无阻断项→通过；仅非阻断项→有条件通过并限期整改；有阻断项→退回。
7. 列明所有安全与合规疑问为待专业复核项，生成免责与边界页，跟踪闭环到 100%。

## 判断清单（可判定的判据）
以下数值均为**常见评审判据区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 判据 | 判准 |
|---|---|
| 房间面积与任务书偏差 | ≤5% 且可解释（常见工程惯例区间） |
| 净高（办公 / 走廊） | 办公 ≥2.6 m、走廊 ≥2.3 m（吊顶后，常见工程惯例区间） |
| 走廊净宽 | ≥1.5 m，按人流与规范校核（常见工程惯例区间） |
| 材料三方一致 | 材料表 / 图纸 / 样板三方一致，无例外 |
| 图纸版本一致 | 全专业同版本，无例外 |
| 待验收的否决项 | 退回项闭环率必须 100%，无例外 |
| 未决项 | 提交前应清零，或显式列出并指定决策人 |
| 不确定信息 | 图说中 `uncertain = true` 的构件必须在问题清单中作为阻断项列出 |

## 硬性规则
1. **结构安全、消防、无障碍、机电负荷与当地法规符合性不在本系统结论范围内**，须由持证专业人员在项目所在地复核签署；本系统只做规则初筛。
2. **不得写"已通过审查""符合规范"**；本能力的"通过"仅表示满足本阶段内部评审要求，不等于合规审查通过。
3. 不得把方案深度成果当作施工图通过审核；深度须如实命名。
4. 评审意见必须可判定、可追溯：无版本号或无法指向具体对象的意见不得作为结论。
5. 不代业主决策、不跳过安全项；评审不放过图说不一致。
6. 所有安全与合规结论一律标注 `uncertain` 与待专业复核，不得由设计单方判定。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 只审平面，不审天花、地面、立面 | 界面问题留到施工暴露 | 按对象分组逐项勾选 |
| 意见笼统、无法执行 | 整改无方向，反复返工 | 每条意见指向图纸/构件/数值并给修改方向 |
| 忽略跨专业接口 | 现场冲突，拆改 | 重点核对接口与版本一致性 |
| 材料表、图纸、样板不一致未被发现 | 选错料、验收争议 | 三方一致列为强制核对项 |
| 净高只查典型处 | 最不利点不成立 | 逐层取最不利点 |
| 判断结论写成"通过"即收工 | 把内部评审误当合规签署 | 结论分档并输出免责与边界页 |
| 退回项无责任人、无期限 | 问题悬空无人管 | 问题清单含责任方与期限并跟踪闭环 |

## 与阶段 / 其他能力的关系
- 参与阶段：S6、S7
- 上游能力：专业协调校核（提供冲突与净高结果）、工程量计算与造价适配（提供指标匹配情况）、各设计能力（提供本轮成果）
- 下游能力：交付文档与版本管理（接收结论与整改闭环记录）、设计汇报与提案（接收结论页与待确认项）
- 本能力的产物进入：G6 锁定深化依据、G7 施工图审查记录、待持证专业人员复核清单
