# 专业协调校核

## 做什么
检查多专业之间的**空间冲突**：结构构件与装修界面、机电管线与吊顶净高、末端点位与造型、做法与收口的接口。
设计审核看的是"单个专业的设计本身是否达标"，本能力看的是"专业之间有没有打架"——同一空间里两样东西占了同一个位置。
输出冲突清单（编号、部位、涉及专业、严重度）、净高校核结果与接口协调表，并把无法闭环项转为待专业复核。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 定稿前要把结构、机电、吊顶冲突一次性查清（S6） | 判定结构安全、耐火或消防分区是否符合法规 |
| 施工图阶段要做管线综合与碰撞检查（S7） | 计算结构配筋、机电负荷或设备容量 |
| 吊顶造型与风口、喷淋、烟感、灯位互相打架时 | 替代持证专业人员出具专业签署 |
| 结构柱、梁、管井与装修界面位置冲突时 | 单独审核某一专业成果是否达标（属设计审核） |
| 变更后要判断冲突面是否需要重跑协调 | 决定采用哪家供应商的系统与专有做法 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 统一空间模型当前修订（含结构构件占位） | `clash-report.json`（冲突清单：编号+部位+涉及专业+严重度+建议） |
| 机电系统占位（管井、管线、机房、末端） | `net-height-check.dxf`（逐层最不利点净高校核剖面） |
| 吊顶做法（标高、跌级、造型、灯槽）与点位 | `interface-matrix.json`（专业接口协调表：谁给谁什么条件） |
| 结构预留条件（预留洞、预埋件）与柱梁位置 | `coordination-report.md`（协调结论 + 未闭环项） |
| 材料做法与收口要求（厚度、交接方式） | `pending-review.md`（待持证专业人员复核项清单） |
| 上一轮冲突记录与闭环状态 | `coordination-closure.json`（冲突闭环跟踪） |

## 操作步骤
1. 收集各专业在同一空间内的占位条件，标注各条件的来源与置信度。
2. 逐层取最不利点，把结构、机电、吊顶、末端叠到同一剖面上做空间核对。
3. 记录每一处冲突：涉及哪几个专业、占位重叠多少、谁应避让（小让大、有压让无压、临时让永久）。
4. 按严重度分级：影响净高或安全的为高，影响观感的为中，仅需微调的为低。
5. 对每个冲突给出避让建议并回写到相应专业的条件表，再复核是否真正消除。
6. 无法在本系统内消除的（涉及负荷、安全、规范）转为待专业复核，不得自行判定为"已解决"。
7. 变更发生后按影响面重跑：动了几何则全量重校，仅饰面级变更则只重算相关点位。

## 判断清单（可判定的判据）
以下数值均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 判据 | 判准 |
|---|---|
| 最不利点净高 | 逐层成立：办公 ≥2.6 m、走廊 ≥2.3 m（常见工程惯例区间） |
| 桥架与水管层间距 | ≥150 mm（常见工程惯例区间） |
| 强弱电间距 | ≥300 mm，或做隔离防护（常见工程惯例区间） |
| 管井尺寸 | 满足立管数量 + 检修裕量（常见工程惯例区间） |
| 机房检修通道 | ≥700 mm（常见工程惯例区间） |
| 吊顶内综合净空 | 办公常用 400–800 mm，容纳风管+桥架+水管（常见工程惯例区间） |
| 冲突闭环 | 高severity冲突必须闭环或明确转交，闭环率 100% |
| 不确定信息 | 占位条件中 `uncertain = true` 者作为阻断项，未消除前不得判为协调完成 |

## 硬性规则
1. **结构安全、消防、无障碍、机电负荷与当地法规符合性不在本系统结论范围内**，须由持证专业人员在项目所在地复核签署；本能力只查空间冲突。
2. **不得写"冲突已全部解决、系统安全"**；未闭环项一律显式转交并写入待复核清单。
3. 不确定占位条件标 `uncertain = true` 并作为阻断项，不得用推断值掩盖冲突。
4. 不得在未拿到设备与结构条件时编造管线断面或结构尺寸来"凑通"协调。
5. 不代业主决策：避让方案给推荐 + 理由 + 备选，不写"两套都行"。
6. 平台未接入时只交付协调任务包并标 `awaiting_platform`，绝不写占位图、绝不改道第三方。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 只叠两款管线，漏掉结构与吊顶 | 现场冲突，拆改返工 | 各专业占位同剖面叠加核对 |
| 冲突记录只有结论，无编号与部位 | 无法追溯、无法闭环 | 每处冲突编号+部位+涉及专业+严重度 |
| 把推断占位当作实测条件 | 冲突被掩盖 | `uncertain = true` 作阻断项 |
| 净高只算典型房间 | 最不利点不成立 | 逐层取最不利点 |
| 变更后只改单专业未回写接口 | 其他专业条件过期，二次冲突 | 接口矩阵同步更新并复核 |
| 涉及负荷的冲突自行判定 | 越界结论，风险外溢 | 转待专业复核并明说边界 |

## 与阶段 / 其他能力的关系
- 参与阶段：S6、S7
- 上游能力：机电与设备协同（提供净高与末端占位）、BIM 建模（提供构件与碰撞检测基础）、结构条件（提供预留与柱梁位置）
- 下游能力：设计审核（接收冲突清单作为审核输入）、施工深化与节点（接收预留与收口要求）、工程量计算（接收调整后的占位量）
- 本能力的产物进入：G6 锁定深化依据、G7 施工图审查记录、待持证专业人员复核清单
