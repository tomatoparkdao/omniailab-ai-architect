# 布局优化

## 做什么
在平面方案成立之后、锁定之前，对同一块面积给出多套布局并量化比较：房间比例与进深、
公共区与私密区的开放度、交通面积占比、家具与通行是否成立。它把"哪种排布更好"从审美
争论变成可比指标的对比，输出被选方案与代价说明。它服务于 S3 的方案比选与 S6 的定稿收敛。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 业主说"两套平面我拿不定，帮我比比" | 从零做功能分区（属空间规划） |
| 需要判断开放厨房 / 开放式办公是否划算 | 校核单件家具的人体尺度（属人体工学） |
| 定稿前房间比例或进深仍不理想 | 判定结构调整是否可行 |
| 需要量化"多隔一间"的采光与流线代价 | 出正式施工图 |
| 锁定前比较可变性与当期使用效率 | 做防火与疏散合规结论 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 空间规划交付的 2–3 套平面与面积指标表 | `layout-comparison-r<rev>.json`（方案可比指标） |
| 人体工学尺度表与通行净宽下限 | 方案对比表（面积 / 动线 / 造价 / 舒适度四项） |
| 结构柱网与承重墙条件 | 被选方案与代价说明（放弃了什么） |
| 造价适配口径（`cost-check` 反馈） | 更新后的 `plan-r<rev>.dxf` 与流线分析图 |
| S6 协调回传的机电占位与净高 | 待确认项清单（标 `uncertain = true`） |

## 操作步骤
1. 读取空间规划交付的平面与指标表，固定不可变条件（柱网、承重墙、管井、采光面）。
2. 明确本次优化目标：比的是房间比例、进深、开放度还是交通效率，一次只抓主要矛盾。
3. 生成 2–4 套候选布局，逐套按同一组指标测量，不夹带不同口径。
4. 对每套跑人体工学与净宽校核与流线交叉检查，淘汰不成立者。
5. 核算每套的交通面积占比、可容纳家具清单与造价影响，填入对比表。
6. 给出推荐方案 + 理由 + 备选，写明推荐方案牺牲了什么、是否可接受。
7. 输出被选方案并回写统一空间模型；S6 阶段重复本流程做锁定前最后收敛。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 房间进深与面宽比 | 不出现狭长无用空间，主功能房间避免单侧过窄（常见工程惯例区间） |
| 主通道净宽 | 双人并行 1200–1500 mm（常见工程惯例区间） |
| 单人通行净宽 | 600–750 mm 为最低舒适宽度（常见工程惯例区间） |
| 交通面积占比（办公） | 20%–30%（常见工程惯例区间） |
| 开放区与私密区过渡 | 有缓冲，不硬性切换 |
| 静闹分级 | 高敏感区与低敏感区不直接相邻 |
| 候选方案数量 | 2–4 套，同一组指标可比 |
| 造价影响 | 每套给出相对造价方向（增 / 持平 / 减） |
| 死角空间 | 无进不去、用不上、放不了家具的空间 |

## 硬性规则
1. 不对结构可行性、消防与无障碍下最终结论；相关判定由持证专业人员在项目所在地复核签署。
2. 比较必须同口径：不同面积基数或不同家具标准的方案不得直接比优劣。
3. 不代业主决策：给推荐 + 理由 + 备选，不写"两套都行"。
4. 造价影响只给相对方向与方案阶段估算，不构成结算依据。
5. 优化不得偷偷改动已确认的采光面分配或承重条件；如必须改，须显式提出并重走确认。
6. 所有数值标注为常见工程惯例区间，不得写成法定强制值。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 比方案时换了家具尺寸或面积口径 | 结论不可比、误导业主 | 操作步骤 3 固定统一指标 |
| 只看平面好看，不看交通面积 | 得房率下降被忽略 | 强制填交通面积占比 |
| 为多隔一间牺牲采光 | 房间成立却不可用 | 采光面分配作为硬约束先锁定 |
| 只比当期效率，不留可变性 | 运营调整时返工 | 对比表增设可变性一栏 |
| 推荐方案不写代价 | 业主签字后才发现取舍 | 输出必须写明"放弃了什么" |

## 与阶段 / 其他能力的关系
- 参与阶段：S3、S6
- 上游能力：`space-planning`（交付平面与面积指标）、`ergonomics`（交付尺度校核表）、`cost-check`（交付造价适配口径）
- 下游能力：`interior-design`（以被选布局深化界面）、`concept-visualization`（在确认布局上出图）、`design-presentation`（把比选结论做成可决策提案）
- 本能力的产物进入：G3 门禁确认材料；S6 的锁定前收敛依据。
