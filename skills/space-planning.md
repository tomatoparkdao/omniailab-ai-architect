# 空间规划

## 做什么
把设计任务书的功能与面积口径、概念阶段确定的空间原型，翻译成有明确功能命名、
真实尺寸、可校核流线的平面方案。它负责"谁在什么房间、按什么路径、占多大面积"这一组判断，
产出写入统一空间模型（Canonical Spatial Model），成为后续所有专业的工作底图。
它给出的是平面逻辑与校核框架，不是施工图深度。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 业主要求"先给我两套平面方案比一比" | 判定结构跨度与配筋是否安全 |
| 需要把功能清单落成房间并核面积配比 | 做防火分区的最终划分 |
| 需要梳理主客流线与后勤、货运、垃圾流线 | 定机电末端与管井详细位置（属机电协同） |
| 平面需要达到"可被施工方标注尺寸"的完成度 | 做立面造型与体量（属建筑设计） |
| 功能置换或户型改造需要重塑平面逻辑 | 出最终疏散与无障碍合规结论 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 已确认的功能任务书与面积指标 | `plan-r<rev>.dxf`（真实尺寸平面布置图） |
| 概念方向与空间原型 | 功能气泡图（功能块 + 关系 + 权重） |
| 原始条件报告（承重墙、柱网、管井、门窗洞口） | 面积指标表（房间名 + 面积 + 与任务书偏差） |
| 人体工学尺度表（通行净宽、洁具间距） | 流线分析图（主客 / 后勤 / 货运 / 垃圾四类分色） |
| 已确认的面积与预算口径 | 家具清单（房间 + 家具名 + 规格 + 数量）、`quantities.json` |

## 操作步骤
1. 读取统一空间模型当前修订与任务书，先暴露面积指标内部矛盾，冲突项标 `uncertain = true`。
2. 画功能气泡图，标注功能关系与权重，确定静—半静—闹分区。
3. 把气泡落成平面：先定主通道与竖向交通，再排房间，最后落门与家具。
4. 逐房间核面积配比，与任务书偏差写出可解释原因；核对采光、通风、噪声三项。
5. 做至少两套方案，列出面积、动线、造价影响的可比指标。
6. 对每套方案跑人体工学与净宽校核，把结果回写平面尺寸标注。
7. 输出全部交付物并登记到产生它的模型修订，交由 G3 门禁确认。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 起居室 / 主卧 / 次卧面积 | 18–30 / 12–18 / 8–12 m²（常见工程惯例区间） |
| 厨房 / 卫生间面积 | 6–10 / 4–8 m²（常见工程惯例区间） |
| 办公工位面积 | 6–10 m²/人，含通道与家具（常见工程惯例区间） |
| 主通道净宽 | 双人并行 1200–1500 mm（常见工程惯例区间） |
| 走廊净宽 | 1.5–2.4 m，按人流取（常见工程惯例区间） |
| 房间门洞净宽 | 800–1000 mm（常见工程惯例区间） |
| 交通面积占比（办公） | 20%–30%（常见工程惯例区间） |
| 主入口到主要功能点路径 | 最短且不穿越服务区 |
| 有采光需求的房间 | 至少一面临外墙或采光井 |
| 静闹分级 | 高敏感区与低敏感区不直接相邻 |
| 方案数量 | ≥2 套，且给出面积、动线、造价三项可比指标 |

## 硬性规则
1. 不对结构跨度、防火分区、疏散与无障碍下最终结论；这些须由持证专业人员在项目所在地复核签署。
2. 功能命名必须唯一，"多功能房"这类无约束空间不得作为房间名写入模型。
3. 面积指标内部矛盾未澄清前，不得假装已对齐；须显式标注假设与待确认项。
4. 平面未通过 G3 门禁前，不得进入精细建模与正式出图。
5. 不代业主决策：给推荐方案 + 理由 + 备选，不写"两套都行"。
6. 所有数值标注为常见工程惯例区间，不得写成法定强制值。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 只做气泡图不落家具与尺寸 | 平面无法施工、指标失真 | 操作步骤 3 强制落到真实尺寸 |
| 房间面积与任务书对不上却无解释 | 业主失去信任 | 输出面积偏差表并写明原因 |
| 门开在角落 | 家具布置被迫将就 | 门位与家具清单联合校核 |
| 只出一个方案 | 无法论证取舍 | 硬性要求 ≥2 套对比 |
| 忽略管井上下对位 | 标准层被迫降板 | 平面阶段即标管井并校验贯通 |

## 与阶段 / 其他能力的关系
- 参与阶段：S3
- 上游能力：`design-brief`（交付功能任务书与面积、预算口径）、`concept-design`（交付空间原型与关键词）、`site-analysis` / `existing-drawing-analysis`（交付原始条件与可置信信息）
- 下游能力：`ergonomics`（回传尺度校核）、`layout-optimization`（做多方案收敛）、`concept-visualization`（以确认平面为依据出概念效果图）
- 本能力的产物进入：G3 门禁确认材料；确认后作为 S4 深化与 S5 建模的基准。
