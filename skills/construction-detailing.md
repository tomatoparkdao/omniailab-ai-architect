# 施工深化与节点

## 做什么
把平面、界面、材料统一到可施工的节点上：基层做法、构造层次与厚度、材料交接与收口、防水与检修、变形缝处理。
它是设计的"最后一公里"——把方案深度的做法意向，深化成施工方能照着做的节点大样、尺寸与图层。
本能力只出 S7 的施工深化成果；S4 的方案深度图纸属方案表达，两者深度不同，不能互相冒充。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 设计已锁定，要出完整节点大样与标准图（S7） | 判定结构构件是否安全或配筋是否足够 |
| 要明确收口方式、构造层次与厚度、基层做法 | 给出防火构造的合规结论 |
| 要处理湿区防水上翻、地漏找坡与变形缝 | 出具"节点符合国家规范"的结论 |
| 要出吊顶、铺装、检修口的安装节点 | 代替持证专业人员签署构造做法 |
| 要建立节点索引、尺寸标注与图层标准 | 在方案阶段用节点图冒充施工图 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 已锁定的设计版本（S6）与统一空间模型当前修订 | `construction-<sheet>.dxf`（平立剖正式深度图，含尺寸与图层） |
| 材料规格与厚度（材料与饰面选择） | `detail-index.json`（节点索引：编号 + 引用图号 + 适用部位） |
| 机电预留洞与末端点位（机电与设备协同） | `detail-<id>.dxf`（节点大样：完整构造层次 + 厚度 + 材料编号） |
| 灯具、风口、喷淋安装要求（灯光设计、机电） | `node-schedule.json`（标准节点与做法表） |
| 防水、检修、变形缝要求（来自协调与做法定案） | `layer-standard.json`（图层与标注标准，含节点引用规则） |
| 方案深度图纸（schematic，仅作对照，不作依据） | `schematic-vs-construction.md`（两个深度的对照说明，避免误用） |

## 操作步骤
1. 确认设计已锁定、模型为当前修订；未锁定时不做施工深化，退回 S6。
2. 建立节点索引：逐个数出收口部位（墙地、墙顶、湿区、干挂、木饰面、检修口、门窗、变形缝、异形）。
3. 对每个节点标注完整构造层次与厚度，基层做法写清（找平、找坡、防水、隔声、防潮）。
4. 明确材料交接方式与施工顺序：压条、凹缝、密拼，标注余量与容差。
5. 湿区节点保证防水连续、上翻高度明确，找坡与地漏位置对应。
6. 出平立剖正式深度图，统一图层、标注与图框，确保图纸间尺寸一致、节点索引完整无缺。
7. 标注涉及承载与安全的构造为待专业复核项，不得自行下安全结论。

## 判断清单（可判定的判据）
以下数值均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 判据 | 判准 |
|---|---|
| 收口部位节点覆盖 | 每个收口部位都有对应节点大样，索引无缺 |
| 节点标注完整度 | 标注完整构造层次与厚度，含材料编号与规格 |
| 地面构造总厚 | 找平层 20–50 mm，完成面总厚 30–80 mm（常见工程惯例区间） |
| 石材干挂空腔 | 50–150 mm，视龙骨（常见工程惯例区间） |
| 吊顶龙骨间距 | 300–600 mm，吊杆 300–1500 mm（常见工程惯例区间） |
| 防水上翻高度 | 淋浴区 ≥1800 mm、其他 ≥300 mm（常见工程惯例区间） |
| 变形缝 / 踢脚 / 收口凹缝 | 变形缝 20–50 mm、踢脚 60–120 mm、凹缝 3–10 mm（常见工程惯例区间） |
| 检修口尺寸 | 300×300 或 600×600 mm，可反复开启（常见工程惯例区间） |
| 木饰面基层含水率 | ≤12%，防膨胀变形（常见工程惯例区间） |
| 不确定信息 | 由图纸推断的构造尺寸标 `uncertain = true`，在交底中作为阻断项 |

## 硬性规则
1. **结构安全、消防、防水与防火构造的最终判定不在本系统结论范围内**，须由持证专业人员在项目所在地复核签署。
2. **方案深度成果不得当作施工图**：`schematic` 只表达做法意向，`construction` 才可施工，两者不得互相冒充。
3. **DXF ≠ DWG、网格 ≠ 参数化 BIM**；写出后必须用独立实现读回校验，不通过即视为失败。
4. 涉及承载与锚固的构造（石材挂贴、吊顶吊挂）必须标注待专业复核，不得自行判定安全。
5. 节点与材料表、图纸必须一致；变更须同步更新节点索引，不得只改一处。
6. 不代业主决策：收口做法给推荐 + 理由 + 备选，不写"两套都行"。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 只画平面与界面，无节点大样 | 现场随意施工，效果失控 | 逐收口部位建节点并索引 |
| 节点只给外形不给层次与厚度 | 施工无从下手 | 标注完整层次 + 厚度 + 材料编号 |
| 基层做法缺位 | 开裂、空鼓、变形 | 找平/找坡/防水/防潮逐项写明 |
| 材料交接靠打胶 | 后期开裂脱落 | 先定交接方式与施工顺序 |
| 湿区防水不连续或上翻不足 | 渗漏、返潮 | 防水连续并核定上翻高度 |
| 用方案深度图当施工图交底 | 施工误读、返工 | 明确标注深度，`schematic` 不作施工依据 |
| 节点未留施工误差余量 | 现场被迫削改 | 设定容差与余量 |

## 与阶段 / 其他能力的关系
- 参与阶段：S7
- 上游能力：室内设计与材料设计（提供做法与材料规格）、机电与设备协同（提供预留洞与末端）、专业协调校核（提供冲突闭环结果）
- 下游能力：CAD 制图与 BIM 建模（接收节点与图层标准）、工程量计算（接收构造层次以计体积与展开面积）、设计审核（接收节点完整性供审查）
- 本能力的产物进入：G7 施工图审查记录、S8 交付包与施工技术交底
