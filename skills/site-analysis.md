# 场地与建筑条件分析

## 做什么
读原始建筑与场地条件，把朝向与采光面、结构格局、进出动线、可拆改边界、现场限制读成一份可核对的约束清单；同时把"看得到但不确定"的部分（承重墙、管线、标高）显式标注，供后续设计避让。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 拿到原始建筑图或现场照片要先判断条件 | 判定承重墙是否可拆（须结构专业复核） |
| 要确认朝向、采光面与主要景观面 | 出消防或无障碍合规结论 |
| 要梳理人、货、垃圾的进出动线 | 计算结构荷载或配筋 |
| 现场条件有疑问、需要列澄清清单 | 替代现场实测与测绘 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 原始建筑图 / 现场照片 / 测量记录 | `site-conditions.md` — 场地与建筑条件报告 |
| 项目地址与所在气候区 | `constraints.json` — 约束清单（朝向、退线、层高、可拆改边界） |
| 现场踏勘记录 | `circulation-map.png` — 五类流线图（人 / 货 / 垃圾 / 疏散 / 后勤） |
| 原始图纸解析结果 | `uncertain-items.json` — 标 `uncertain = true` 的待现场核对项 |
| 市政接入信息（如有） | `site-conditions-r{n}.pptx` — 原始条件汇报（G1 材料） |

## 操作步骤
1. 依据项目所在地气候区判断主朝向与采光面，标注主要房间应朝哪一侧（北半球通常南向优先，具体以气候区为准）。
2. 读结构格局：识别承重墙、柱网、核心筒与竖向交通位置，能识别的标为已知，无法判定的标 `uncertain`。
3. 梳理动线：分别画出人、货、垃圾、疏散、后勤五类流线，标出交叉点与是否可错峰或物理分隔。
4. 记录限制：退线、消防车道与转弯半径、层高与净高、市政接入点标高、可拆改边界。
5. 核对采光与通风：主要使用空间是否有可开启外窗、是否存在对视与遮挡问题。
6. 把结果分成"已知 / 推断 / 待现场核对"三份，把不确定项做成澄清清单。
7. 出具原始条件报告供 G1 确认。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 朝向判断 | 主要使用空间朝向符合当地日照惯例，北半球通常南向优先（以气候区为准） |
| 主入口识别 | 主入口可在不使用导航标识的情况下由外部道路自然识别 |
| 流线交叉 | 公共流线与服务流线在图上无强制交叉；若交叉须写明错峰或物理分隔措施 |
| 疏散路径 | 疏散路径在图上连续、可读、无回头路（最终距离以当地规范为准） |
| 消防车道 | 净宽 4.0 m 起、转弯半径 12 m 起（常见工程惯例区间，以现行规范为准） |
| 净高底线 | 地下车库层高 2.2–2.4 m（常见工程惯例区间，以规范与车型为准） |
| 无障碍路径 | 通行路径在总图与首层平面上连续（最终合规由持证专业人员复核） |
| 不确定性 | 承重墙、管线、标高无法确认的一律标 `uncertain = true` 并进校核阻断项 |

## 硬性规则
1. 不判定承重结构的可拆改；凡涉及承重的结论须由结构专业在项目所在地复核签署。
2. 不把照片或图纸推断当实测：未实测的尺寸标为推断值，不得直接作为设计基准。
3. **不确定信息必须标 `uncertain = true`**，并在校核中作为阻断项。
4. 结构安全、消防、无障碍、机电负荷与当地法规符合性不在本能力结论范围内。
5. 平台未接入时只交付条件报告并标 `awaiting_platform`，绝不写占位图、绝不改道第三方。
6. 不引用外部品牌名、商业站点或推广链接。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 把图纸尺寸当实测尺寸 | 平面做到一半发现对不上 | 未实测的一律标推断值 |
| 未识别承重墙就当可拆 | 方案无法落地 | 结构属性不明项标 `uncertain` |
| 只画人流不画货流与垃圾流 | 运营期动线冲突 | 五类流线全画并检查交叉 |
| 忽略市政接入点标高 | 地下室排水方案后期失效 | 标高列为约束并待现场核对 |
| 日照通风只在文字里描述 | 缺乏体块级验证 | 朝向判断落到具体采光面 |
