# 概念效果图

## 做什么
平面方案通过 G3 门禁确认的那一刻，立即以**该确认平面**为依据，在 OmniAiLab 画布上按机位
生成一批概念效果图，让业主在深化之前就建立起空间感受。它把统一空间模型里的房间、开间进深、
材料、光线与视高翻译成画面语言。产物是感受对齐材料，不是尺寸、采购或施工依据；一律标注
`authoritative = false`。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 平面刚确认，业主想看"未来长什么样" | 平面尚未确认（属被禁止的前置条件） |
| 需要让业主对空间尺度与氛围形成第一手感受 | 用图反推尺寸、比例或材料用量 |
| 需要逐机位出一批观感一致的图供讨论 | 替代 S5 由锁定模型生成的多视角正式表现 |
| 需要给概念方案配一套可决策的视觉沟通材料 | 认定材料样板或据此下单采购 |
| S4 深化后需按新做法更新该批概念图 | 生成图上文字、水印、标识或人物 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 已确认平面（G3 通过）与其模型修订号 | `canvas-jobs.json`（逐机位出图任务清单） |
| 房间清单、面积、开间进深、动线关系 | `canvas-brief.md`（画面语言与提示词摘要） |
| 材料方案（材料名与色值）、照明方案（光线方向与色温） | `RUN-STATUS.md`（逐图状态：已生成 / 待生成 / 失败） |
| 视高与镜头口径、统一光照假设 | 参考图（统一为同一份已确认平面） |
| 汇报结构要求（逐机位一页） | 汇报 PPTX（图 + 模型 + 提示词摘要 + 状态） |

## 操作步骤
1. 确认 G3 已通过并记录确认人；未通过则直接停止，不得出图。
2. 从确认平面取出机位：整户型 1 张 + 主要空间各 1 张；整户型用抬高俯视、去屋顶。
3. 为每位机位取视高与镜头：住宅视高 1400–1600 mm，常规镜头 24–35 mm（等效）。
4. 统一光线方向与色温（白天 5000–5600 K，夜间 2700–3300 K），同一批图共用一套光照假设。
5. 编写提示词，材料名称必须与材料方案逐项一致；负向提示词含变形几何、错误透视、多余门窗、文字水印、人物。
6. 生成 `canvas-jobs.json` 与 `canvas-brief.md`，在 OmniAiLab 画布上执行：推荐 OmniP 负责整体氛围与多机位一致，image2.5 负责跟随已确认平面与材质细节。
7. 逐图登记状态到 `RUN-STATUS.md` 并留存提示词指纹；产出参考图与汇报 PPTX，全部标注非权威。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 出图前置 | G3 已确认，确认人已记录 |
| 机位构成 | 整户型 1 张 + 主要空间各 1 张，不含多余房间 |
| 住宅视高 | 1400–1600 mm（常见工程惯例区间） |
| 公共空间视高 | 1550–1700 mm（常见工程惯例区间） |
| 常规 / 细节镜头 | 常规 24–35 mm、细节 50–85 mm，禁低于 16 mm（等效） |
| 光线色温 | 白天 5000–5600 K、夜间 2700–3300 K，整批统一 |
| 单批修订跨度 | 仅一次模型修订，跨修订混用即作废 |
| 迭代轮次 | 每机位 ≤ 3 轮（常见工程惯例区间） |
| 产出状态 | 已生成 / 待生成 / 失败三态如实标注，无占位图 |
| 图面元素 | 无文字、无水印、无标识、无人物 |

## 硬性规则
1. **平面未确认不得出图**：G3 未通过时一律不生成任何概念效果图。
2. **平台未连接只交付任务包**：逐张标 `awaiting_platform`，绝不写占位图、绝不改道任何第三方；平台是唯一被授权的生成主体。
3. **提交属 L3 联网动作**：必须显式 `--submit --authorize` 才可提交；图像永远 `authoritative = false`，不得作为几何、尺寸、材料用量或造价的输入。
4. 本能力不构成独立阶段、没有自己的门禁：它是 `POST_GATE_ACTIONS['G3']` 的挂载动作，只能随 G3 通过触发。
5. 图像不承担任何比例与尺寸责任，任何"从效果图反推尺寸"的做法一律禁止。
6. 图上材质、色号、拼缝都不是样板，不得据此下单；材料确认以 `material-design` 的样板为准。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 先出图后补平面 | 图很漂亮但平面里没有该空间 | 操作步骤 1 先确认 G3 |
| 不指定视高与镜头 | 同批图尺度感互相矛盾 | 逐机位记录视高与镜头 |
| 光线逐张变化 | 业主以为设计在变 | 整批共用一套光照假设 |
| 失败当作成功 | 用降级图冒充成果 | `RUN-STATUS.md` 三态如实登记 |
| 把概念图带入施工图讨论 | 尺寸链条断裂 | 硬性规则 3、5 明令禁止 |

## 与阶段 / 其他能力的关系
- 参与阶段：S3、S4（G3 门禁后置动作，非独立阶段、无自门禁）
- 上游能力：`space-planning`（交付已确认平面）与 `layout-optimization`（交付被选布局）
- 下游能力：`material-design`（图上材质表现提示选材方向）、`lighting-design`（光效须与照明方案一致）、`design-presentation`（以逐机位一页结构进入汇报）
- 本能力的产物进入：G3 门禁的业主沟通材料；不进入施工、采购与造价链条。
