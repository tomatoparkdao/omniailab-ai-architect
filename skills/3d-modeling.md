# 3D 空间建模

## 做什么

把统一空间模型（Canonical Spatial Model）翻译成可编辑的三维场景：墙体、天花、地面、构件与家具按真实尺寸建立，尺寸可追溯至模型修订。产物用于后续渲染、漫游与几何校核，而不是用来替代设计判断。本仓内置的是**三角 / 多边形网格（OBJ + MTL）**：它是几何外壳，**不是参数化 BIM**，不带构件参数与信息属性。

## 什么时候用 / 不用

| 用 | 不用 |
|---|---|
| 平面与初步设计已确认，要为表现阶段建立三维场景（S5） | 判定结构安全或配筋是否成立 |
| 需要一份可编辑、可复用的场景几何用于多视角出图 | 生成最终效果图（见 scene-rendering / ai-visualization） |
| 需要核对体量、层高、构件关系是否与平面一致 | 承载构件参数、IFC 与专业协同信息（见 bim-modeling） |
| 需要为漫游与全景准备统一坐标系下的场景 | 用三维模型反推施工尺寸作为放线依据 |
| 需要把空间序列做成可被相机遍历的几何 | 做机电系统计算或负荷核算 |

## 输入 → 输出

| 输入 | 输出 |
|---|---|
| 统一空间模型当前修订 | `scene-r<rev>.obj`（三角 / 多边形网格几何） |
| 界面做法与构件尺寸（S4 已确认） | `scene-r<rev>.mtl`（材质外壳定义） |
| 材料与色彩方案（名称、色值） | `camera-set.json`（机位定义：位置、视高、镜头） |
| 照明方案的发光面与色温 | `model-manifest.json`（模型修订号、单位、坐标原点、构件来源） |
| 家具尺度与布置（S3 / S4） | `geometry-report.json`（体量、层高、净高校核结果） |
| 建模约定（单位、原点、命名） | 缺项与不确定项清单（标 `uncertain = true`） |

## 操作步骤

1. 读取模型当前修订，确认单位为 mm、坐标原点唯一，并记录修订号到 `model-manifest.json`。
2. 按"先结构外壳、后界面、再固定家具"的顺序建立几何；构件按统一命名规则组织。
3. 赋予材质外壳（名称与色值取自材料方案），不臆造方案中没有的材料。
4. 定义机位集合：位置、视高、镜头，与 ai-concept-visualization 的机位语言一致。
5. 校核体量与层高：净高、门洞、开间进深与模型一致，偏差记录进 `geometry-report.json`。
6. 自检：几何无无意义穿插、无孤立冗余面，单位与原点统一。
7. 交付 OBJ / MTL 与机位集；若委托方需要参数化模型或 IFC，转交 bim-modeling。

## 判断清单（可判定的判据）

以下均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地实践为准。

| 判据 | 判准 |
|---|---|
| 网格精度与用途匹配 | 表现用 LOD200–LOD300 量级，不盲目堆高面数（常见工程惯例区间） |
| 单位与坐标 | 统一 mm，原点唯一，与制图 / BIM 同坐标系 |
| 尺寸可追溯 | 每个构件能回溯到模型修订号与平面依据 |
| 视高设置 | 住宅 1400–1600 mm、公共空间 1550–1700 mm（常见工程惯例区间） |
| 材质来源 | 材质名称与材料方案逐项对应，无方案外材料 |
| 几何洁净度 | 无无意义穿插、无孤立面、无重复构件 |
| 文件规模 | 单场景控制在可协同的体量，避免高面数拖慢出图 |
| 深度命名 | 只声明为"可编辑网格场景"，不得声明为参数化 BIM 或 IFC 模型 |

## 硬性规则

1. **网格 ≠ 参数化 BIM**：OBJ / MTL 是几何网格，不含构件参数、属性与信息模型；本仓不得把网格场景称为 BIM。
2. **不得虚构后端**：内置只保证 OBJ 网格写出；Blender / FreeCAD 为可选，缺失时降级并如实标注。
3. R1 前置：业主确认功能需求之前不得开始精细建模。
4. 模型几何仅作表现与校核依据，**不得作为施工放线的尺寸依据**；放线以施工图与持证复核为准。
5. 不确定信息标 `uncertain = true`，并作为阻断项上报，不得以默认值掩盖。

## 常见坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 把 OBJ 网格当 BIM 交付 | 对方无法统计构件与信息，误解为信息模型 | 明确网格≠参数化 BIM，需信息模型转 bim-modeling |
| 机位不统一，模型自由出图 | 同一批表现尺度感互相矛盾 | 先定 camera-set.json，再出图 |
| 臆造方案外材质 | 画面与材料方案脱节，误导选材 | 材质名称逐项取自材料方案 |
| 无意义几何穿插未清理 | 量算失真、出图出现穿模 | 建完做洁净度检查 |
| 高面数构件过多 | 文件沉重、协同与渲染变慢 | 按用途选网格精度，控制面数 |

## 与阶段 / 其他能力的关系

- 参与阶段：S5
- 上游能力：空间规划（交付已确认平面）、室内设计（交付界面做法与家具布置）
- 下游能力：场景渲染（消费场景几何做多视角出图）、漫游与多视角表现（消费坐标系做序列）、BIM 建模（如需信息模型则承接深化）
- 本能力的产物进入：S5 表现成果、G5 表现成果确认门禁材料、模型交付清单
