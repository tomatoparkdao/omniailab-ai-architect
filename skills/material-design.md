# 材料与色彩设计

## 做什么
把设计意图翻译为可采购、可施工、可维护的实体，同时受美学、性能、造价、工期、环保、安全
六个维度约束。它负责材料组合、色彩体系、工艺与规格、面积占比，向上承接设计意图，向下决定
构造做法与物料清单。给出的是常见规格与做法区间，不构成防火环保安全的合规结论。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 需要定地面、墙面、天花、固定家具的材质体系 | 判定结构的承重材料与配筋 |
| 需要给出主材编号、色彩体系与面积占比 | 做材料燃烧性能的最终判定 |
| 需要出排版图、收口方式与样板计划 | 选具体品牌与供应商 |
| S5 需要为表现提供材料名与色值 | 做机电设备选型 |
| S8 需要编制物料清单（规格、用量、损耗、替代） | 判定环保检测是否合格（转待复核） |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 室内设计交付的材质基调与界面条件 | `material-schedule-r<rev>.json`（主材表：编号 + 名称 + 规格 + 部位） |
| 照明条件（色温、显色性） | 材质样板清单（实物或照片 + 编号） |
| 构造与收口意向（`construction-detailing` 回传） | 排版图（瓷砖、石材铺装起点与分缝） |
| 造价分档与自适应口径 | 色彩体系说明（主色 / 辅色 / 点缀色 + 部位） |
| 运输通道尺寸（电梯、楼梯） | 物料清单（S8：规格 + 用量 + 损耗 + 替代方案） |

## 操作步骤
1. 按功能分区确定材料档次分级：重点区高完成度，辅助区低完成度，界面对齐不打架。
2. 为每种材料分配唯一编号，与图纸标注一一对应，写入主材表。
3. 校核材料性能与部位匹配：潮湿区防水耐水，高频通行区耐磨，隐蔽区不堆砌奢材。
4. 定规格与排版起点，评估大板材料的搬运上楼与现场切割可行性。
5. 定收口方式（压条、凹缝、密拼）与材料厚度，写进节点而非口头约定。
6. 协调材料与照明：核对反射率与显色需求，避免洗墙灯"洗掉"材质质感。
7. 出样板并经业主书面确认；S5 输出材料名与色值供表现；S8 编制含损耗与替代的物料清单。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 地砖 / 墙砖规格 | 地砖 600×600、800×800 mm；墙砖 300×600、600×1200 mm（常见工程惯例区间） |
| 石材台面 / 地面厚度 | 台面 18–30 mm、地面 18–25 mm（常见工程惯例区间） |
| 木地板 / 木饰面板厚度 | 木地板 12–18 mm、木饰面板 12–18 mm（常见工程惯例区间） |
| 玻璃厚度（隔断 / 夹胶） | 隔断 8–12 mm 钢化；夹胶 6+6、8+8 mm（常见工程惯例区间） |
| 地面防滑等级 | R9–R11，潮湿区取高值（常见工程惯例区间） |
| 材料损耗率 | 瓷砖 5%–10%、石材 8%–15%（常见工程惯例区间） |
| 主材编号 | 与图纸标注一一对应，无重复无遗漏 |
| 潮湿区材料 | 采用防水或耐水材料，并说明基层防水做法 |
| 样板确认 | 经业主书面确认后才进入批量采购 |
| 替代方案 | 每种主材有同等性能的备选，应对断供 |
| 材料与照明 | 反射率、色温、显色已协调，无质感被洗平 |

## 硬性规则
1. 不对材料燃烧性能、环保等级与放射性下最终结论；须由持证专业人员在项目所在地复核签署。
2. 未封样材料不得进入采购流程；不得用效果图上的"看起来像"替代真实样板。
3. 材料档次分级须与造价分级一致，不得在隐蔽处堆砌奢材。
4. 不代业主决策：给推荐 + 理由 + 备选，不写"两套都行"。
5. 主材编号、图纸标注、样板三者必须一致；任一处变更须同步全部相关文件。
6. 规格与厚度一律标注为常见工程惯例区间，不得写成法定强制值。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 主材编号与图纸标注不一致 | 施工阶段选错材料 | 操作步骤 2 强制唯一编号 |
| 潮湿区用不防水材料 | 后期发霉返工 | 性能与部位逐项匹配 |
| 大板进不了电梯或楼梯 | 现场被迫改小、破坏排版 | 操作步骤 4 评估运输与切割 |
| 忽略批次色差 | 成品墙面色块不均 | 设定验收容差 |
| 未提供维护说明 | 业主长期维护无依据 | 交付含清洁与保养要求 |

## 与阶段 / 其他能力的关系
- 参与阶段：S4、S5、S8
- 上游能力：`interior-design`（交付材质基调）、`ergonomics`（回传完成面厚度对净尺寸的影响）、`lighting-design`（交付照明条件）
- 下游能力：`construction-detailing`（接收材料厚度与收口方式）、`bim-modeling`（输出材料属性数据）、`material-schedule` / `quantity-takeoff`（编制物料与工程量）
- 本能力的产物进入：G4 材料方案确认材料；S5 表现的材料依据；S8 交付包的物料清单。
