# 意向板与审美迭代

## 做什么
把概念阶段的方向感翻译成可打分的意向板：先用关键词锚定审美目标，再用固定框架量化打分，最后跨轮追踪整改，让"好不好看"变成"哪一维度差几分、下一轮改什么"。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 业主要求"给我一版意向板 / 参考图集" | 判定材料燃烧性能或环保等级是否达标 |
| 概念方向需要被量化比较 | 出正式材料清单与用量 |
| 需要跨轮迭代并追踪整改 | 替代概念主张与平面逻辑 |
| S5 表现前要锁定审美基调 | 出可施工的节点与做法 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 概念主张与四个可验证维度 | `moodboard-r{n}.png` — 意向板（含材质与色调倾向） |
| 业主风格偏好与禁忌 | `keywords.json` — 三组关键词（基调用词 / 材质用词 / 排除用词） |
| 原创知识库 · 已授权图像（素材库仅供调研） | `moodboard-scores.json` — 量化打分表（维度 + 分值 + 依据） |
| 上一轮评审意见与整改项 | `iteration-log.md` — 跨轮整改追踪（意见 → 改动 → 核销） |
| 材料档次与造价档位 | `moodboard-r{n}.pptx` — 意向板汇报 |

## 操作步骤
1. 从概念主张提取审美目标，写成三组关键词：基调、材质、排除项。
2. 需要看前沿案例时，去素材库（`docs/REFERENCE_SOURCES.md`）做方向调研：
   只提取可验证特征并记进 `reference-log.md`，原图不下载、不进交付物。
3. 组织意向板：冷调打底、暖色点睛，同一纹理至少给出三种密度。
4. 用固定框架量化打分：先看 200ms 第一印象，再走 Design Critic 六维，最后做 60-30-10 拆色。
5. 对每条打分写明依据，分数只来自可观察特征，不写"感觉不错"。
6. 与上一轮对比，列出本轮整改项与被延后项，逐条追踪到核销。
7. 锁定口径：同一项目内评分体系不得中途更换，否则跨轮分数不可比。
8. 出具 `moodboard-r{n}` 供 G2 / G5 确认，确认后关键词与材料占比既定。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 关键词锚定 | 三组关键词齐备，排除项明确列出 |
| 冷暖对峙 | 冷调打底、暖色点睛，暖材占比 ≤40%（常见工程惯例区间） |
| 黑作重音 | 黑色占比 3–8%，作重音不作块面（常见工程惯例区间） |
| 纹理分密度 | 同一纹理至少给出三种密度，避免整面同质 |
| 配色校验 | 60-30-10 配比 + 黑色 5% 独立校验 |
| 200ms 第一印象 | 描述可观察特征，不使用不可验证形容词 |
| 口径一致 | 评分体系跨轮不更换，否则分数不可比 |
| 整改闭环 | 每条意见进入台账，跨轮可追踪、可核销 |

## 硬性规则
1. 意向板只定倾向，不定材料清单与结算价格。
2. **参考图分两层**：调研级可用素材库看趋势与流行手法，但只带走结论（关键词、比例、
   材质组合）；进意向板与汇报的**图像**必须来自原创知识库、已授权内容或本系统产出，
   不引用第三方事务所自有作品。分层判据见 `docs/REFERENCE_SOURCES.md`。
3. **不代业主决策**：给推荐 + 理由 + 备选。
4. 打分依据必须可观察，禁用"高级""大气"等形容词。
5. 材料燃烧性能、环保等级等合规要求不在本能力结论范围内，须由持证专业人员复核签署。
6. 平台未接入时只交付意向板任务包并标 `awaiting_platform`，绝不写占位图、绝不改道第三方。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 意向板只有图没有关键词 | 后续轮次无法对齐 | 词先于图，三组关键词锚定 |
| 中途更换评分体系 | 跨轮分数不可比 | 口径一次锁定、全项目沿用 |
| 打分全是形容词 | 争议无法收敛 | 分数只来自可观察特征 |
| 素材库的图直接贴进意向板 | 版权风险，业主会误以为是本方案 | 只带走结论；图像用自有或已授权内容 |
| 参考图只存不记来源 | 后面说不清结论从哪来 | 逐条登记 `reference-log.md` |
| 意见不落台账 | 同类问题反复出现 | 逐条核销、跨轮追踪 |

## 与阶段 / 其他能力的关系
- 参与阶段：S2, S5
- 上游能力：`concept-design`（概念主张）、`material-design`（材料档次）
- 下游能力：`scene-rendering`（按此基调出图）、`material-design`（材料与色彩体系）、`design-presentation`（意向板汇报）
- 本能力的产物进入：G2 概念确认材料、G5 表现成果确认依据
