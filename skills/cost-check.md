# 造价适配

## 做什么
把方案的各阶段成果翻译成**区间口径的造价估算**，判断方案是否落在业主预算区间内，并在超预算时给出可执行的取舍建议。
它从 S1 就开始工作：没有平面时按套内轮廓与任务书面积估，随深化逐步用实测值替换假设，到 S6 完成预算适配。
估算是"够不够做决策"的量级判断，量价分离、随阶段收敛，**不构成结算依据**。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 业主要求"这个方向大概要多少钱"（S1 起） | 出具可作为结算或招标依据的正式造价 |
| 平面方案比选时要比较两套的造价影响（S3） | 替代造价咨询单位或持证造价专业人员的成果 |
| 初步设计要确认"造价仍在预算区间内"（S4） | 核定材料品牌单价与供应商报价 |
| 定稿前要做最后一次预算适配（S6） | 决定付款、结算或索赔金额 |
| 材料或做法变更要重算对造价的冲击 | 承诺最终决算不超预算 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 设计任务书的预算区间与目标入住时间 | `cost-baseline.json`（估算基线：基数来源 + 假设 + 置信度） |
| 当前阶段的面积与工程量口径（统一空间模型 / 工程量计算） | `estimate-r<revision>.json`（区间估算：分项 + 低/中/高值） |
| 材料档次与规格（材料与饰面选择） | `cost-breakdown.json`（分项占比：硬装 / 软装 / 机电 / 家具） |
| 机电占位与设备档次（机电与设备协同） | `budget-fit-report.md`（是否落区间 + 超支点 + 取舍建议） |
| 上一轮估算与预算偏差记录 | `cost-risk.md`（造价风险：断供、涨价、变更敏感项） |
| 方案比选结果（各方案造价影响） | `cost-comparison.json`（多方案造价对比） |

## 操作步骤
1. 读取当前阶段可得的面积、工程量与做法口径，写明估算基数（实测 / 任务书 / 轮廓估算）。
2. 按分项列区间估算：分别给硬装、软装、机电、家具的低/中/高值，而不是一个点数。
3. **量价分离**：工程量与单价分列；单价只作参考区间，不绑定任何品牌。
4. 与预算区间比对，判断落在区间内 / 贴近上限 / 超支，并标出超支的主要分项。
5. 超支时给取舍建议：给推荐 + 理由 + 备选（换档次 / 调范围 / 留待后期），不代业主决策。
6. 标出对变更最敏感的项与受市场波动影响的项，写进造价风险。
7. 随阶段推进，用实测值替换假设值并重出估算，记录与上一轮的偏差变化。

## 判断清单（可判定的判据）
以下数值均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 判据 | 判准 |
|---|---|
| 估算落区间 | 中值应落在业主预算区间内；贴近上限需预警（常见工程惯例区间） |
| 阶段偏差收敛 | 深化后估算与预算偏差 ≤10% 且可解释（常见工程惯例区间） |
| 不可预见费 | 预留 5%–10% 应对变更与涨价（常见工程惯例区间） |
| 材料损耗率 | 瓷砖 5%–10%、石材 8%–15%，计入用量（常见工程惯例区间） |
| 档次与造价一致 | 材料档次分级与造价分级一一对应，不出现档位错配 |
| 软硬装占比 | 分项占比与项目类型经验区间可解释（常见工程惯例区间） |
| 基数声明 | 每份估算必须写明基数来源与假设，无基数不得出数 |
| 不确定信息 | 由图纸推断的面积/做法标 `uncertain = true`，超预算判断中作为阻断项 |

## 硬性规则
1. **R3 铁律**：成本估算自 S1 起动态进行，随深化逐步收敛，S6 完成预算适配；不得拖到 S8 才第一次算。
2. **量价分离**：工程量与单价分列，单价只作参考区间，不绑定品牌。
3. **方案阶段估算不构成结算依据**；不得写成"造价 / 决算 / 报价"，不得承诺最终不超预算。
4. 不代业主决策：超支时给推荐 + 理由 + 备选，不写"两套都行"。
5. 无基数不出数：不得用占位数据冒充估算结果；平台未接入时标 `awaiting_platform`。
6. 不越界到结算与法定造价：本能力只做预算适配，不承担造价咨询签署责任。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 到最后阶段才算一次预算 | 造价风险全压到末端，方案被迫大改 | 自 S1 起逐阶段滚动估算 |
| 估算只给一个点值 | 看似精确、实则误导 | 给低/中/高区间 |
| 量价混在一起给总价 | 无法判断是量多还是价高 | 量价分离分列 |
| 逐轮估算基数漂移却不记录 | 前后不可比 | 每轮记录基数与偏差 |
| 忽略损耗与不可预见费 | 落地超支 | 计入损耗率与 5%–10% 不可预见费 |
| 把估算写成结算依据 | 越界承诺，责任外溢 | 明确标注非结算依据 |

## 与阶段 / 其他能力的关系
- 参与阶段：S1、S2、S3、S4、S5、S6
- 上游能力：设计任务书（提供预算区间）、工程量计算（提供量）、材料与饰面选择（提供档次与损耗）
- 下游能力：设计汇报与提案（接收造价页）、设计审核（接收预算适配结论）、版本管理（接收造价基线）
- 本能力的产物进入：G1 任务书确认的预算口径、G3/G4/G6 各阶段确认材料、S6 预算适配结论
