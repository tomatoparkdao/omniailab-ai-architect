# 机电与设备协同

## 做什么
把电气、给排水、暖通、消防、智能化五类系统的空间需求，翻译成吊顶前后可执行的占位、净高剖面、管线走向与末端点位。
它协调的是"空间与接口"——吊顶里怎么排队、管井够不够、机房放哪、净高最不利点成不成立。
它不进行负荷计算、设备选型与配电系统设计，只看空间与接口能不能对上。
输出净高控制条件、管井与机房占位、管线综合与预留洞清单，供结构与装修同步施工。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 业主要求"吊顶别太低，先算算还能留多少净高" | 判定结构荷载、消防系统是否满足当地法规 |
| 平面确认后需要预留机房、管井与主要管线路径（S4） | 计算空调冷负荷、配电容量或水管流量 |
| 定稿前要统一风口、喷淋、烟感、灯位的天花排布（S6） | 选定设备品牌型号并出具采购参数 |
| 施工图阶段做管线综合、碰撞检查与预留洞图（S7） | 判断是否存在规范强制的最低净高或机房面积 |
| 界面或天花变更后要复核净高与点位是否需重排 | 承担机电专业的设计签署责任 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 统一空间模型当前修订（房间边界、层高、柱网） | `net-height-conditions.json`（净高控制条件表，逐房间最不利点） |
| 平面与吊顶做法（标高、跌级、检修口意向） | `net-height-section.dxf`（最不利点净高剖面，标注各层管线标高） |
| 功能分区与敏感房间清单（卧室、会议室、洁净区） | `mep-reserve.json`（机房、管井与主干管线占位） |
| 专业工程师提供的设备清单与管线尺寸（无则标待定） | `mep-coordination.dxf`（多专业管线综合图） |
| 天花造型与末端功能需求（风口、喷淋、烟感、灯位） | `terminal-layout.json`（末端点位协调表，含回路编号占位） |
| 结构预留条件（预留洞、预埋件有无） | `reserved-openings.dxf` + `coordination-report.md`（冲突记录 + 待专业复核项） |

## 操作步骤
1. 读取模型当前修订，按房间列出层高、吊顶标高与允许占用的吊顶内空间。
2. 定义管线"主干道"优先级：小管让大管、有压让无压、临时让永久、电在上或做防护。
3. 在每层最不利点（管线交叉处）画净高剖面，算出完成面到最低障碍物的净距。
4. 校核管井上下贯通与尺寸、机房面积与设备清单、设备运输路径（电梯、门洞、吊装口）。
5. 统一末端点位：风口、喷淋、烟感、灯位、扬声器按同一模数排布，检修口可开启且不被造型遮挡。
6. 标记冲突点与无法满足项，把预留洞与机电条件回写，供结构在施工前预留。
7. 凡涉及负荷、容量、消防的疑问一律不判定，写入待专业复核清单。

## 判断清单（可判定的判据）
以下数值均为**常见工程惯例区间**，非当地法定强制值，须以项目所在地现行规范与专业复核为准。

| 判据 | 判准 |
|---|---|
| 每层最不利点净高已校核 | 办公 ≥2.6 m、走廊 ≥2.3 m（吊顶后，常见工程惯例区间） |
| 吊顶内综合净空 | 办公常用 400–800 mm，能同时容纳风管+桥架+水管（常见工程惯例区间） |
| 桥架与水管分层 | 层间距 ≥150 mm（常见工程惯例区间） |
| 强弱电间距 | ≥300 mm，或做隔离防护（常见工程惯例区间） |
| 冷凝水与排水坡度 | 冷凝水 ≥0.8%，排水横管 1%–3%（常见工程惯例区间） |
| 检修口与操作距离 | 检修口 300×300 起；机房检修通道 700–1000 mm（常见工程惯例区间） |
| 风口与喷淋间距 | ≥500 mm，防吹湿误报（常见工程惯例区间） |
| 不确定信息 | 由图纸推断而非实测的尺寸标 `uncertain = true`，在协调报告中作为阻断项 |

## 硬性规则
1. **机电负荷、容量与消防结论不在本系统结论范围内**，须由持证专业人员在项目所在地复核签署；本能力只协调空间与接口。
2. **不把"机电协调完成"写成"安全合规"**；协调通过只表示占位不冲突，不代表系统成立。
3. 不确定尺寸一律标 `uncertain = true` 并作为阻断项，不得把推断当实测。
4. 未拿到设备清单时，管线尺寸按区间占位并声明基数，**不得编造确定断面**。
5. 不代业主决策：净高与造价的取舍给推荐 + 理由 + 备选，不写"两套都行"。
6. 预留洞与预埋件条件必须在结构施工前提出，不得留到结构完成后补洞。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 净高只在典型房间校核 | 漏掉管线交叉的不利点，现场吊顶被迫降低 | 逐层取最不利点画剖面 |
| 管线无主次全面铺开 | 交叉无数，现场临时抬降 | 先定主干道与避让优先级 |
| 风管与桥架标高打架 | 拆改返工，工期与造价双输 | 综合图分层间距 ≥150 mm 并出碰撞记录 |
| 管井尺寸不足 | 立管挤不下或无法检修 | 按立管数量加检修裕量核定井道 |
| 主风管穿越卧室等敏感空间上方 | 噪声与净高双输 | 分区标注允许穿越限制 |
| 天花图与管线综合图版本不一致 | 施工装错，末端错位 | 两图同源同版本，变更后同步回写 |

## 与阶段 / 其他能力的关系
- 参与阶段：S4、S6、S7
- 上游能力：空间规划（提供机房与管井位置）、室内设计（提供吊顶标高与造型）、灯光设计（提供灯具回路）
- 下游能力：施工深化与节点（接收预留洞与收口处理）、专业协调校核（接收净高与末端接口）、工程量计算（接收管线与设备占位量）
- 本能力的产物进入：G4 初步设计确认材料、G6 锁定深化依据、G7 施工图审查记录
