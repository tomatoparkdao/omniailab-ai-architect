# 建筑设计

## 做什么
在建筑项目里负责体量、立面、剖面与空间组织：把功能分区、竖向交通、朝向与场地关系组织成一个自洽的整体，并给出首层 / 标准层 / 设备层 / 屋顶层各自的策略。室内项目不启用本能力。

## 什么时候用 / 不用
| 用 | 不用 |
|---|---|
| 建筑项目要定体量、总图与楼层策略 | 室内改造项目（改走 `space-planning` / `interior-design`） |
| 要判断立面开窗与内部功能是否匹配 | 出结构配筋与构件截面 |
| 要组织竖向交通与竖向分区 | 判定消防疏散是否最终合规 |
| 要比较 2–3 个体量方向 | 出施工图节点大样 |

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| `design-brief` 任务书与面积指标 | `massing-options.md` — 2–3 个体量方向比选 |
| `site-conditions` 场地、朝向与退线 | `floor-strategy.md` — 楼层策略表（首层 / 标准层 / 设备层 / 屋顶层） |
| 规划限高与容积率约束 | `section-netting.md` — 净高估算表（结构 / 机电 / 吊顶 / 净高，mm） |
| 结构、机电初步接口 | `circulation-diagram.png` — 五类流线图（交叉点加注） |
| 造价与完成度分级 | `architecture-r{n}.pptx` — 体量与楼层策略汇报 |

## 操作步骤
1. 核对任务书与规划条件：面积指标、限高、容积率、退线、消防车道是否自洽。
2. 生成 2–3 个体量方向，比较场地回应、成本与可建性，写明各自代价。
3. 组织功能分区与竖向分区：裙房 / 塔楼 / 地下室的功能与交通衔接要清晰。
4. 布置核心筒与竖向交通，按使用效率加权定位，而非几何中心。
5. 分列首层、标准层、设备层、屋顶层的独立策略，不做简单复制。
6. 做净高估算：逐层扣减结构、机电、吊顶后核对净高底线。
7. 核对立面开口率与内部功能匹配，出具体量与楼层策略供 G1 / S4 确认。

## 判断清单（可判定的判据）
| 判据 | 判准 |
|---|---|
| 面积映射 | 每块功能面积都能对应任务书条目，无"为了填满平面"的冗余空间 |
| 核心筒定位 | 核心筒位于使用效率加权中心，而非几何中心 |
| 流线分离 | 公共流线与服务流线无强制交叉；若交叉须写明错峰或物理分隔 |
| 净高底线 | 逐层扣减结构 + 机电 + 吊顶后净高 ≥ 功能最低值；办公 ≥2.6 m、走廊 ≥2.3 m（常见工程惯例区间） |
| 层间占用 | 梁下净高占用 400–900 mm（含风管）（常见工程惯例区间） |
| 得房率 | 住宅 75%–85%、办公 65%–78%（常见工程惯例区间） |
| 消防车道 | 净宽 4.0 m 起、转弯半径 12 m 起（常见工程惯例区间，以现行规范为准） |
| 楼层差异化 | 首层 / 标准层 / 设备层 / 屋顶层各有独立策略，非单一"通用层"复制 |
| 立面匹配 | 外立面开口率与内部功能匹配（机房少开窗、展示面多开窗） |

## 硬性规则
1. 不判定结构构件截面与配筋；涉及结构安全的结论须由持证专业人员在项目所在地复核签署。
2. 不判定消防疏散、无障碍合规与机电负荷；此类项只标注"待专业复核"。
3. 建筑退线、限高、容积率不可自行假设，须以当地规划条件为准。
4. 不使用"绝对安全""零风险"等不可兑现措辞。
5. **不代业主决策**：体量方向给推荐 + 理由 + 备选。
6. 平台未接入时只交付方案任务包并标 `awaiting_platform`，绝不写占位图、绝不改道第三方。

## 常见坑
| 坑 | 后果 | 怎么避 |
|---|---|---|
| 核心筒居中于几何中心 | 得房率低、使用效率差 | 按使用效率加权定位 |
| 用单一"通用层"复制所有楼层 | 首层、设备层失效 | 逐层给独立策略 |
| 净高只查典型处 | 最不利点不达标 | 查最不利点净高 |
| 立面追求效果忽视功能 | 立面与内部对不上 | 开口率与功能分区对位 |
| 结构机电方案阶段缺席 | 深化被迫大改 | 方案阶段预留接口与管井 |
| 日照通风只在文本描述 | 缺乏体块级验证 | 做体块级朝向验证 |
