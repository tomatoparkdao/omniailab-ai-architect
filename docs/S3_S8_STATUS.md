# S3–S8 实况：哪一步真出东西，哪一步还差什么

> 本轮停止 S1／S2 的所有视觉与检索优化，只做一件事：让方案阶段之后的六步
> 真的产出可打开、可编辑、可继续深化的文件。三个真实项目跑到底，逐项打开验证。

## 一、八阶段当前状态

| 阶段 | 状态 | 实际产出 | 边界（明确不做/未做） |
|---|---|---|---|
| S1 项目启动 | 可用 | 任务书、访谈、可行性、判断一页 | 无变化（本轮不动） |
| S2 概念方案 | 可用 | 2–3 套方向、图版、四步、汇报 PPTX/HTML | 无变化（本轮不动） |
| S3 平面方案 | 可用 | 方案 A/B、面积表、方案深度 DXF、总平面（行业项目）、逐层平面 DXF | 退界、消防车道、结构柱网未核 |
| S4 初步设计 | 可用（方案深度） | 顶面／地面分区 CAD（室内）、立面／剖面（教育）、材料与灯光数据、景观深化 | 节点大样、幕墙与构造未做 |
| S5 三维表现 | 可用（几何真实） | 可编辑 OBJ+MTL、逐层 OBJ、Blender 场景脚本、IFC 投影、机位任务、轴测检视图（带房间名） | 无 Blender 时无 .blend／写实渲染；无 IfcOpenShell 时无真 IFC |
| S6 定稿与协调 | 可用（未锁定） | 校核报告、专业协调清单、造价适配、未闭环项 | 结构/消防/机电须持证人员确认；不声明"已冻结" |
| S7 施工图 | 部分可用 | 平面布置、房间面积、家具定位、顶面、地面、总平面、立面、剖面（DXF，可读回） | 无节点详图、无门窗表深化、无机电图；不得用于施工 |
| S8 物料与交付 | 可用（预览包） | 工程量、材料表、造价区间、交付清单、变更记录、待审查事项 | 无采购级清单；未过 G8 时只能出"待审查交付预览包" |

## 二、三个项目实跑

全部从一句客户需求走真实 S1→S2，再用同一份项目文件跑 S3→S8（`--assume-approval`
标记为演示确认，不写业主基准）。产物在 `out/s38/<case>/`。

| 项目 | 专业 | 阶段 | 实跑结果 |
|---|---|---|---|
| 24 班小学新建 | 建筑 | S3→S8 | 4 层逐层平面 DXF（263 实体）＋总平面（含临路与主入口流线）＋南北立面＋体量剖面；整楼 OBJ 3808 顶点 / 2856 面，4 层逐层 OBJ；S4–S8 全部 degraded（立面/节点未完成、无 Blender/IFC） |
| 150 m² 住宅精装 | 室内 | S3→S8 | 2 套平面＋方案深度 DXF；顶面/地面分区 CAD；OBJ 800 顶点/600 面（墙/门/家具材质分组）；3 张带房间名的轴测检视图；工程量 132.94 m²、造价 24.0–71.6 万元；交付包 57 文件／29 成果／3 项未闭环 |
| 800 m² 私家庭院 | 景观 | S3→S8 | 景观总平面 DXF（84 实体，含水景/铺装/种植/环路）＋分区复核图；OBJ 1302 顶点/925 面（材质含水面、种植、铺装、砾石）；面积与工程量按模型统计 |

## 三、这一轮真正修掉的阻断

| 症状 | 根因 | 处理 |
|---|---|---|
| 室内项目进不了 S3："只有文字需求" | 系统没有读业主实测资料的入口，又没有 DXF 导入 | 新增 `omniarchitect/existing.py` + `conditions` 命令：读业主给的轮廓与墙，标不确定项；**不生成几何**，已有轮廓时拒绝覆盖 |
| 住宅项目 read_program 报"没有 program" | 行业项目有 `sector.program`，住宅没有房间任务表 | 新增 `omniarchitect/program.py`：按套内实测面积 × 住宅配比 + 家庭构成推导，每行带 `basis`；面积未知返回空表 |
| 小学 S3 直接抛 ValueError 崩掉 | `site_area` 只认亩/平方米，不认公顷，退回 6000 m² 默认值，总平面放不下 | 补公顷/hectare 换算；放不下改为 `blocked` + 下一步（补红线或调规模），不再抛异常 |
| `run --all` 在已确认项目上报错 | 逐阶段重跑，S1 一确认就"如需修改请走变更影响分析" | 已确认阶段跳过（仍是显式提交记录的 skipped），改设计继续走 `change` |
| `--project .../project.json` 报 WinError 183 | 项目目录被当成文件继续拼 `project.json` | 传文件时取其父目录 |
| 景观 S3 后置动作报 ModelError | 场地没有 envelope 空间，概念效果图不适用 | 后置动作区分"不适用"与"崩溃"，如实写 skipped |
| S8 交付说明写"阶段进度 87.5%" | 包在自己确认前生成 | 改为"覆盖 S3–S8，属待审查交付预览" |

## 四、仍然做不到（如实列出）

* **结构、机电、消防、无障碍、当地法规**：不在结论范围，须持证专业人员在项目所在地复核签署；
* **施工图深度**：S7 现有成果是方案/待审查深度，缺节点详图、门窗表、机电图，不得用于施工；
* **写实渲染与 IFC**：本机无 Blender／IfcOpenShell，只交付可执行工程文件（snapshot、
  `build_scene.py`、`build_ifc.py`）与几何读回投影，不冒充渲染图或真 IFC；
* **工程量**：来自统一模型面积与长度，没有几何依据的项不写数；造价是区间估算，非清单报价；
* **景观竖向与苗木**：只有方案相对标高与种植分区，苗木规格与土方平衡未做；
* **教育配套**：食堂、体育馆、运动场只是体量预留，没有内部房间与结构。
