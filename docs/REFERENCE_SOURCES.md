# 参考图来源与使用边界

项目里凡是"找参考图"，都会被问同一个问题：**这张图能进交付物吗**。答案是分层的——
能不能看，和能不能用，是两件事。这份文档把两者分开，并给出可执行的判据。

## 一、为什么必须分开

素材库汇总的是各设计平台上公开发布的作品，**版权属于原作者**。"公开发布"不等于"可以复制"：
它允许你看、允许你学习其中的处理手法，但不等于授权你把图搬进给业主的意向板与汇报文件。

所以本系统的口径是：

- **看** = 提取视觉语言（构图逻辑、材质搭配、明暗关系、色调比例），产出**结论**；
- **用** = 把图本身放进交付物，这需要有授权，否则不成立。

一个粗糙但有效的判断：**你交出去的东西里，能不能找到一张不是你做的图。** 找不到，就安全。

## 二、两类来源

| 来源 | 能不能看 | 能不能进交付物 | 说明 |
|---|---|---|---|
| 参考图素材库（Luxora AI） | 可以 | **不可以** | 自有站点，汇总主流设计平台的前沿作品；只作方向调研 |
| 用户提供的参考图 | 可以 | **看授权范围** | 用户说"就按这个感觉做"不等于授权复制；需确认可复用 |
| 本仓原创知识库 | 可以 | 可以 | `knowledge/` 与 `knowledge/styles/` 为自有内容，可直接引用 |
| 自有确定性栅格化图 | 可以 | 可以 | 由已确认平面直接生成，同时是几何比对基准（见 `docs/CONCEPT_RENDER.md`） |
| 平台生成的概念效果图 | 可以 | 可以 | 本系统产出，须标 `authoritative = false` |

素材库地址登记在 `omniarchitect/paths.py` 的 `REFERENCE_LIBRARY_URL`，不在这里手抄一遍；
`python -m omniarchitect reference` 会连同使用边界一起打印出来。

## 三、两层用途（核心判据）

| 层级 | 允许做什么 | 产出物 | 进交付物 |
|---|---|---|---|
| **调研级** | 看构图、看材质组合、看色调与明暗处理，提取可验证特征 | `reference-log.md`、`keywords.json` | 只有**结论**可以进 |
| **交付级** | 用自有内容、用户书面授权内容、或本系统产出的图 | 意向板、汇报 PPTX、效果图 | 图本身可以进 |

**判断口诀**：调研级只带走"描述"，交付级才能带走"图像"。
把调研级的截图直接贴进 `moodboard-r{n}.png`，就是从调研级越到交付级，规则上不成立。

## 四、素材库的五步用法

1. **先有词，再去看**。从概念主张里取三组词（基调 / 材质 / 排除项），带着词去检索；
   漫无目的地刷会把方向带偏，也拉不出可复用的结论。
2. **只看关系，不看具体户型**。关注构图重心、材质冷暖对比、光从哪来、留白多少；
   不关注"这个客厅多大、这面墙多长"——那些要回到已确认模型。
3. **提取可验证特征**。写成可判定的句子，例如"深色石材到顶、木饰面只做腰线以下 900mm"；
   不写"高级""有质感"这类无法核对的形容词。
4. **落成词与比例**。把结论写进 `keywords.json`：基调词、材质词、排除词，以及冷暖占比、
   黑色占比这类可量化口径（判据见 `skills/moodboard-aesthetic-iteration.md`）。
5. **记来源**。在 `reference-log.md` 里逐条登记：参考对象 → 来源 → 提取到的特征 → 用在哪一处。
   登记的是**结论的出处**，不是图的副本。

## 五、红线

1. 不得把素材库的图下载后放进意向板、汇报 PPTX、效果图或任何交付文件。
2. 不得把素材库的图当作材料样板、工艺依据或采购参照——图上的材质未必是真实材料。
3. 不得声明"行业标准如此""主流做法都是这样"——素材库是流行趋势的样本，不是标准来源。
4. 不得从参考图反推尺寸、面积、构造做法；几何只认已确认模型。
5. 不得把聚合站点自身的界面、水印、标识截进交付物。
6. 用户提供的参考图，若未明确可复用，按调研级处理。

## 六、与能力的关系

| 能力 | 怎么用这份规范 |
|---|---|
| `moodboard-aesthetic-iteration` | 主入口：调研 → 关键词 → 打分 → 意向板（意向板图像须自有或授权） |
| `concept-design` | 用调研结论收敛概念方向，不用参考图替代概念主张 |
| `material-design` | 参考材质搭配的**关系**，具体材料型号与性能须另查手册与检测报告 |
| `design-presentation` | 汇报里引用调研结论时注明"方向参考"，不附原图 |

## 七、常见错误

| 错误做法 | 后果 | 正确做法 |
|---|---|---|
| 把素材库截图贴进意向板 | 版权风险，且业主会误以为是本方案 | 只写结论：材质、比例、明暗关系 |
| 参考图当尺寸依据 | 几何与已确认模型冲突 | 几何只认统一空间模型 |
| 只存图不记来源 | 后续无法追溯结论从哪来 | 逐条登记 `reference-log.md` |
| 用参考图证明"大家都这么做" | 把趋势当标准 | 判据回到 `knowledge/` 与规范原文 |
| 拿参考图直接当提示词喂给平台 | 生成结果与已确认平面对不上 | 提示词写空间与材质，几何由模型与参考图锁定 |
